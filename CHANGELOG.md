## Unreleased

### Features

- **a11y:** dialogs trap focus, Esc closes only the top-most dialog and focus returns to the opener; reduced motion calms the VRM rig and the island.
- **agents:** coding tools (Claude Code / Codex / dsh …) no longer pop a bubble, voice, sound or island notice when a task starts; only finish / failure / waiting / stalled / permission requests notify. While monitoring is on, a digest ("N coding tasks still running", grouped by tool) is shown every 10 minutes. New "Spoken summaries" switch (off by default) adds progress to the digest and reads a completion summary aloud through the existing TTS path; when off, only short bubble / island notices are shown.
- **brand:** every user-visible 看板娘 / Live2D / Companion Desk string is now Nomi.
- **chat:** conversation rows now show rename, delete and more icons on hover, keyboard focus, the selected row and touch devices. Rename edits inline, deleting a Nomi chat asks for a second confirmation, deleting on a CLI tab closes the tab (still confirming when it is running), and "more" opens the same menu as right click. Read-only disk history sessions only offer "Open in a tab". The title fades out under the icons and the time gives way, so the list does not jump.
- **chat:** normal/dev chat mode, per-endpoint conversation isolation, dual sidebar list (全部/按端), and same/cross-endpoint fork (CLI tabs seed compact transcripts; not resume).
- **chat:** one provider page per endpoint, CLI history in the sidebar, unified new/conversation menus, endpoint icons and workspace picker UI strings. (`@nomi-ai/ui` patch)
- **chat:** settings "Providers and models" is now "Coding assistants" with Nomi, Claude Code, Codex, dsh and a monitor tab. The three CLI endpoints use the same third-party provider cards, presets and editor as Nomi and default to the CLI's own login. Each CLI page has a version card to detect, install and update (exact command, confirm dialog, Node checks, no silent sudo); dsh can now be installed and updated too. The coding monitor moved out of the schedule page. Endpoint icons use the Nomi, OpenAI and DeepSeek marks (lobe-icons, MIT).
- **chat:** settings menu consolidated from 16 to 13 sections. "Knowledge base" + "Memory" are now "Knowledge & memory" (tabs: Knowledge base / Long-term memory); "Schedule & reminders" + "Calendar" are now "Schedule & calendar" (tabs: Schedule reminders / Calendar sources); "Privacy & data" + "Desktop permissions" are now "Privacy & permissions" (tabs: Privacy & data / Desktop permissions). All panels, switches and data are unchanged; the old section ids and deep-link aliases are removed. The tab strips share the coding page style, with arrow-key / Home / End navigation.
- **chat:** the sidebar header is now one row (collapse, Nomi logo, search icon, new-chat icon) and the all/by-endpoint switch is a compact control next to the conversation heading. New fuzzy conversation search (Cmd/Ctrl+F): matches title, first message, workspace and endpoint name, tolerant of skipped letters and friendly to Chinese, highlights matches, works in both views, and covers Nomi chats, CLI tabs and Claude/Codex/dsh disk history through a chunked index built by the main process. In normal mode the sidebar shows Nomi conversations only; the saved view is restored when you go back to dev mode.
- **cli-providers:** separate Claude/Codex provider stores, upstream API formats, and local routing UI strings. (`@nomi-ai/ui` patch, `@nomi-ai/ai-runtime` patch)
- **electron:** dsh becomes the third coding agent takeover endpoint: version check and npm update, headless JSON sessions forwarded and resumed, and a separate dsh provider store that writes a managed block into `cordis.patch.yml` (the API key is only injected at launch). Docs add the Ollama context length note and the multi-tab concurrent backend design.
- **electron:** the local CLI route now converts streaming (SSE) responses between Anthropic Messages, OpenAI Chat Completions, OpenAI Responses and Gemini, including text deltas, tool calls, stop reasons, usage and mid-stream errors.
- **i18n:** label tables and provider names translated; English UI e2e; `check:i18n` now also fails on dead keys.
- **mascot:** Nomi's 2D mascot now has 41 named Live2D-style actions (wave, nod, think, heart, blow a kiss, thumbs up, sorry, yawn, goodnight and more) on a brand-locked rig. The official hairclips, orange bow, hair bars, earring, choker charm, jacket, chest logo and ID tag are only ever moved, never redrawn: a test hashes every master layer and checks that all brand layers stay opaque, unsheared and uniformly scaled in every frame of every action. Hands are cut from AI art and attached to a raised arm that is one continuous sleeve (upper arm, round elbow cap, forearm that foreshortens on the swing), with anticipation, overshoot, spring follow-through of head, hair, ribbon and torso, and slow drift while a pose is held. The action manager has priorities, queueing, holds, cooldowns and crossfades, with idle micro-actions on top; task results, thinking, tools, long answers and file drops pick fitting actions, reduced motion is respected, and the toolbar menu, tray and AI tool list every action with Chinese labels.
- **shortcuts:** new chat, focus input, settings and a Cmd/Ctrl+K command palette; every shortcut is listed in Settings with rebinding and conflict hints.
- **ui:** unified empty / error / loading states with retry, including failed model and voice downloads.
- **ui:** unify icons on lucide-react — settings navigation, empty states, notices, badges, close and chevron buttons, the composer and the Dynamic Island no longer use emoji, text glyphs or hand-drawn SVG. One size/stroke spec (18 nav, 16 inline, 1.75 stroke, theme colour, accent for the active nav item) and one EmptyState with a rounded tinted icon container. Provider and vendor brands keep the vendored lobehub icons.
- **usage:** manual price sync from models.dev — a "Sync prices" button in Usage & cost → Pricing downloads the public price table (`https://models.dev/api.json`, `Accept-Encoding: br, gzip`, ETag / `If-None-Match` so unchanged data is not downloaded again) only when you click it; nothing about your usage is uploaded and there is no background polling. Only first-party providers are used (no resellers); only input / output / cache read / cache write and context tiers are kept; negative / non-numeric / incomplete entries are dropped, deprecated models never override built-in prices and built-in models are never removed. The result is cached in userData as an overlay (falls back to the built-in table on failure); priority is custom > synced > built-in, and the panel shows the table date and last sync time. Long-context tiers (e.g. > 272K) are applied per request (prompt tokens incl. cache), not per day; the built-in table now carries these tiers too.
- **usage:** read local usage of Qwen Code, OpenCode, GitHub Copilot CLI and Kimi (Kimi CLI / Kimi Code) alongside Claude Code, Codex, dsh, Gemini and Aider — accounting fields only (time, model, token counts), de-duplicated per request. OpenCode (`opencode.db`) and Copilot CLI (`session-store.db`) are opened read-only with Node's built-in `node:sqlite` and only run fixed `SELECT`s on accounting columns, so no native dependency is added; nothing is uploaded and no credentials are read. Each tool's home-directory environment variable is respected (`CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `GEMINI_CLI_HOME`, `QWEN_HOME`, `OPENCODE_HOME` / `XDG_DATA_HOME`, `COPILOT_HOME`, `KIMI_HOME`, `KIMI_CODE_HOME`), and the detected-tools line in the usage panel now shows friendly names for them.
- **usage:** safe quota refresh — the subscription quota card gets a Refresh button; only when you click it and the local snapshot is missing / expired (> 5 min or window reset) does Nomi start the official CLI, which fetches the quota with its own login: `claude -p /usage --output-format json` (restricted subprocess: temp dir, no tools / MCP / settings, telemetry and auto-update off, 15 s timeout, 256 KB stdout cap, stderr discarded; reset-time parser handles time zones / DST; silently degrades when `/usage` is unavailable in `-p` mode) and `codex app-server` → `account/rateLimits/read` (read-only, no approvals, exits right after; only percentages / windows / reset times / plan are kept). Nomi never reads, stores or uploads login credentials (no `auth.json` / `.credentials.json` / keychain access, no unpublished endpoints, no third-party credentialed HTTP); never auto-polls; each tool is refreshed at most once per 60 s; Codex sends one request to OpenAI on a manual refresh (explained in the panel). Caches are isolated per account via a salted-hash fingerprint (no email stored), switching accounts clears the old value, transient failures show the last value as stale while auth failures clear it. Respects `CLAUDE_CONFIG_DIR` / `CODEX_HOME`; custom-provider detection now covers `settings.local.json` and `apiKeyHelper`. New "Active quota refresh" switch in Privacy & data; API-billed tools still show "API billing, no subscription quota".
- **usage:** token usage and billing — Settings → 用量与费用 (usage & cost) panel with summary cards, trend, source / provider breakdown, model ranking, yearly heatmap, detail table with CSV export and an editable price table (USD / CNY); records Nomi chat / local-route calls (response usage, estimate marked) and reads Claude Code / Codex / dsh session logs incrementally; unpriced models are never guessed; local-only storage; daily / monthly budget alerts at 80% and 100% (once each, mascot bubble + island, quiet-mode aware) and a single-task high-spend alert; CodingMonitor sessions show cumulative tokens and cost; the task-end summary broadcast appends this task's cost when summary broadcast is on; privacy settings (master switch, log reading, retention, one-click clear); subscription quota card shown only for tools signed in with an account / subscription (login method read from the official `claude auth status` / `codex login status`, falling back to config key names; API-key / third-party / local-route tools and Nomi chat show "API billing, no subscription quota"); quota comes only from data already on this machine — the quota snapshot Codex writes to its session logs and, opt-in, Claude Code's official statusline `rate_limits` saved by a reversible local hook script — never estimated and never fetched with credentials or unpublished APIs; the usage panel no longer clips on narrow windows (min-width fix, responsive heatmap / table / cards) and card spacing is unified.
- chat tabs run coding agents concurrently (Claude Code / Codex / dsh, default limit 3, queueing beyond it), each with its own session and working directory; tabs show status dots, unread badges and running/queued load, support add/close/rename and keyboard shortcuts, and persist across restarts. The coding agent monitor aggregates dsh sessions (detected via the held session lock) and Nomi tabs with endpoint filters; the mascot and the Dynamic Island react per endpoint. dsh tool results are paired with their tool names, and the app warns when dsh needs Node 24 or newer.

### Fixes

- **chat:** Alt+number in the Local panel now follows the visible tabs (Local, Calendar access and
- **chat:** CLI install and update progress, logs and results are kept by the main process per endpoint, so leaving the settings page or switching endpoints no longer loses them; repeated clicks reuse the running task. fix(electron): CLI probing runs asynchronously so the main process is never blocked. fix(chat): a Codex session spread over several rollout files is listed once, which removes the duplicate React key warning.
- **chat:** a streaming reply is now saved into the conversation that started it, so switching or creating a conversation mid-stream no longer leaks messages into the wrong chat. feat(chat): the send button turns into a stop button while Nomi is generating; stopping aborts the upstream request and keeps what was already generated. fix(chat): switching conversations quickly no longer lets a slower history load overwrite the visible messages.
- **chat:** deleting a conversation no longer creates a blank new one; the view switches to the most recent remaining conversation of the same kind, and deleting the last one only clears the pane.
- **chat:** drawers and dialogs (e.g. "Add provider") now start below the window title bar, so the native window buttons (macOS traffic lights, Windows / Linux window controls) always stay fully visible and the title bar stays draggable; the drawer close button is now the text "Close" ("关闭") instead of an X icon. This replaces the earlier workaround that hid or dimmed the native window buttons and intercepted window close while a drawer was open.
- **chat:** in normal mode a Nomi conversation can no longer be forked to Claude Code, Codex or dsh. The context menu and the row "more" menu only offer "Fork as new chat"; cross-endpoint fork stays a dev-mode feature.
- **chat:** long conversations (50+ messages) no longer clip or overlap tall messages: rows are measured instead of assuming a fixed height, and are keyed by message id. fix(chat): the message list follows new content only while you are at the bottom; scrolling up to read no longer gets yanked back, and short conversations now follow the stream too.
- **chat:** while one CLI endpoint is being installed or updated, other endpoints' install/update actions are disabled and the main process refuses concurrent runs instead of surfacing a failing error task. fix(chat): CLI version info is refreshed only once after an install/update run finishes, removing a redundant round of npm version checks.
- **electron:** fixes found by running the real Claude Code and Codex: the harness closes CLI stdin, so Codex no longer hangs waiting for input; switching backend drops the previous CLI session and Codex resume uses valid arguments; the Codex config patch keeps a single provider table; and the local route reports input token usage at the end of the stream.
- **electron:** non-streaming replies through the local CLI route now keep tool calls, stop reasons and usage for every format pair, and Codex free-text tools come back as `custom_tool_call` items (streaming and non-streaming).
- **electron:** on macOS the Dynamic Island no longer transforms the process type when it shows over full-screen spaces, which made the menu-bar items and Dock icon disappear in dev mode; the tray is also kept alive, never gets an empty icon, and is recreated when lost.
- **electron:** opening the chat window from several places at once (tray, shortcut, notification) now opens a single window. fix(voice): stopping hands-free / wake listening and starting again quickly no longer lets the previous session's pending recognition leak into the new one. fix(renderer): the 3D character reports frame rate once per second from an averaged window instead of on every frame, and automatic quality reduction now actually triggers when the frame rate stays low.
- **electron:** quitting the app (menu, Cmd/Ctrl+Q or SIGTERM/SIGINT) now waits for a real shutdown, with a 5s safety timeout, before exiting; previously the process could exit before cleanup finished. fix(electron): on quit the CLI harness kills running Claude/Codex/dsh processes together with the tools they spawned, the local route closes its keep-alive connections, and the knowledge base stops its indexing timers, downloads and OCR worker instead of leaving them behind.
- **electron:** running Python code now says plainly that it has no system-level isolation (it runs with your user's permissions, only with a temp working directory and a trimmed environment) and asks for a second confirmation before it runs; the tool description no longer calls it an isolated sandbox. JavaScript keeps its Node permission-model limits and a single confirmation.
- **electron:** the CLI harness, CLI provider, local route and agent-progress IPC channels now verify the sender like every other ai:* channel. fix(electron): the local CLI route only listens on loopback (0.0.0.0 / LAN hosts are rejected), validates the Host header and requires a random per-install token, which is written into the Claude Code / Codex config (re-activate a routed provider profile once to refresh it). fix(electron): the agent browser now blocks sub-resource requests (images, scripts, XHR, WebSocket, iframes) and redirects to private, link-local and cloud-metadata addresses, not only top-level navigations. fix(runtime): a failed or timed-out MCP connect now closes the client and its stdio child process instead of leaking it. fix(electron): the chat stream stops pushing chunks (and cancels generation) once the window that asked for it is destroyed.
- **electron:** the local CLI route now forwards tools, tool choice, prior tool calls and results, images, system prompts and max tokens to non-native upstreams; Gemini upstreams authenticate with `x-goog-api-key` and take the model from the URL; a plain JSON reply to a streaming request is converted into the client's SSE events.
- **island:** the Dynamic Island no longer has a big empty black area above its content. The window height now follows the content (measured in the page), padding is symmetric and compact (pill: 11px; notch: only the real menu-bar height, with the icon moved into the notch band), the pill keeps a 5px gap under the menu bar and follows the light/dark appearance, and each event state has its own accent. The island window also uses its own session so the app-wide CSP no longer blocks its inline script in non-dev builds.
- **security:** CSP is injected as a `<meta>` tag into the chat and TTS-config pages so it also applies to `file://` loads in packaged builds.
- **security:** private-address check covers IPv4-mapped/compatible IPv6, NAT64, decimal/octal/hex IPv4, 100.64.0.0/10 and 0.0.0.0/8; TTS downloads resolve DNS first and pin the checked address (rebinding mitigation).
- **usage:** more accurate usage billing from coding-tool logs. Gemini CLI: new `session-*.jsonl` logs (and subagent logs under `chats/<parent>/<child>.jsonl`) are scanned, repeated lines of the same message id keep the last one, cached tokens are subtracted from input. Codex: forked / subagent rollouts that replay the parent's history are no longer counted twice. Claude: cache writes are priced per tier (1h ≈ 2× input, 5m remainder), `speed: "fast"` requests are billed at 2×, and duplicated message ids keep the max usage. dsh: `inputTokens` is now treated as excluding cache (checked against the repo fixture only — not yet verified against real dsh logs); V0 `session.jsonl` is matched too. Existing ledger records keep their old accounting (missing fields mean the old basis).
