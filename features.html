功能

Nomi 能帮你做什么

一位会动、会说话的桌面伙伴，加上干净好用的对话与自动化能力。

桌面伙伴

  • 会呼吸的角色分层立绘驱动的伪 3D：眨眼、视线跟随、呼吸、头发摆动、说话口型同步。
  • 表情与互动表情随对话与任务切换；摸头、单击、双击各有反应；可沿屏幕底边散步，支持多显示器。
  • 透明不挡事只有角色本身可点击，其余区域鼠标穿透；回复以气泡显示在身边。
  • 换形象与拖文件可导入 VRM 模型；把文件拖到 Nomi 身上直接总结。

对话

  • 简洁对话窗口平静简洁的布局，流式输出，会话列表与可收起侧栏。
  • 图片与截图提问Ctrl/⌘+Alt+A 框选屏幕任意区域，直接带图提问。
  • 快捷命令与引导输入框按 / 打开命令；首次引导完成语言、主题、角色、模型与隐私设置。

供应商

  • 一键切换在对话工具栏或托盘直接切换供应商与模型，立即生效。
  • 内置预设OpenAI、Anthropic、Gemini、DeepSeek、Kimi、智谱、通义、豆包、Ollama、LM Studio 等，也可自定义。
  • 多 Key 与加密主备 Key 自动切换；API Key 用系统钥匙串加密，界面只显示掩码。
  • 按任务分配模型对话、工具调用、摘要可分别指定不同供应商与模型。

知识库

  • 文件夹与笔记基于你选的文件夹或笔记回答，并标出可点击的引用来源。
  • 多格式与 OCR支持 txt、Markdown、PDF、Word，以及图片里的文字（本地 OCR）。
  • 增量索引增量更新；可选本地或云端向量模型提升检索效果。

记忆

  • 长期记忆对话结束后自动整理成记忆，相关话题时自然想起。
  • 个人档案称呼与偏好随时可看、可改、可删、可导出。

日程

  • 提醒与定时任务支持重复规则；错过的提醒下次启动补上；可做每日简报等。
  • 主动聊天默认关闭；按频率、活跃时段与免打扰偶尔搭话。
  • 系统日历连接 macOS / Windows / Linux 日历，或导入 .ics、订阅链接、CalDAV。

屏幕问答

  • 框选提问框选屏幕直接提问。
  • 屏幕记忆默认关闭；定时截屏并本机识别文字，之后可问刚才看过的内容；可排除应用与自动清理。

MCP 与技能

  • MCP 服务器图形界面添加、连接、管理；敏感工具调用前会请你确认。
  • 技能包支持 SKILL.md：启用、编辑、新建，或从文件夹导入。

本地模型

  • 一键本机运行下载开源小模型并在本机运行，自动注册为可用供应商。
  • Ollama 管理列出、拉取、删除本机 Ollama 模型；完全离线也能聊天与知识库问答。

自动化

  • 桌面文件授权后可列出、搜索、阅读、总结；写入需确认，删除进回收站可撤销。
  • 受控浏览器与沙箱独立无痕窗口浏览公开网页；隔离目录运行 JS / Python 片段。
  • 审计日志所有操作都有本地审计日志。

语音

  • 语音输入本地离线识别，或使用你配置的在线服务；支持免按键对话。
  • 语音播报系统语音或自建 TTS（支持参考音频克隆）；口型随声音同步。

编程助手监视

  • 发现本机助手自动发现 Claude Code、Codex、Cursor、Aider、Cline、Continue 等。
  • 气泡提醒任务完成或需要你操作时用气泡提醒；只读本机已有日志与会话文件。

灵动岛

  • macOS 灵动岛消息、编程助手进度与提醒以刘海处样式出现；其他平台以顶部胶囊显示。

个性化

  • 主题与图标暖墨、石墨、纸白、冷雾；多款应用图标，窗口与托盘即时更新。
  • 快捷键Ctrl/⌘+K 命令面板等全部可改键，并提示冲突。
  • 中英文与无障碍界面可跟随系统；完整键盘操作，尊重「减少动态效果」。

自动更新

  • 后台检查安装版后台检查并下载新版本，经你确认后才重启安装。

隐私

  • 本地优先对话、记忆、知识库、日程都保存在本机；可一键导出全部本地数据。
  • 仅本地模型可开启「仅本地模型」，敏感内容不发往云端。

更细的说明见 文档中心，或直接阅读仓库内 docs/features。
