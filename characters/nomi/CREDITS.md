# Nomi character pack — credits & license

The official character, **Nomi**, as an ordinary character pack: Rive scene (`rive/`, a remote
asset downloaded when the animation is turned on), prompt voice clips (`voice/zh/`), onboarding
illustrations (`onboarding/`), persona and character copy (`persona.json`, `locales/`). The static
image the app shows by default (and when Rive cannot start) is the SVG rig's mother image.

Artwork is owner-provided and AI-generated, licensed by the project owner (see `docs/BRAND.md`,
`CREDITS.md` at the repository root and `assets-licenses.json`).

There is no model store or model import: a build ships exactly one character pack.
