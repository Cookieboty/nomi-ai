# Nomi character pack — credits & license

The official character, **Nomi**, as an ordinary character pack: Rive scene (`rive/`), 2D layered
sprite fallback (`sprite/`), prompt voice clips (`voice/zh/`), onboarding illustrations
(`onboarding/`), persona and character copy (`persona.json`, `locales/`).

Artwork is owner-provided and AI-generated, licensed by the project owner (see `docs/BRAND.md`,
`CREDITS.md` at the repository root and `assets-licenses.json`). The sprite master layers are
brand-locked (`sprite/brand-lock.json`).

There is no model store or model import: a build ships exactly one character pack.
