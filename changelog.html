v1.1.0 — 本地统一模型网关与按标签页第三方编程助手

2026-10-22
  • 本地统一模型网关：Nomi 对话与编程助手第三方模型经同一进程转发；新增设置 →「模型」页，可编辑供应商、Key、协议与回退链。
  • 编程助手可按标签页选择「官方账号」或「第三方」（Claude Code / Codex / Gemini / Grok / dsh），不再改写 CLI 全局配置；可选 nomi-claude / nomi-codex 等终端启动命令。
  • DeepSeek、智谱 GLM、Kimi、通义千问（百炼）、MiniMax 等预设补全协议地址与模型能力，含 Coding Plan；网关自动换 Key、冷却、会话亲和并从上游报错学习。
  • 用量面板新增「最近请求」；Codex 压缩历史可完整列出；标签可一次关闭左侧或右侧；托盘列出最近 5 个模型。
  • 修复 Gemini CLI 0.65 第三方认证、Windows 分数 DPI 透明窗口尺寸、推理重试、Codex 发送后立刻停止误拆会话，以及端信息卡模型展示。

v1.0.3 — 全新看板娘、斜杠命令与性能提升

2026-10-18
  • 看板娘全新升级：桌面角色换成全身 Rive 角色，分层服装与手臂协同运动（挥手、问好、欢呼），有表情、眨眼，说话时口型同步；Rive 无法启动时自动回退到分层 2D 渲染器。
  • 看板娘可调大小：约 30%–150%（受屏幕限制），支持 Ctrl/⌘ + 滚轮、Ctrl/⌘ + + / - / 0、右键菜单与「设置 → 通用 → 看板娘大小」滑块；脚底位置不动，大小会被记住。
  • 所有对话支持斜杠命令：在 Nomi、Claude Code、Codex、Grok、dsh 中输入 / 即可打开分组、可模糊搜索的命令面板；/context、/cost、/status、/model 等在本地执行并以卡片显示，未知命令不会被误发给模型。
  • 所有对话同一套视图，并新增 Grok Build 编程助手端点：紧凑工具行、可折叠分组、彩色 diff、等待状态与每轮耗时 / Token / 费用；订阅额度改为按工具的卡片，开发模式新增端点信息卡。
  • 性能：切换会话中位延迟 252 ms → 27 ms，流式回复主线程占用 34.8% → 8.8%，对话窗口首屏 JS 由 901 KB 降到 737 KB；空闲 30 分钟的 Claude Code 进程会自动回收并在下一条消息续接。
  • 修复与行为变化：「分叉为新对话」立即显示在侧栏；看板娘气泡不再显示原始 Markdown；「没有找到可用的麦克风」提示自动消失；TTS 不再回退到系统语音；默认唤醒词改为「你好，诺米」。

v1.0.2 — 用量统计与体验改进

2026-10-16
  • 用量与费用：统计 Nomi 对话与本机编程工具（Claude Code、Codex、dsh、Gemini CLI、Qwen Code、OpenCode、GitHub Copilot CLI、Kimi、Aider）的 Token 用量与预估费用，含趋势、分布、年度热力图、CSV 导出与可编辑价格表；数据只保存在本机，日 / 月预算在 80% 与 100% 时提醒。
  • 同步价格与订阅额度：仅在点击时下载 models.dev 公开价格表；订阅额度卡片的“刷新”由官方 CLI 用自己的登录态获取，Nomi 不读取、不保存登录凭据，也不在后台轮询。
  • 编码助手通知更安静：任务开始不再弹出提示，只在完成、失败、等待、卡住与请求权限时通知；监控开启时每 10 分钟汇总一次运行中的任务；新增“语音摘要”开关（默认关闭）。
  • 对话：生成时发送按钮变为停止按钮；流式回复保存到发起它的会话，切换会话不再串话；长对话不再裁切或重叠消息。
  • 设置菜单由 16 项精简为 13 项（知识与记忆、日程与日历、隐私与权限、语音与屏幕），知识 · 记忆 · 日程合并为一个抽屉；图标统一；抽屉与对话框从标题栏下方开始，窗口按钮始终可见。
  • 稳定性与安全：退出时等待干净关闭并停止编码助手进程；本地 CLI 路由仅监听回环地址并使用随机令牌；Agent 浏览器拦截内网子资源与重定向；运行 Python 前明确提示无系统级隔离并二次确认。

v1.0.0 — 首个正式版

2026-10-16
  • 首个正式版：Windows / macOS（Apple Silicon 与 Intel）/ Linux 官方安装包均由 GitHub Actions 构建发布。
  • 编码助手：Nomi、Claude Code、Codex 作为可切换的接入端点；对话标签页可并发运行（默认并行上限 3，超出排队），每个标签页有独立会话与工作目录；可检测、安装并更新各 CLI 版本。
  • 本地 CLI 路由：在 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses 与 Gemini 之间转换流式与非流式回复，包含工具调用、停止原因与用量。
  • 对话：普通 / 开发者模式、按端点隔离的会话、会话模糊搜索（Cmd/Ctrl+F）、会话行重命名与删除、分叉为新对话、可随时停止生成。
  • 桌面伙伴：Nomi 拥有 41 个命名动作，并锁定品牌形象；任务结果、思考、工具调用与文件拖入会触发合适的动作，并尊重“减少动态效果”设置。
  • 效率：Cmd/Ctrl+K 命令面板，新建对话、聚焦输入框、设置等快捷键均可在设置中查看与重新绑定。
  • 体验与可访问性：对话框焦点管理、统一的空 / 错误 / 加载状态（含重试）、首次使用引导、设置页与侧边面板按需加载。
  • 安全：CSP 同样作用于打包后的 file:// 页面，私有地址检查更严格，TTS 下载防 DNS 重绑定，加固 IPC、本地 CLI 路由、浏览器与 MCP 连接。
