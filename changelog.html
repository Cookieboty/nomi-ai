v2.0.2 — 右栏「改动」直接提交与同步、外发内容保护、全局背景图

2026-10-26

新功能

  • 右栏「改动」可以直接提交、暂存、撤销。
  • 分支栏可以拉取（只快进）和推送（不会强推）。
  • 右栏「改动」可以切换 worktree。
  • AI 一键生成提交信息。
  • 放弃未暂存的改动后可以撤销。
  • 外发内容保护：发往云端前自动隐藏密钥，回复里再还原。
  • 全局背景图，可选内置图或自己的图片。
  • 对话窗口可以拖入任意文件。

改进

  • 背景图选图失败会提示，大图自动缩小并保留透明。
  • 底部提交区不再被裁掉。

修复

  • 复制按钮点了没反应的问题已修复。
  • git 操作更安全：不会误动仓库外的文件，凭据不会出现在日志里。
  • 第一个未暂存的文件不再被误显示为已暂存。
  • 没配置 Nomi 模型时，生成提交信息改用当前标签的模型。

v2.0.0 — 委派编程助手、统一网关加深与模型质量

2026-10-25

新功能

  • 委派编程助手：诺米可把开发、文档、审查、调研交给本机 Claude Code、Codex、Grok、Gemini、dsh 或你添加的外部助手；对话里有进度、审批与停止，完成后整理汇报。
  • Agent Profile：委派时可选用默认 / 省钱 / 本地等档位，少花钱也能把活干完。
  • 外部 CLI：在设置里用命令与参数模板接入任意说 ACP 的编程助手。
  • 模型质量面板：按模型、供应商与 Key 对比成功率、延迟与断流，支持并排与导出。
  • Nomi 自己的权限模式（计划 / 逐项确认 / 自动改文件等），敏感与破坏性操作仍会请你确认。
  • 代码沙箱更硬：在支持的系统上隔离运行，改文件更安心。

改进

  • 「模型」页统一网关体验加深：辅助模型、每 Key 并发、回退与分配更稳，对话与编程助手共用一套配置。
  • 官方账号一账号一配置目录，多账号可并行用在不同标签。
  • 斜杠命令 /agent 可指定编程助手名；委派默认异步，仓库内可用隔离工作区并行。

修复

  • 模型路由与上游异常时更稳的降级与提示，减少「卡住不知道怎么了」。
  • 编程助手会话、权限切换与自动更新失败提示更清楚，可重试。

v1.2.0 — 三栏工作区、全屏审查与上下文环

2026-10-23
  • 工作台改为左中右三栏：左侧会话、中间对话与 Diff、右侧「改动 · 文件」。git 仓库里按「已暂存 / 未暂存」分组，助手本会话改过的文件带标记；文件树列出整个工作目录；分割线可拖动并被记住。
  • Diff 宽屏左右并排；文件预览可编辑保存，Markdown 有预览模式；新增全屏审查；助手每轮消息下出现「已编辑 N 个文件」摘要卡，确认后可撤销本轮写入；「让助手提交」只把指令填进输入框，由你确认后发送。
  • 上下文环取最后一次模型请求的真实用量，悬停显示「当前上下文 / 最大」；Claude Code、Codex、Grok、Gemini 可附图（dsh 不支持）；Codex 新增 ultra 思考深度。
  • 新增界面模式「精简 / 全量」；聊天背景铺满整个工作台，侧栏、对话区、右侧面板分别调模糊；记住窗口位置与大小；macOS 红绿灯跟随主题；去掉「最多同时运行」并发上限。
  • 自动更新失败会说明在哪一步并可重试，下载 90 秒无进度自动取消；网关非流式请求的首字节超时按流式 / 非流式 / 推理分别为 30 秒 / 5 分钟 / 10 分钟，可用 NOMI_GATEWAY_* 环境变量覆盖；工作区文件读写拒绝符号链接逃逸。

v1.0.3 — 全新桌面伙伴、斜杠命令与性能提升

2026-10-18
  • 桌面伙伴全新升级：桌面角色换成全身 Rive 角色，分层服装与手臂协同运动（挥手、问好、欢呼），有表情、眨眼，说话时口型同步；Rive 无法启动时自动回退到分层 2D 渲染器。
  • 桌面伙伴可调大小：约 30%–150%（受屏幕限制），支持 Ctrl/⌘ + 滚轮、Ctrl/⌘ + + / - / 0、右键菜单与「设置 → 通用 → 桌面伙伴大小」滑块；脚底位置不动，大小会被记住。
  • 所有对话支持斜杠命令：在 Nomi、Claude Code、Codex、Grok、dsh 中输入 / 即可打开分组、可模糊搜索的命令面板；/context、/cost、/status、/model 等在本地执行并以卡片显示，未知命令不会被误发给模型。
  • 所有对话同一套视图，并新增 Grok Build 编程助手端点：紧凑工具行、可折叠分组、彩色 diff、等待状态与每轮耗时 / Token / 费用；订阅额度改为按工具的卡片，开发模式新增端点信息卡。
  • 性能：切换会话中位延迟 252 ms → 27 ms，流式回复主线程占用 34.8% → 8.8%，对话窗口首屏 JS 由 901 KB 降到 737 KB；空闲 30 分钟的 Claude Code 进程会自动回收并在下一条消息续接。
  • 修复与行为变化：「分叉为新对话」立即显示在侧栏；桌面伙伴气泡不再显示原始 Markdown；「没有找到可用的麦克风」提示自动消失；TTS 不再回退到系统语音；默认唤醒词改为「你好，诺米」。

  • 稳定性与安全：退出时等待干净关闭并停止编码助手进程；本地 CLI 路由仅监听回环地址并使用随机令牌；Agent 浏览器拦截内网子资源与重定向；运行 Python 前明确提示无系统级隔离并二次确认。

v1.0.0 — 首个正式版

2026-10-16
  • 首个正式版：Windows / macOS（Apple Silicon 与 Intel）/ Linux 官方安装包均由 GitHub Actions 构建发布。
  • 编码助手：Nomi、Claude Code、Codex 作为可切换的接入端点；对话标签页可并发运行（默认并行上限 3，超出排队），每个标签页有独立会话与工作目录；可检测、安装并更新各 CLI 版本。
  • 本地 CLI 路由：在 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses 与 Gemini 之间转换流式与非流式回复，包含工具调用、停止原因与用量。
  • 对话：普通 / 开发者模式、按端点隔离的会话、会话模糊搜索（Cmd/Ctrl+F）、会话行重命名与删除、分叉为新对话、可随时停止生成。
  • 桌面伙伴：Nomi 拥有 41 个命名动作，并锁定品牌形象；任务结果、思考、工具调用与文件拖入会触发合适的动作，并尊重“减少动态效果”设置。
  • 效率：Cmd/Ctrl+K 命令面板，新建对话、聚焦输入框、设置等快捷键均可在设置中查看与重新绑定。
  • 体验与可访问性：对话框焦点管理、统一的空 / 错误 / 加载状态（含重试）、首次使用引导、设置页与侧边面板按需加载。
  • 安全：CSP 同样作用于打包后的 file:// 页面，私有地址检查更严格，TTS 下载防 DNS 重绑定，加固 IPC、本地 CLI 路由、浏览器与 MCP 连接。
