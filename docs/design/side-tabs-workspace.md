# 对话旁的标签区（子任务 + 文件）

状态：已实现（`feat/agent-tabs-workspace`）。在[子任务对话与主对话对齐](subagent-chat-parity.md)的侧栏方案上，把「对话旁那一栏」改成一排标签。

## 要解决的问题

- 以前侧栏一次只能看一个子任务，点另一个「查看」会把前一个换掉；多个 agent 并行时来回切很麻烦。
- 文件预览（预览区的文件 / Diff 标签）和子任务侧栏是两块互相抢位置的右栏：文件预览浮在对话上面、有自己的宽度和「全屏」，子任务又是另一栏。
- 文件预览的「全屏」会把主对话缩成一个可拖动的小浮窗，主对话不是一等公民。

## 交互模型

参考 Codex 桌面版的分栏标签：左边主对话，右边一排标签。

```text
分栏：  [ 主对话 (chat-column) ] | [ 标签栏: Claude Code ● | 子代理 | a.md | b.ts  (+) (⤢) ]
                                   [ 当前标签的内容                                         ]

铺满：  [ 标签栏: 主会话 | Claude Code ● | 子代理 | a.md | b.ts  (+) (⤡)          ]
        [ 当前标签的内容（主会话时就是原来的主对话列）                            ]
```

- 标签种类：
  - 子任务：委派的编程助手标签（harness）、进程内子代理（nested）、后台 Nomi（nomi-task）。面板和 #356 完全一样（同一个 `HarnessChat` / `NestedChat` / `NomiTaskChat`，按会话 id 绑定），只是放进了标签里。
  - 文件：预览区的每个文件 / Diff 标签各占一个标签，和子任务排在同一排（子任务在前，文件在后，各自按打开顺序）。
  - 主会话：只在铺满时出现，永远是第一个，不能关。
- 点「查看子任务」（时间线、委派卡、会话详情里的 Agents / 任务）：开一个标签，已开着就切过去。可以同时开好几个。
- 切换标签：切走的标签只隐藏、不卸载，流式输出、输入框草稿、滚动位置、待发列表都在。
- 关闭（×、中键、⌘/Ctrl+W）：只关标签，不停子任务。文件标签的关闭交给预览区（先存草稿，Diff 有没保存的编辑要确认）。分栏时在子任务里按 Esc（焦点不在输入框）仍然关当前子任务标签，和以前的侧栏一致。
- 标签上：图标（编程助手的品牌图标 / 子代理 / Nomi / 文件 / Diff）、名字（由面板报上来，和面板头一致）、状态点（运行中闪烁，等你批准是警示色），× 悬停或当前标签时出现。
- 「+」：打开会话详情里的 Agents 列表（从那里开子任务），或打开右侧文件栏（从那里开文件）。
- 双击任意标签 → 铺满：标签区占满整个对话区，停在双击的那个标签；主会话变成第一个标签。铺满时：
  - 点主会话标签显示原来的主对话列（同一个 DOM，只是从隐藏变显示，草稿和流式输出都在）；
  - 再双击任意标签、点右上角的还原按钮、或按 Esc（焦点不在输入框 / 弹窗里），回到分栏，右侧仍是之前看的那个标签；
  - 文件标签的 Esc 由预览区自己处理（先关选区菜单等，再退出铺满），预览工具栏原来的「展开」按钮也改成切换铺满；
  - 文件里选中文字「问助手」：铺满时自动切到主会话标签再把引用填进输入框（替代原来的浮动小窗）。
- 最后一个标签关掉后自动回到分栏、那一栏收起。

### 排序

- 拖动标签改顺序（HTML5 拖放，落点画一条竖线）；子任务和文件可以混排。铺满时主会话标签固定在最前，不能拖，也拖不到它前面。
- 键盘：焦点在标签上时 Ctrl+Shift+PageUp / PageDown 或 Alt+Shift+← / →，一次挪一格，焦点跟着标签走。
- 顺序记在 `order`（按会话、随标签区状态一起落盘）；没排过的标签按打开顺序排在后面，关掉的标签从 `order` 里去掉。

### 向右拆分（铺满时左右并排）

```text
拆分：  [ 标签栏: 主会话 | Claude Code ● | a.md  (+) (⫼) (↗) (⤡)                 ]
        [ 主对话列            ‖ 当前标签（子任务 / 文件）                          ]
```

- 入口：子任务标签右键「向右拆分」、标签栏的拆分按钮（⫼）、把标签拖到拆分按钮上。没铺满时会先铺满。
- 拆分时左边一直是主对话，右边是当前标签；点主会话标签只是去主对话（右边不变），点别的标签 / 双击别的标签换右边。
- 中间分割线拖动改宽度（主对话占 20%–80%），双击回到一半；焦点在分割线上时 ← / → 每次 5%。比例记在 `splitRatio`。
- 退出：再点拆分按钮（仍铺满）；双击主会话标签 / 还原按钮 / Esc 回到分栏（同时退出拆分）。
- 布局：`main-content--side-split` 用 grid：第一行标签栏，第二行「主对话列 | 分割线 | SideWorkspace」，比例在 CSS 变量 `--side-split`。

### 弹出到独立窗口

- 入口：子任务标签右键「在新窗口打开」、标签栏的弹出按钮（↗，对当前标签）、把标签拖出窗口松手。
- 宿主（Go）：契约 `chatWindow.detachTab / detachedTabs / dockTab`，事件 `chatWindow.detachedChanged`（整份 id 列表）、`chatWindow.tabDocked`。
  `core/tabwindows` 记着哪些标签开着窗口；`wailsshell/detachedwindow.go` 用 Wails v3 新建 `WebviewWindow`：
  和对话窗口同一个页面 `/chat/index.html?detached=<spec>`，自己一份 chat 面 token（窗口关闭时撤销），mac 隐藏标题栏、Windows / Linux 无边框自绘窗口按钮，默认 760×820、最小 420×360。同时最多 12 个。
- id = `JSON.stringify([会话键, 标签键])`：同一个会话的同一个标签只开一个窗口，再弹一次 / 在主窗口再点「查看」只是把那个窗口提到最前（`focused: true`）。
- spec（`utils/detachedTabs.ts`）：子任务 = 会话键 + `SubagentTarget`；文件 = 链接 + 来源会话的范围（`ResourceScope`）。宿主不解析，只限长度、要求是 JSON 对象。
- 页面（`main.tsx` → `detached/DetachedApp.tsx`，单独的 chunk）：和主窗口同一套数据层（`AiChatContextProvider` / `HarnessTabsProvider` / 标签区 Provider），只画那一个面板（`SubagentPane standalone`）或文件预览，所以流式输出、输入栏、排队 / 插话、授权回复、提问都和在主窗口里一样（都按会话 / 标签 id 绑定）。窗口标题跟着子任务名字变（`<名字> — Nomi`）。弹出窗口自己的标签区状态不落盘（会话键为空）。
- 主窗口：开着窗口的子任务 / 文件不在标签栏里显示（子任务仍记在本地存储里）。
- 关窗口（系统关闭按钮 / 自绘的关闭 / 应用退出）：子任务标签回到主窗口的标签栏（不切过去）；文件弹出时已经从主窗口移走，关窗口就是关掉这个文件。
- 「放回主窗口」（只有子任务窗口有）：宿主先发 `tabDocked`（主窗口切到这个标签），再关窗口（`detachedChanged` 让它回到标签栏）。
- 退出应用：所有弹出窗口跟着关，不记哪些弹出过；下次启动这些子任务都在主窗口的标签栏里。
- 不能弹出的：主 Nomi 会话里的进程内子代理（它的内容是从主列消息里拼出来的，独立窗口里没有主列）、Diff 标签。

### 子任务悬停卡片

- 鼠标停在子任务上约 300ms，浮出一张小卡片（参考 Codex）：图标 + 名字 + 运行中转圈、状态（处理中 / 等你确认 / 已完成 / 失败 / 空闲）、最近发给它的一句（右侧气泡，两行）、它最近的输出（四行；运行中是正在写的那段），有待确认的授权时多一行提示。
- 出现的位置：标签栏里不在看的子任务标签；对话里的委派卡片标题、子代理 / 后台 Nomi 那一行；会话详情的 Agents / 任务列表。
- 移到卡片上不收起，移开约 150ms 后收起；Esc、滚动收起；拖标签时不出。点卡片 = 打开 / 切到这个子任务的标签。
- 内容只在卡片开着时订阅现有的实时来源：编程助手标签的消息与实时进度（`useHarnessTabMessages` / `useHarnessLive`）、后台 Nomi 的 `tasks.get / trace / live`、父转录里的子代理（`nestedMessages` + 实时 agent 状态）；实时来源还没内容时用调用处给的任务说明 / 结果顶上。摘录规则在 `AgentHoverCard/preview.ts`。

## 状态与持久化

- 状态在 `SubagentPaneContext`，纯函数在 `utils/sideTabs.ts`：

  ```ts
  SideTabsState = {
    agents: SubagentTarget[]; // 开着的子任务（按打开顺序）
    active: string | null; // 右侧当前看的：'files' | 子任务键（harness:/nested:/nomi-task:）
    maximized: boolean; // 是否铺满
    mainActive: boolean; // 铺满时是否切到了主会话标签
    order: string[]; // 拖过的标签顺序
    split: boolean; // 铺满时向右拆分
    splitRatio: number; // 拆分时主对话占的比例（0.2–0.8）
  };
  ```

  实际当前标签由 `resolveActive` 算：铺满且 `mainActive` → 主会话；记下的那个不在了 → 最后一个子任务 → 文件 → 无。

- 每个会话一份：键就是主列的会话键（`nomi:<对话 id>` / 编程助手标签的转录键），由 `App` 同步进来。切换主列会话时，右侧换成那个会话自己开着的标签。
- 存在 `localStorage['nomi.sideTabs.v1']`（只记有内容的、最近 40 个会话），重开应用后恢复开着的子任务标签、当前标签和铺满状态。委派标签被关掉、来源标签没了的子任务在读取时滤掉。
- 文件标签不按会话分：仍是预览区自己的一份（和以前一样，文件记着自己的来源会话，切到别的会话时显示「来源不同」）；标签区只记「当前看的是文件」，具体哪个文件由预览区记。
- 标签的名字 / 状态不落盘：每个面板挂着时报给标签栏（`reportMeta`）。

## 键盘

| 按键                                | 条件                                       | 作用                         |
| ----------------------------------- | ------------------------------------------ | ---------------------------- |
| Ctrl+Tab / +Shift                   | 焦点在标签区里（铺满时整个对话区）         | 下一个 / 上一个标签          |
| ⌘W（mac）/ Ctrl+W                   | 同上，当前标签可关                         | 关当前标签（主会话标签不关） |
| Esc                                 | 铺满、当前不是文件、焦点不在输入框和弹窗里 | 回到分栏                     |
| Esc                                 | 分栏、当前是子任务、焦点不在输入框里       | 关当前子任务标签（沿用）     |
| Ctrl+Shift+PgUp/PgDn、Alt+Shift+←/→ | 焦点在某个标签上                           | 把这个标签往左 / 右挪一格    |
| Shift+F10                           | 焦点在子任务标签上                         | 打开它的右键菜单             |
| ← / →                               | 焦点在拆分分割线上                         | 左右宽度 ±5%                 |

- Ctrl+Tab 全局本来是轮换编程助手标签（`useAppCommands`）。标签区的监听在捕获阶段、只在焦点在标签区时接管并 `preventDefault`，全局那个看到 `defaultPrevented` 就不动；焦点在主对话时 Ctrl+Tab 照旧轮换编程助手标签。
- ⌘/Ctrl+W 在快捷键设置里是保留组合（关窗口），这里同样只在焦点在标签区时拦下。macOS 上如果系统菜单先吃掉了这个组合，就退回关窗口的老行为（真机待验证）。

## 布局

- `App`：`main-content` 里依次是（铺满时的）标签栏、主对话列、预览区的覆盖层（图片查看器、外部打开失败提示）、分割线、`SideWorkspace`。插在前面的标签栏是条件渲染，不改变主对话列的位置，切换铺满不会重挂主对话。
- 分栏宽度沿用原来子任务侧栏那条分割线（对话列宽度，可拖动、双击复位、记住）。文件预览不再用自己的百分比宽度和浮层，改成在这一栏里按正常文档流排版（`ResourcePreview` 的 `hideTabs` / `embedded`）。
- 铺满：`main-content--side-max` 改成纵向排列；当前是主会话时隐藏 `SideWorkspace`，否则隐藏主对话列（都是隐藏，不卸载）。
- 右侧的「改动 · 文件」栏（`FilesRail`）保持是导航：在那里点文件，在标签区开文件标签。它的未提交文件预览（没有预览区时的旧路径）在没有任何标签时仍用原来的挂载点。

## 和 #356 的关系

- 三类子任务的面板、绑定（按 `tabId` / `callId` / `taskId`）、直接对子代理说话、主窗口面板按钮都没改，只是外面多了一层标签。
- `useSubagentPane()` 保留 `target`（当前看的子任务）、`tabId`、`openSubagent` / `openNested` / `openNomiTask`、`closeSubagent`，新增 `targets`、`active`、`activate`、`closeTab`、`toggleMaximized`、`restore`、`setScope`。
- 面板头的 × 在标签区里去掉（关闭在标签上）；单独使用 `SubagentPane` 时（单测 / 没有标签区的窗口）仍有。

## 没做的 / 限制

- 拆分只能「主对话 + 一个标签」，不能两个子任务并排。
- 拖出窗口靠 `dragend` 时指针在窗口外判断；各平台 WebView（尤其 Linux WebKitGTK）对拖出窗口的坐标不一定可靠，右键菜单 / 弹出按钮是稳定入口。
- 弹出窗口不记位置大小，也不在下次启动时恢复；文件窗口没有「放回主窗口」（关掉即可，需要时从文件栏重新打开）。
- 打包后的真机（mac / Windows / Linux）上弹出窗口只在 CI 里编译、跑了 Go 单测，没有人工点过。
- 文件标签不按会话分开（沿用预览区原来的行为）。
- 预览区原来的「文档全屏 + 浮动对话小窗」（`PreviewChat`）在主窗口里不再使用，改成主会话标签；组件和单测仍保留。
