# Nomi·诺米 2.0.10

2.0.9 之后的修复版本，Go 版与 Electron 版同时提供（文件名以 `Nomi-Electron-` 开头的是 Electron 版）。 / A fix release after 2.0.9; Go and Electron builds ship together (Electron files are named `Nomi-Electron-…`).

## 修复 / Fixes

- Codex 压缩上下文后，如果回合结束前没有新的用量上报，上下文环不再显示压缩前的旧值（重开会话后也不会），改为显示估算，直到下一次真实上报（#217） / After Codex compacts the context, if no new usage arrives before the turn ends, the context ring no longer shows the pre-compaction size (not even after reopening the chat); it shows an estimate until the next real report (#217)
- Electron 版下载角色动画时写文件失败（磁盘满、没有权限、文件被占用），按下载失败处理：有旧素材继续用，没有就显示错误可重试，不再导致整个应用退出（#216） / In the Electron build, a failed write while downloading the character animation (disk full, no permission, file in use) is treated as a failed download: the previous asset keeps working, or an error with retry is shown, instead of quitting the app (#216)

## 说明 / Notes

- 已安装 2.0.4 到 2.0.9 的用户在应用内检查更新即可升级到 Go 版 2.0.10 / Users on 2.0.4 through 2.0.9 update in-app to the Go build 2.0.10
