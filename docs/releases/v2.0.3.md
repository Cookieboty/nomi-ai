# 诺米 2.0.3

## 新功能 / Features

- Edge 实时朗读：默认晓伊（`zh-CN-XiaoyiNeural`）、语速 -5%，可换中文音色、调语速、试听；需联网 / Edge realtime TTS: Xiaoyi by default at −5% rate; pick a Chinese voice, change rate, preview; needs network
- 诺米中文提示语改为内置晓伊预录音频（约 96 段）；播放顺序：预录 → 实时朗读 → 只显示文字 / Nomi Chinese prompts use prerecorded Xiaoyi clips (~96); playback order: clip → realtime TTS → text only
- 朗读 AI 回复：普通诺米对话按句流式朗读（约前 300 字），跳过代码 / 表格 / 链接 / 思考；新消息、停止、切会话、按住说话可打断 / Read AI replies aloud sentence-by-sentence (~first 300 chars), skipping code / tables / links / thinking; interrupted by new message, stop, session switch, or push-to-talk
- 设置新增「朗读 AI 回复」（默认开）与统一「朗读语速」 / New Settings → Voice “Read AI replies” (on by default) and one shared speaking rate

## 改进 / Improvements

- 精简看板娘台词（约删 83 句），去掉调情 / 灌水互动台词，保留有信息量的提示 / Trimmed mascot lines (~83 removed), including flirt / filler poke lines; kept informative prompts
- 安装包不再内置离线 TTS 模型与系统 speechSynthesis 路径，体积更小 / Installers no longer ship the offline TTS model or system speechSynthesis path — smaller packages
- 旧 Fish / legacy 音色配置自动按「无」加载，不报错 / Old fish-local / fish-cloud / legacy configs load as “None” without errors

## 修复 / Fixes

- 中文序号「步骤1.打开…」不再与后文粘成一句连读 / Chinese ordinals like “步骤1.打开…” no longer glue to the next clause as one utterance

## 已知问题 / Known issues

- Edge 在线朗读与预录片段的再分发许可属灰色地带；正式对外建议用 Azure Speech 同音色重录预录片段 / Redistribution terms for Edge read-aloud audio are a grey area; regenerate clips with Azure Speech (same voice) before a formal external release
- Azure / OpenAI 实时引擎仍为占位（选中时静默） / Azure / OpenAI realtime engines remain stubs (silent when selected)

## 说明 / Notes

- 编程助手会话与 `/agent` 委派轮不朗读 AI 回复 / Coding-agent sessions and `/agent` handoff turns are not read aloud
- 不接入火山（Volcengine）TTS / Volcengine TTS is not integrated
