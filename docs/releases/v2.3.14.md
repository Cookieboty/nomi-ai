# Nomi·诺米 2.3.14

定时任务和编程助手不再每一步都等你点批准：授权到能跑命令的等级，就按风险自动判断。

- 定时任务：授权到「可以跑命令」（L3）及以上时，命令先交给命令审核，放行就直接跑。只有高风险、读凭据、永不放行类、审核不放行的，以及读了外部内容之后的操作才停下来问你。新建任务里「按风险自动判断」默认勾上，取消勾选才是每条命令都问。
- 派给编程助手（如 Codex）：做完自动收下，改动落到工作区，结果直接回到对话，不用再手动点确认。后台标签在任务授权到 L3 时用「自动」档，跑命令交给命令审核，不再因为前台没开「全部自动」就每条都问。
- 可重复的任务每次都回到「待开始」，等下一次触发，不会卡在「等你验收」。
- 编程助手检测不再卡在「检测中」：本地探测一结束就先显示已安装或未安装，最新版本在后台刷新（#350）。
- 预览里的工作区授权错误会留在界面上，不再一闪而过。
- Diff 草稿切换预览标签页时不会丢，保存前会校验版本，避免覆盖外部修改。

## English

Scheduled tasks and delegated coding assistants no longer ask at every step: once the grant allows running commands, risk-based review decides.

- Scheduled tasks: with a grant of L3 ("can run commands") or higher, commands go to command review and run once cleared. Only high-risk steps, credential reads, never-allow classes, review rejections, and actions after reading outside content still stop to ask. "Judge by risk" is now checked by default when creating a task; uncheck it to be asked about every command.
- Delegated coding assistants (such as Codex): finished work is accepted automatically, changes are landed in the working tree, and the result returns to the conversation instead of waiting for a manual confirmation. Background tabs use the "auto" level when the task grant reaches L3, so commands go to review instead of asking every time simply because full auto is off in the foreground.
- Recurring tasks return to "waiting for trigger" after each run instead of getting stuck on "awaiting acceptance".
- Coding-assistant detection no longer stays on "Checking…": local install state shows as soon as the probe finishes, with the latest version refreshed in the background (#350).
- Workspace authorization errors in the preview stay visible instead of flashing by.
- Diff drafts survive switching preview tabs, and saves check the revision first so they do not overwrite outside changes.
