# Nomi·诺米 2.3.10

Mermaid 图可以放大看；同时开着很多编程助手标签时，刚写的消息不再丢；文件预览放上一小时后还能继续保存。 / Mermaid diagrams open large; messages are kept when many coding tabs are open; a file preview can still be saved after an hour.

## 新功能 / New

- 会话和文件预览里的 Mermaid 图可以点图画或「查看大图」打开，滚轮和触控板捏合绕着指针缩放，也能拖动，Esc 关闭 / Mermaid diagrams in chats and file previews open from the diagram or "View full image". The wheel and a trackpad pinch zoom around the pointer; drag still works, and Esc closes it

## 修复 / Fixes

- 同时开着较多编程助手标签时，一条消息还在写入磁盘就不会被清出内存，之后再打开也不会用旧记录盖掉刚写的内容（#323） / With many coding-agent tabs open, a message that is still being written stays in memory, so opening the tab again cannot replace it with an older copy (#323)
- 文件预览打开超过一小时后再改，会重新核对工作区和文件：内容没变就换一张新的保存许可并写入草稿；文件被改过、换过、或不再允许写入时不会覆盖。草稿可以复制，也可以确认后放弃，然后关闭或切换（#324） / Editing a file preview that has stayed open for more than an hour re-checks the workspace and the file. If the bytes are unchanged, Nomi issues a new save grant and writes the draft; if the file changed, was replaced, or can no longer be written, it is not overwritten. The draft can be copied, or discarded after a confirmation, and then the tab can close or switch (#324)
- 自动更新装好并重新打开后，清掉缓存里已经用过的安装包和没下完的半截文件；还没安装的更新版本会留着。不删正在使用的程序、下载文件夹里的文件和用户数据 / After an update is installed and Nomi opens again, used installer packages and unfinished downloads are removed from the update cache. A newer package that is not installed yet is kept. The running app, files in your Downloads folder, and your data are left alone
- `/agent 名字 需求` 会立刻派出编程助手；没安装或派不出去时对话里说明，不再由对话模型回一句当作已经交出。`NOMI_USE_MOCK_CLI=1` 在 `pnpm dev`（工作目录 `apps/desktop-go`）下也能找到仓库里的假 CLI。假 CLI 不提供更新到正式版。新建任务里选代码目录的菜单不再被对话框挡住，新建任务默认改为手动运行 / `/agent name request` starts the coding assistant immediately. If it is not installed or the handoff cannot start, the chat says so instead of a normal reply that looks like success. `NOMI_USE_MOCK_CLI=1` finds the repo mocks when `pnpm dev` runs from `apps/desktop-go`. Mock CLIs are not offered an update to a real release. The code-folder menu in a new task is no longer hidden behind the dialog, and a new task defaults to run manually
- 去掉预算拦截：Nomi 自动续跑不再因为累计用量停下来让你说「继续」；持续任务不再按 token、时长或每天费用暂停或判失败，一直做到完成。之前停在「预算用完」的任务升级后自动接着排队 / Budget interception is removed. Nomi's auto-continue no longer stops on accumulated usage and asks you to say "continue", and ongoing tasks are no longer paused or failed by tokens, duration or daily cost. Tasks that were waiting on "budget used up" are queued again after the update
