# Nomi·诺米 2.3.10

工作台的第一眼改干净了：对话和工坊、空看板、引导，都按同一句话说话。

- 模式改成对话和工坊。设置侧栏写「本地优先的 Agent 工作台」。
- 引导盖住整个窗口。顺序是语言和主题、接模型、打开看板，桌面角色放在最后且默认关闭。
- 看板没有会话时只留一个主动作：派出 Claude Code 或 Codex。筛选和调度策略等有会话再出现。任务筛选等有任务再出现。
- 只宣布一个默认主题：浅色。主题名用浅色、深色、日落橙。
- 图可以放大看。同时开着很多编程助手时，刚写的消息不再丢。

## 细节

- 会话和文件预览里的 Mermaid 图可以点图画或「查看大图」打开，滚轮和触控板捏合绕着指针缩放，也能拖动，Esc 关闭。
- 同时开着较多编程助手标签时，一条消息还在写入磁盘就不会被清出内存，之后再打开也不会用旧记录盖掉刚写的内容（#323）。
- 文件预览打开超过一小时后再改，会重新核对工作区和文件：内容没变就换一张新的保存许可并写入草稿；文件被改过、换过、或不再允许写入时不会覆盖。草稿可以复制，也可以确认后放弃，然后关闭或切换（#324）。
- 自动更新装好并重新打开后，清掉缓存里已经用过的安装包和没下完的半截文件；还没安装的更新版本会留着。不删正在使用的程序、下载文件夹里的文件和用户数据。
- `/agent 名字 需求` 会立刻派出编程助手；没安装或派不出去时对话里说明，不再由对话模型回一句当作已经交出。`NOMI_USE_MOCK_CLI=1` 在 `pnpm dev`（工作目录 `apps/desktop-go`）下也能找到仓库里的假 CLI。假 CLI 不提供更新到正式版。新建任务里选代码目录的菜单不再被对话框挡住，新建任务默认改为手动运行。
- 编程助手页的名称不再被裁成半截。权限、终端启动命令和终端代理默认收起。
- 命令面板第一屏有：派出编程助手、添加供应商、打开看板、新建任务。
- 新安装默认打开工作台，桌面角色关闭。升级的安装保持原来的启动方式。
- 去掉预算拦截：Nomi 自动续跑不再因为累计用量停下来让你说「继续」；持续任务不再按 token、时长或每天费用暂停或判失败，一直做到完成。之前停在「预算用完」的任务升级后自动接着排队。
- 编程助手的会话工作目录在某个项目里就自动归进那个项目，从本机历史打开的会话、Nomi 委派开的会话也一样，以前的会话升级后自动补上。侧栏「最近」改名「其他对话」，去掉重复的新建按钮；只看一个端时不再列没有会话的项目；新建失败时说明原因。

## English

The workbench's first look is cleaner: Chat and Workshop, the empty board, and onboarding now say the same thing.

- Modes are Chat and Workshop. The settings sidebar says "Local-first Agent workbench".
- Onboarding covers the whole window. The order is language and theme, connect a model, open the board. The desktop character is last and off by default.
- An empty board has one primary action: dispatch Claude Code or Codex. Filters and the scheduling policy appear after there is a session. Task filters appear after there is a task.
- One default theme is announced: Light. Theme names are Light, Dark, and Sunset.
- Diagrams open large. A message you just wrote is kept when many coding-assistant tabs are open.

## Details

- Mermaid diagrams in chats and file previews open from the diagram or "View full image". The wheel and a trackpad pinch zoom around the pointer; drag still works, and Esc closes it.
- With many coding-assistant tabs open, a message that is still being written stays in memory, so opening the tab again cannot replace it with an older copy (#323).
- Editing a file preview that has stayed open for more than an hour re-checks the workspace and the file. If the bytes are unchanged, Nomi issues a new save grant and writes the draft; if the file changed, was replaced, or can no longer be written, it is not overwritten. The draft can be copied, or discarded after a confirmation, and then the tab can close or switch (#324).
- After an update is installed and Nomi opens again, used installer packages and unfinished downloads are removed from the update cache. A newer package that is not installed yet is kept. The running app, files in your Downloads folder, and your data are left alone.
- `/agent name request` starts the coding assistant immediately. If it is not installed or the handoff cannot start, the chat says so instead of a normal reply that looks like success. `NOMI_USE_MOCK_CLI=1` finds the repo mocks when `pnpm dev` runs from `apps/desktop-go`. Mock CLIs are not offered an update to a real release. The code-folder menu in a new task is no longer hidden behind the dialog, and a new task defaults to run manually.
- Names on the coding-assistant page are no longer cut off. Permissions, terminal launch commands, and the terminal proxy start folded.
- The command palette opens on: dispatch a coding assistant, add a provider, open the board, new task.
- A new install opens the workbench. The desktop character stays off. An upgraded install keeps its startup choice.
- Budget interception is removed. Nomi's auto-continue no longer stops on accumulated usage and asks you to say "continue", and ongoing tasks are no longer paused or failed by tokens, duration or daily cost. Tasks that were waiting on "budget used up" are queued again after the update.
- Coding-agent sessions inside a project folder are now filed under that project, including sessions opened from local history and ones Nomi delegates; older sessions are filed after the update. The sidebar's "Recent" section is renamed "Other chats" and loses its duplicate new-chat button, viewing one endpoint no longer lists projects without sessions on it, and a failed new chat says why.
