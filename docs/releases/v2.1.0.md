# Nomi·诺米 2.1.0

持续任务版本：交代一次，Nomi 一直记着——按时间或事件推进，需要你的时候来找你。Go 版与 Electron 版同时提供（文件名以 `Nomi-Electron-` 开头的是 Electron 版）。 / The persistent tasks release: tell Nomi once and it keeps track, running on a schedule or on events and coming to you when it needs you. Go and Electron builds ship together (Electron files are named `Nomi-Electron-…`).

## 新功能 / New

- 侧栏新增「任务」：在对话里说「每天 9 点帮我……」或点「新建任务」，确认授权卡片（能做什么、多久到期、预算）后才创建；任务按时间运行，结果、要你批准的事、出错都集中在任务页 / New **Tasks** in the sidebar: say "every day at 9, …" in chat or choose New task; nothing is created until you confirm the authorization card (what it may do, when it expires, budget). Tasks run on schedule, and results, approvals and errors gather on the tasks page
- 任务可以交给 Nomi 自己做，也可以交给你装好的编程助手（Claude Code、Codex……）：编程助手在独立的工作副本里改代码，做完你验收后再回填到工作区 / A task can be done by Nomi itself or by a coding assistant you have installed (Claude Code, Codex, …); the assistant works in a separate worktree, and changes come back to your workspace only after you accept them
- 事件触发：网页或 RSS 有更新、GitHub 仓库的 issue / PR 或 CI 有动静、文件夹里有新文件、编程助手一轮结束、知识库更新、本机 MCP 工具有新结果；新建的事件任务先只记录，你决定「处理这些」或改成自动处理 / Event triggers: a web page or RSS feed changes, GitHub issues / PRs or CI change, new files land in a folder, a coding assistant finishes a turn, the knowledge base updates, or a local MCP tool returns new items; new event tasks only record what they find until you choose to handle them or switch to automatic
- 对外动作逐项授权：在 GitHub issue / PR 下评论、从 `nomi/` 分支开 PR、调用本机 MCP 服务器的工具；每个对外动作先记下意图，重启后不确定有没有发出去会先自动核对，查不了再请你确认 / Outside actions are granted one by one: comment on GitHub issues / PRs, open PRs from `nomi/` branches, call tools on your local MCP servers; each action is recorded before it runs, and after a restart Nomi checks whether it went out before asking you
- 派给后台的 Nomi：生成一组图片、写 PPT 或调研报告这类要做一阵子的事，Nomi 交给后台的自己去做，对话照常继续，做完结果回到这个对话；后台的 Nomi 能用对话里的工具，代码部分自己再交给编程助手。它默认有较高权限，只有删除、高危命令和审核没放行的命令会停下来等你 / Hand work to Nomi in the background: for things that take a while, such as a set of images, a slide deck or a research report, Nomi hands them to a background copy of itself and the chat carries on; the result comes back to the same chat. The background Nomi uses the same tools as the chat and passes coding parts to a coding assistant. It runs with broad permissions by default and only stops to ask before deleting, running high-risk commands or commands the review doesn't allow
- 看板视图：按进度或重要程度分列、按类型筛选；任务可以设重要程度和类型 / Board view: columns by progress or priority, filtered by type; tasks can have a priority and a type
- 设置新增「应用与账号」：连接 GitHub（复用本机 gh 登录或粘贴令牌），如实显示登录的权限范围；本机 MCP 服务器的工具可以按任务授权 / New **Apps & accounts** in Settings: connect GitHub (reuse your gh login or paste a token) with its permissions shown as they are; tools on local MCP servers can be granted per task

## 改进 / Improvements

- 对话里交给编程助手的后台任务现在就是持续任务：满了排队、临时出错重试一次、重启后接着做、可以停止，做完在任务页验收 / Background hand-offs to a coding assistant are now tasks: they queue when busy, retry once on a temporary error, continue after a restart, can be stopped, and finish in the tasks page for review
- Nomi 按你的意图判断要现在做还是派出去：一两步的直接做，要做一阵子的派到后台，你说「现在就要」就不派 / Nomi decides from what you ask whether to do it now or hand it off: quick things are done right away, longer jobs go to the background, and "I need it now" keeps it in the chat
- 侧栏「任务」显示运行中的任务数；任务页或素材库打开时点侧栏里的会话会直接回到对话 / The sidebar **Tasks** entry shows how many tasks are running, and clicking a conversation while the tasks page or asset library is open takes you straight back to the chat
- 命令自动审核先做确定性分类：读取凭据、合并发布这类命令总是问你，对外推送需要授权 / Command review now classifies commands first: reading credentials and merging or releasing always ask you, and pushing to outside services needs a grant
- 任务里的编程助手默认看不到你本机的 gh 登录，授权了 GitHub 对外动作才可以用 / Coding assistants inside tasks can't see your local gh login unless the task is granted GitHub actions
- 编程助手没装好、工作目录不在了、没有可用的模型时，任务停下来等你处理，处理好再继续，不悄悄换配置 / When a coding assistant is missing, the workspace is gone or no model is available, the task waits for you instead of switching settings silently
- 包含 2.0.10 的全部修复 / Includes every fix from 2.0.10

## 修复 / Fixes

- macOS 和 Linux 上，从访达 / 文件管理器把文件或图片拖进对话窗口能添加为附件了，拖动经过时输入框会高亮 / On macOS and Linux, dragging files or images from Finder / your file manager into the chat window now adds them as attachments, and the input box highlights while you drag
- 不同的 Nomi 会话可以同时回复：一个会话在回复时切到另一个会话，输入框照常可以发送，不再显示上一个会话的「发送中」，停止键只停当前会话 / Different Nomi chats can reply at the same time: while one chat is replying, another chat's input works normally instead of showing the first chat's sending state, and Stop only stops the chat you are looking at
- 停止回复后，这一轮里还在运行的工具调用显示为「已停止」，不再一直转圈（命令本身随停止一起结束） / After you stop a reply, tool calls that were still running in that turn show as stopped instead of spinning forever (the commands themselves end with the stop)
- 上一轮 Nomi 画的图，下一轮说「把它改一下」就能接着改：发给模型的历史里带上了这一轮生成的图片地址 / After Nomi draws an image, saying "change it" in the next message now works: the history sent to the model includes the links of images generated in each reply
- 你发出去的图片可以点开看原图、复制，也能「以此修改」「作为参考」交给 Nomi 改图（原图存进素材库「你发送的」）；生成图片的查看器也能复制图片 / Images you send can be opened full size, copied, and used with Edit this / Use as reference for image editing (the original is saved to the asset library under Sent by you); the viewer for generated images can copy them too
- 命令自动审核看的是要执行的完整命令，不再只看前 4000 个字符；超过审核上限的命令交给你确认（#222） / Command auto-review now sees the whole command it approves instead of only the first 4000 characters; commands over the review limit are sent to you to confirm (#222)
- 素材库记下完整的生图提示词（最多 4000 字），重新生成发的就是原来的全文，查看与复制也是全文（#225） / The asset library keeps the full image prompt (up to 4000 characters), so regenerate sends the original prompt and view / copy show all of it (#225)
- 重新生成时原图用的图片模型不可用（供应商停用或删除）会直接报错，不再悄悄改用当前图片模型（#224） / Regenerate now fails with a clear error when the original image model is unavailable (provider disabled or removed) instead of silently switching to the current image model (#224)
- 记忆去重不再把只差数字、编号或英文字母的事实当成同一条（如「项目 A 预算 10 万」和「项目 AB 预算 100 万」），重启后两条都保留（#223） / Memory de-duplication no longer merges facts that differ only by numbers, IDs or Latin letters (such as two projects with different budgets); both are kept after a restart (#223)
