# Nomi·诺米 2.1.0

持续任务版本：交代一次，Nomi 一直记着——按时间或事件推进，需要你的时候来找你。Go 版与 Electron 版同时提供（文件名以 `Nomi-Electron-` 开头的是 Electron 版）。 / The persistent tasks release: tell Nomi once and it keeps track, running on a schedule or on events and coming to you when it needs you. Go and Electron builds ship together (Electron files are named `Nomi-Electron-…`).

## 新功能 / New

- 侧栏新增「任务」：在对话里说「每天 9 点帮我……」或点「新建任务」，确认授权卡片（能做什么、多久到期、预算）后才创建；任务按时间运行，结果、要你批准的事、出错都集中在任务页 / New **Tasks** in the sidebar: say "every day at 9, …" in chat or choose New task; nothing is created until you confirm the authorization card (what it may do, when it expires, budget). Tasks run on schedule, and results, approvals and errors gather on the tasks page
- 任务可以交给 Nomi 自己做，也可以交给你装好的编程助手（Claude Code、Codex……）：编程助手在独立的工作副本里改代码，做完你验收后再回填到工作区 / A task can be done by Nomi itself or by a coding assistant you have installed (Claude Code, Codex, …); the assistant works in a separate worktree, and changes come back to your workspace only after you accept them
- 事件触发：网页或 RSS 有更新、GitHub 仓库的 issue / PR 或 CI 有动静、文件夹里有新文件、编程助手一轮结束、知识库更新、本机 MCP 工具有新结果；新建的事件任务先只记录，你决定「处理这些」或改成自动处理 / Event triggers: a web page or RSS feed changes, GitHub issues / PRs or CI change, new files land in a folder, a coding assistant finishes a turn, the knowledge base updates, or a local MCP tool returns new items; new event tasks only record what they find until you choose to handle them or switch to automatic
- 对外动作逐项授权：在 GitHub issue / PR 下评论、从 `nomi/` 分支开 PR、调用本机 MCP 服务器的工具；每个对外动作先记下意图，重启后不确定有没有发出去会先自动核对，查不了再请你确认 / Outside actions are granted one by one: comment on GitHub issues / PRs, open PRs from `nomi/` branches, call tools on your local MCP servers; each action is recorded before it runs, and after a restart Nomi checks whether it went out before asking you
- 看板视图：按进度或重要程度分列、按类型筛选；任务可以设重要程度和类型 / Board view: columns by progress or priority, filtered by type; tasks can have a priority and a type
- 设置新增「应用与账号」：连接 GitHub（复用本机 gh 登录或粘贴令牌），如实显示登录的权限范围；本机 MCP 服务器的工具可以按任务授权 / New **Apps & accounts** in Settings: connect GitHub (reuse your gh login or paste a token) with its permissions shown as they are; tools on local MCP servers can be granted per task

## 改进 / Improvements

- 对话里交给编程助手的后台任务现在就是持续任务：满了排队、临时出错重试一次、重启后接着做、可以停止，做完在任务页验收 / Background hand-offs to a coding assistant are now tasks: they queue when busy, retry once on a temporary error, continue after a restart, can be stopped, and finish in the tasks page for review
- 命令自动审核先做确定性分类：读取凭据、合并发布这类命令总是问你，对外推送需要授权 / Command review now classifies commands first: reading credentials and merging or releasing always ask you, and pushing to outside services needs a grant
- 任务里的编程助手默认看不到你本机的 gh 登录，授权了 GitHub 对外动作才可以用 / Coding assistants inside tasks can't see your local gh login unless the task is granted GitHub actions
- 编程助手没装好、工作目录不在了、没有可用的模型时，任务停下来等你处理，处理好再继续，不悄悄换配置 / When a coding assistant is missing, the workspace is gone or no model is available, the task waits for you instead of switching settings silently
- 包含 2.0.10 的全部修复 / Includes every fix from 2.0.10
