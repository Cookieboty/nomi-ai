# 诺米 2.0.5

## 修复 / Fixes

### 模型与供应商 / Models & providers

- 自定义供应商内联表单恢复可选「测试模型」输入：没有 `/models` 列表时也能用同一 ID 探测并保存（#161） / The custom-provider inline form again has an optional test-model field so endpoints without a `/models` list can probe and save with that ID (#161)
- 取消添加供应商时作废进行中的检测，迟到的 detect 结果不再写入（#162） / Cancelling add-provider invalidates in-flight detect so late results no longer upsert (#162)

### 侧栏 / Sidebar

- 折叠侧栏从菜单或快捷键重命名时先展开，再显示行内编辑器（#163） / Renaming from the collapsed sidebar (menu or shortcut) expands first so the inline editor is visible (#163)

### 隐私日志 / Privacy log

- 清空隐私日志与在途异步写串行，迟到的旧快照不会盖回空文件（#164） / Clearing the privacy log serializes with in-flight async writes so a late old snapshot cannot overwrite the empty file (#164)

### Windows 主线程 / Windows main thread (#154)

- 隐私日志 flush/clear、聊天背景启动落盘、模型目录同步改为异步原子写；退出仍等待未完成的保存 / Privacy-log flush/clear, chat-background startup persist, and models-catalog sync use async atomic writes; quit still waits for pending saves
- **尚未在真机 Windows 上验证** / **Not yet verified on real Windows hardware**
- 仍为同步原子写（Windows 占用时会 `Atomics.wait`）的路径：GatewayStore.save、AccountService 若干保存、homes.ts 账号目录、ExtensionsService.writeJson、ConfigService.saveSync（退出）、claudeStatusline 写 settings.json；首次收紧某目录 ACL 仍可能同步调用一次 icacls / Remaining sync atomic writes (may `Atomics.wait` under Windows file locks): GatewayStore.save, some AccountService saves, homes.ts account dirs, ExtensionsService.writeJson, ConfigService.saveSync (on quit), claudeStatusline settings.json; the first ACL tighten on a directory may still call icacls synchronously once

### 安装包体积 / Installer size

- 打包瘦身（低风险）：`asarUnpack` 不再在 `app.asar` 内保留 onnxruntime-web / tesseract 重复文件；`bare-*` native prebuilds 只保留当前平台与架构；zlibjs 去掉未使用的 `.dev` / `.pretty` / 分文件 `.min`；`@nomi-ai/i18n` 不打包 `src` 与 ESM `dist`（保留 `dist-cjs`）；`assets` 仅通过 `extraResources` 上盘，不再进 asar / Packaging slim (low risk): drop asarUnpack duplicates of onnxruntime-web / tesseract inside `app.asar`; keep only current-platform `bare-*` prebuilds; drop unused zlibjs bins; ship `@nomi-ai/i18n` `dist-cjs` only (no `src` / ESM `dist`); assets via `extraResources` only, not asar
- 未做按需加载 Rive / ort / tess / mp3（产品门控，延后） / No on-demand Rive / ort / tess / mp3 (product-gated, deferred)

### 自动更新 / Auto-update

- 沿用启动后静默检查与定期检查；更新下载完成后，工作台左下角「设置」旁与设置页左侧导航底部出现「重启更新」，一点即 `quitAndInstall`；无可用已下载更新时不显示 / Keeps launch + periodic auto-check; after an update finishes downloading, a **Restart to update** control appears next to Settings (workbench bottom-left) and at the bottom of the settings nav, calling `quitAndInstall`; hidden when nothing is ready to install
- 更新重启后展示「更新日志」弹层（日期、新增 / 优化 / 修复）；「更新后显示更新日志」可取消并持久化，设置里可重新打开 / After update restart, shows a What’s new panel (date, New / Improvements / Fixes); 「Show release notes after update」can be unchecked and persisted, re-enabled in Settings

### 角色包 / Character pack (#168)

- 官方仍为单角色 Nomi；提供 Scheme A（`character:init/check/apply` → `character.generated.json`）与 Scheme B（`userData` → `resources` → builtin overlay，`character-pack://` + IPC `get-active`）；无商店、无运行时多角色切换 / Official path stays single-character Nomi; Scheme A (`character:init/check/apply` → `character.generated.json`) and Scheme B (`userData` → `resources` → builtin overlay, `character-pack://` + IPC `get-active`); no store and no runtime multi-character switch
- Scheme B：UI 等 overlay 就绪后再读 mode / rive·static URL 并重渲；路径规范化拒绝 traversal / Scheme B waits for overlay readiness before reading mode / rive·static URLs; pack paths reject traversal
- `skirt`→`hem`；voice 稳定 clip id + 一版 legacy 别名 / `skirt`→`hem`; stable voice clip ids with one-release legacy aliases
- 新增 StaticCanvas（static 模式）；示例包 `examples/nomi.pack`、`examples/static-demo.pack`；CI 跑 `character:check` / Adds StaticCanvas (static mode); example packs `examples/nomi.pack`, `examples/static-demo.pack`; CI runs `character:check`
