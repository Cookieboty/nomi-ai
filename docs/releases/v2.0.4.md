# 诺米 2.0.4

## 修复 / Fixes

### 隐私与外发保护 / Privacy & outbound protection

- 文本附件不再被转成普通消息，仍受「仅本地」与首次云端发送确认约束（#149） / Text attachments no longer bypass local-only and first cloud-send confirmation (#149)
- 委派的完整 UI 结果写入历史后，下一轮不再绕过「仅本地发送」过滤（#117） / Archived delegate UI results no longer bypass the local-only filter on the next turn (#117)
- 切到云端备用协议时按实际协议脱敏，不再发送原文（#150） / Outbound protection redacts for the protocol actually used when falling back to a cloud provider (#150)
- 工具 arguments 里 JSON 转义过的自定义密钥也会被 mask / block（#151） / JSON-escaped custom secrets in tool arguments are now masked / blocked (#151)

### 委派与工作区 / Delegation & workspace

- 委派 worktree 回填遵守原目录的授权边界（#115） / Delegate worktree write-back respects the original folder's permission scope (#115)
- 委派 worktree 的 Git exclude 写入目标仓库，而不是应用目录（#139） / The delegate worktree Git exclude is written to the target repo, not the app folder (#139)
- `delegate_followup` 也受「最多同时运行 3 个委派」限制（#141） / `delegate_followup` now counts toward the 3-concurrent-delegates limit (#141)
- 放弃改动的晚到撤销记录绑定到对应工作区，不会把 A 的 stash 恢复到 B（#152） / Late discard-undo records are bound to their workspace and cannot restore A's stash into B (#152)
- 未跟踪目录不再被当作已跟踪文件，右栏「放弃改动」不再失败（#153） / Untracked folders are no longer treated as tracked files; discarding changes in the side panel works (#153)
- CLI 能力过滤不再隐藏 Nomi 插件面板的 Skills / MCP 目录（#143） / CLI capability filtering no longer hides the Skills / MCP folders in the Nomi plugin panel (#143)

### 界面与语音 / UI & voice

- 翻译词典不再读取继承属性，会话重命名为 `__proto__` 不再让聊天界面崩溃（#142） / The translation dictionary ignores inherited keys; renaming a chat to `__proto__` no longer breaks the chat UI (#142)
- 会话 memo 边界跟随语言切换，已有消息的操作文字立即更新（#140） / Session memo boundaries follow language changes; existing message actions update right away (#140)
- 英文 Windows 上删除官方账号可以进入强制删除二次确认（#137） / Deleting the official account on English Windows reaches the force-delete confirmation (#137)
- 按住说话打断后，迟到的同一回复分句不再重新开始朗读（#148） / After push-to-talk interrupts, late sentences from the same reply no longer restart read-aloud (#148)

### 模型与质量页 / Models & quality page

- 流式兜底提交时间不再被当作首内容，质量页 TTFT / 生成速率恢复准确（#136） / Streaming fallback commits are no longer counted as first content; TTFT / generation speed on the quality page are accurate again (#136)
- EffectiveModel 缓存命中也遵守学习结论有效期，过期的推理限制不再生效（#138） / EffectiveModel cache hits honour the learned-result expiry; expired reasoning limits no longer apply (#138)

### 更新与 Windows / Updates & Windows

- 检查更新时，若最新 Release 还没传完安装包，显示「新版本仍在发布中」而不是 404；发版流程改为先建草稿、三平台安装包和更新文件齐全后才自动发布（#146） / Update checks show "a new version is still being published" instead of a 404 while a Release is incomplete; releases are now drafted first and published only once all three platforms' installers and update files are attached (#146)
- 保存聊天背景改为异步写入，Windows 文件占用重试不再阻塞主线程（#154，部分） / Saving the chat background is now async, so Windows file-lock retries no longer block the main thread (#154, partial)

## 已知问题 / Known issues

- #154 仍未完全解决：配置、账号、网关等其它私有文件写入仍为同步，Windows 下 icacls 仍同步调用；尚未在真机 Windows 上验证 / #154 is only partly fixed: other private-file writes (config, account, gateway, …) are still synchronous and icacls still runs synchronously on Windows; not yet verified on real Windows
- v2.0.3 的 Release 没有附带安装包，2.0.3 用户检查更新可能失败，可手动下载 2.0.4 / The v2.0.3 Release has no installers attached; 2.0.3 users may see update checks fail and can download 2.0.4 manually
