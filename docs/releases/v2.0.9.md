# Nomi·诺米 2.0.9

2.0.8 之后的版本，Go 版与 Electron 版同时提供（文件名以 `Nomi-Electron-` 开头的是 Electron 版）。 / The release after 2.0.8; Go and Electron builds ship together (Electron files are named `Nomi-Electron-…`).

## 新功能 / New

- Nomi 对话可以画图：在「设置 → 模型」里给 Nomi 选一个图片模型，没选时按当前对话模型自动匹配同一家的图片模型（图片下面会注明「自动匹配」）；匹配不到时不会画图。图片直接显示在对话里，下面注明由哪个模型生成；支持改图与参考图生成。图片模型不再出现在对话和编程助手的模型选择里 / Nomi can draw: pick an image model for Nomi in Settings → Models, or leave it unset and Nomi matches an image model from the same vendor as the chat model (the image is marked "auto-matched"); if none matches, Nomi won't draw. Images appear in the chat with the model that made them, and can be edited or used as a reference. Image models no longer show up in the chat and coding-assistant model pickers
- 素材库：侧栏会话列表上方新增入口，整页浏览所有生成的图片（Nomi 画的、编程助手生成的），可按来源筛选；查看器里能看提示词、模型、尺寸与生成时间，可以重新生成、以此修改、作为参考、下载、在文件夹中显示和删除（移到废纸篓） / Asset library: a new entry above the chat list shows every generated image (from Nomi or coding assistants), filterable by source; the viewer shows prompt, model, size and time, and can regenerate, edit, use as reference, download, show in folder and delete (moved to the trash)
- 命令自动审核（设置 →「Nomi」→「权限」，默认开）：Nomi 跑命令前先让辅助模型按风险分低 / 中 / 高 / 极高；低风险直接执行，中风险在这一轮没读过外部内容时直接执行，高 / 极高风险、读过外部内容的中风险、审核出错或超时时交给你确认，卡片上写明风险等级与理由。**这改变了 2.0.8 的「每条命令都要确认」**：想回到每条都确认，关掉这个开关即可 / Command auto-review (Settings → Nomi → Permissions, on by default): before Nomi runs a command, the helper model rates it low / medium / high / critical; low runs right away, medium runs right away unless this turn has read external content, and high / critical, medium after external content, or a failed / timed-out review ask you, with the risk and reason on the card. **This changes 2.0.8's "confirm every command"**: turn the switch off to confirm every command again
- 设置新增「Nomi」分区：权限、委派、桌面权限集中在这里，和编程助手分开 / Settings has a new Nomi section that gathers permissions, delegation and desktop permissions, separate from the coding assistants
- Nomi 派给编程助手的子任务，点「查看」会在右侧抽屉里打开它的完整对话，运行中可以直接停止 / A subtask Nomi delegates to a coding assistant opens its full conversation in a side drawer via "View", and can be stopped there while running
- 输入栏的上下文环按实际路由到的模型窗口显示；模型菜单按供应商分标签、按厂商筛选与分组，模型名更短、右侧显示上下文长度 / The context ring follows the window of the model actually used; model menus have provider tabs, vendor filters and grouping, shorter names and the context size on each row

## 改进 / Improvements

- 闲聊时发给模型的工具定义从约 8.5K token 降到约 2K：提醒、浏览器、文件、生图等工具只在对话提到相关的事时才提供 / Tool definitions sent during small talk drop from ~8.5K to ~2K tokens: reminders, browser, files, image and other tools are offered only once the chat mentions them
- 用量按每次上游请求记账，多步工具调用不再只记最后一步 / Usage is recorded per upstream request, so multi-step tool turns are no longer counted as their last step only
- 长期记忆合并说法几乎一样的重复条目，对话里同一件事只引用一次 / Long-term memory merges near-duplicate facts and cites each one once per reply

## 修复 / Fixes

- Nomi 正在回复时切到别的会话再切回来，这一轮的内容和用时都还在；停止对话时进行中的生图也一起中止 / Switching away from a Nomi chat while it replies and back keeps the turn and its timer; stopping a chat also cancels an in-flight image
- Windows 上 Nomi 委派编程助手、跑命令时不再闪出黑色控制台窗口；macOS 上移到废纸篓不再弹「控制 Finder」授权 / On Windows, delegating and running commands no longer flash console windows; on macOS, moving to the trash no longer asks to control Finder
- 新手引导里填本机 / 局域网地址时，「允许访问吗？」确认框不再被引导页挡住 / During onboarding, the "allow this local / LAN address?" confirmation is no longer hidden behind the onboarding screen
- 被拒绝或被拦下的工具调用在时间线上显示为失败，不再打 ✓ / Tool calls you denied or that were blocked show as failed in the timeline instead of a check mark
- 素材库查看器里删除、下载、在文件夹中显示失败时会提示原因；日期按界面语言显示，模型显示供应商名称 / The image viewer explains failed delete / download / show-in-folder actions, shows dates in the interface language, and shows the provider name with the model

## 说明 / Notes

- 已安装 2.0.4 到 2.0.8 的用户在应用内检查更新即可升级到 Go 版 2.0.9 / Users on 2.0.4 through 2.0.8 update in-app to the Go build 2.0.9
