# Nomi·诺米 2.0.7

2.0.6 之后的修复版本，Go 版与 Electron 版同时提供（文件名以 `Nomi-Electron-` 开头的是 Electron 版）。 / A fix release after 2.0.6; Go and Electron builds ship together (Electron files are named `Nomi-Electron-…`).

## 修复 / Fixes

### 稳定性 / Stability

- Go 版关闭或重建窗口时，如果连接恰好同时断开，应用不会再有崩溃风险（#208） / In the Go build, closing or recreating a window while its connection drops no longer risks crashing the app (#208)

### 界面 / Interface

- 桌面角色工具栏和对话窗口顶栏的提示气泡不会再超出窗口 / Tooltips on the character toolbar and the chat header stay inside the window
- 部分颜色改为跟随主题：工具调用行悬停时变亮，上下文用量圆环使用警告 / 危险色 / Several colors now follow the theme: tool-call rows brighten on hover, and the context ring uses the warning / danger colors

### Windows（Go 版） / Windows (Go build)

- 安装器在关闭旧进程、移除旧版本、下载 WebView2 运行时时会显示当前步骤，进度条保持走动，不再像卡住；安装界面跟随系统语言显示中文或英文 / The installer shows the current step while closing the running app, removing the previous version and downloading the WebView2 runtime, and its progress bar keeps moving instead of looking frozen; the installer follows the system language (Chinese or English)

### Windows（Electron 版） / Windows (Electron build)

- 文件夹选择器挂在当前窗口上，刷新页面后不会再单独冒出来；选择期间关掉了标签，选择结果会被丢弃 / The folder picker is attached to the current window, so it no longer pops up on its own after a reload; if the tab is closed while the picker is open, the choice is discarded
- 启动、定时和手动检查更新同时触发时只检查一次，不会弹出重复的更新提示 / Startup, scheduled and manual update checks that overlap run once, so update notices are not duplicated
- 托盘菜单内容没有变化时不再重建，Windows 11 上不再闪烁 / The tray menu is rebuilt only when it changes, so it no longer flickers on Windows 11
- 切换分辨率或缩放比例后，桌面角色窗口会被拉回工作区内 / After a resolution or scaling change, the character window is moved back inside the work area
- 安装版会注册 `nomi://` 链接 / Installed builds register the `nomi://` link handler
- 安装版遇到未捕获的错误时会正常退出 / Installed builds quit cleanly on an uncaught error

## 说明 / Notes

- 已安装 2.0.4、2.0.5 或 2.0.6 的用户在应用内检查更新即可升级到 Go 版 2.0.7 / Users on 2.0.4, 2.0.5 or 2.0.6 update in-app to the Go build 2.0.7
- 发版时 CI 会校验 tag 与版本号一致（`v${version}`），并以本文件作为 Release 说明 / On release, CI checks the tag matches the version (`v${version}`) and uses this file as the Release notes
