# Nomi 1.0.3

> Release-notes body for the GitHub Release `v1.0.3` (English first, then 中文). Range: `v1.0.2..v1.0.3`.
> Release process: [docs/RELEASE.md](../RELEASE.md). The detailed per-change list lives in the root [CHANGELOG.md](../../CHANGELOG.md).

## Nomi 1.0.3

### Highlights

- **A new Nomi mascot.** The desktop character is now a full-body Rive character with layered clothing, arms and hands that move together (wave, hello, cheer, celebrate), facial expressions, blinking and lip-sync while she talks. If Rive cannot start on a machine (wasm or scene fails to load, or no ready signal within 20 s) Nomi automatically falls back to the layered 2D renderer.
- **Resizable mascot.** Zoom the mascot from about 30% to 150% (capped by your display): Ctrl/⌘ + scroll on the character, Ctrl/⌘ + `+` / `-` / `0`, the right-click menu, the toolbar More menu or the new **Settings → General → Mascot size** slider. Her feet stay where they are, the window stays on screen, and the size is remembered.
- **Slash commands everywhere.** Type `/` in any conversation (Nomi, Claude Code, Codex, Grok, dsh) for a grouped, fuzzy-searchable palette with argument hints. `/context`, `/cost`, `/status`, `/model`, `/help`, `/diff`, `/clear` and `/new` run locally and appear as cards in the conversation; project / user commands and Skills are passed through or expanded for the CLI; unknown or interactive-only commands only show a hint and are never sent to the model by accident (`//` sends a literal slash). A read-only **Plugins / commands** panel lists the commands, Skills, plugins, MCP servers and sub-agents found for the current endpoint (names only — credentials and MCP env values are never read).
- **One conversation view for everything.** Nomi chats and every coding agent now share the same Codex-Desktop-style view: compact tool rows, foldable groups ("Explored 3 files, 5 searches"), command output, coloured diffs, collapsible thinking with a timer, explicit waiting states (queued, waiting for permission, first token, retry, compaction, sub-agent), per-turn duration / tokens / cost, copy / regenerate / edit-and-resend / stop, an error card with retry, and a message queue while a turn is running. Each send is its own turn, and the connected CLI's own commands are listed first.
- **Grok Build as a coding-agent endpoint** next to Claude Code, Codex and dsh: detect / install / update, headless harness, its own provider store (the API key is injected only at launch), usage from its session logs, and a subscription quota card.
- **Per-tool quota cards and an endpoint info card.** Subscription quota is a grid of cards (Codex, Claude Code, Grok), each with its own Refresh button. In dev mode → By endpoint, a card at the bottom of the sidebar shows install state, sign-in method, plan and quota, today's usage and cost, models, running tabs and recent activity; open it for a detail drawer (7-day trend, per-model usage, CLI version and update check).

### Performance

- **Switching conversations is smooth again:** median switch latency **252 ms → 27 ms** with no long task (6 conversations × 400 messages); with a 4× CPU slowdown 816 ms → 103 ms.
- **Streaming replies are cheaper:** the live Markdown body is re-rendered at most every 66–320 ms and an unclosed code block is highlighted only once it closes — main-thread busy time **34.8% → 8.8%**, DOM update batches 537 → 206 on an 8000-character code block.
- **Lighter first paint:** the chat window's entry JS drops from **901 KB to 737 KB** (285 KB → 234 KB gzip) because the syntax highlighter loads on demand.
- **Idle coding-agent processes are reclaimed:** a Claude Code process idle for 30 minutes (`NOMI_HARNESS_IDLE_MS`, `0` turns it off) is stopped to free memory; the tab shows a hollow "dormant" dot and the next message resumes the session with `--resume`.
- Mascot idles at a lower frame rate and caches hot calculations; caches that grew for the life of the process are now bounded; history pagination is bounded and stale search results are ignored.

### Also new

- Markdown in conversations is rendered by an upgraded renderer (tables, task lists, code, local images through a safe `chat-asset://` protocol).
- Coding-assistant notifications can be read aloud (**Spoken summaries**: finish, failure, stalled, permission, periodic digest); off by default, bubble and sound stay either way.
- The composer grows with your text (up to 200 px), conversation and chrome fonts are a little larger, and the send / microphone / headset buttons stay on the toolbar row at narrow widths (the left-hand pickers shrink with an ellipsis, then collapse to icons).
- Default wake phrase is now **你好，诺米**.

### Fixes

- **Fork as new chat** now shows the copy in the sidebar immediately (before, it appeared only after another action).
- The mascot speech bubble shows Markdown replies as plain text (no raw `**`, backticks or `#`).
- The "No microphone found" voice message disappears by itself after a few seconds; the chat hands-free tooltip is no longer clipped at the window edge, and long mascot toolbar tooltips wrap inside the window.
- The biggest mascot size keeps a few pixels of slack to the screen's work area, so the window cannot end up 1 px taller than the display on Windows with fractional scaling.
- Imported / store-downloaded VRM characters load again (the `cdmodel://` scheme was overridden by a later registration).
- After the cursor leaves the mascot and stops, the window returns to click-through instead of staying clickable.
- Ctrl/⌘ + `+` / `-` / `0` zoom the mascot on every keyboard layout (including Shift+= and the numeric keypad); zooming no longer drifts the character's feet.
- On Windows, coding CLIs installed via npm (Codex, dsh) start correctly instead of failing as extensionless shims; switching provider no longer forces a restart prompt for idle Claude sessions, and activating dsh/Grok without a model is blocked.
- Stop button, process-tree kill and history scanning fixes across endpoints; Grok image session roots are compared by real path (macOS `/var` → `/private/var`); Grok subscription quota probing works on Windows.
- Model ids from Grok usage logs are read correctly; "Available models" leftovers were removed from settings.

### Behavior changes to be aware of

- **Rive is now the default mascot renderer.** The previous layered 2D character is only a fallback if Rive fails to start. The experimental Rive flag path and the half-body artboard were removed.
- **TTS no longer falls back to system speech.** If the local voice model fails, speech stays silent instead of switching to the OS voice. The character's speed setting is now passed to the local model.
- **Default wake phrase changed** from 你好小桌 to 你好，诺米 (only the default changed).
- **Settings menu (unchanged since 1.0.2, repeated here because it has no backward compatibility):** the 16 sections were merged into 13 (Knowledge & memory, Schedule & calendar, Privacy & permissions, Voice & screen …). The old section ids and deep-link aliases are gone; the sidebar no longer carries its own settings entry.

### Downloads

- Windows: `Nomi-Setup-1.0.3.exe`
- macOS: `Nomi-1.0.3.dmg` (Intel) · `Nomi-1.0.3-arm64.dmg` (Apple silicon)
- Linux: `Nomi-1.0.3.AppImage`

Installed copies update automatically (Settings → General → Updates).

## Nomi 1.0.3（中文）

### 亮点

- **全新的 Nomi 看板娘。** 桌面角色换成全身 Rive 角色：分层服装、手臂与手部协同运动（挥手、问好、欢呼、庆祝），有表情、眨眼，说话时口型同步。如果某台机器上 Rive 无法启动（wasm 或场景加载失败，或 20 秒内没有就绪），会自动回退到分层 2D 渲染器。
- **看板娘可调大小。** 约 30%–150%（受屏幕限制）：在角色上 Ctrl/⌘ + 滚轮、Ctrl/⌘ + `+` / `-` / `0`、右键菜单、工具栏「更多」菜单，或 **设置 → 通用 → 看板娘大小** 滑块。脚底位置不动，窗口始终在屏幕内，大小会被记住。
- **所有对话都支持斜杠命令。** 在任意对话（Nomi、Claude Code、Codex、Grok、dsh）输入 `/`，弹出分组、可模糊搜索、带参数提示的命令面板。`/context`、`/cost`、`/status`、`/model`、`/help`、`/diff`、`/clear`、`/new` 在本地执行并以卡片显示在对话里；项目 / 用户命令与 Skills 会透传或为 CLI 展开；未知或仅交互式可用的命令只提示、不会被误发给模型（`//` 发送字面斜杠）。只读的「插件 / 命令」面板列出当前端点发现的命令、Skills、插件、MCP 服务与子代理（只读名称，不读取凭据和 MCP 环境变量值）。
- **所有对话同一套视图。** Nomi 对话与每个编程助手共用 Codex Desktop 风格的对话视图：紧凑的工具行、可折叠分组（「浏览了 3 个文件、5 次搜索」）、命令输出、彩色 diff、带计时的可折叠思考、明确的等待状态（排队、等待权限、首个 token、重试、压缩、子代理）、每轮耗时 / Token / 费用、复制 / 重新生成 / 编辑重发 / 停止、带重试的错误卡片，以及生成中的消息队列。每次发送是独立的一轮，当前连接的 CLI 自带命令排在最前。
- **Grok Build 成为编程助手端点**，与 Claude Code、Codex、dsh 并列：检测 / 安装 / 更新、无头 harness、独立的供应商存储（API Key 只在启动时注入）、读取其会话日志统计用量，以及订阅额度卡片。
- **按工具的额度卡片与端点信息卡。** 订阅额度改为卡片网格（Codex、Claude Code、Grok），每张卡有自己的「刷新」按钮。开发模式 → 按端 时，侧栏左下角的信息卡显示安装状态、登录方式、套餐与额度、今日用量与费用、模型、运行中的标签与最近活动；点开是详情抽屉（近 7 天趋势、按模型用量、CLI 版本与检查更新）。

### 性能

- **切换会话重新变得流畅：** 切换延迟中位数 **252 ms → 27 ms**，无长任务（6 个会话 × 400 条消息）；4 倍 CPU 降速下 816 ms → 103 ms。
- **流式回复更省资源：** 实时 Markdown 正文最多每 66–320 ms 重渲染一次，未闭合的代码块在闭合后才高亮——8000 字符代码块下主线程忙碌 **34.8% → 8.8%**，DOM 更新批次 537 → 206。
- **首屏更轻：** 对话窗口入口 JS 从 **901 KB 降到 737 KB**（gzip 285 KB → 234 KB），语法高亮改为按需加载。
- **空闲编程助手进程自动回收：** 空闲 30 分钟的 Claude Code 进程（`NOMI_HARNESS_IDLE_MS` 可调，`0` 关闭）会被停止以释放内存；标签显示空心「休眠」圆点，下一条消息用 `--resume` 自动续接。
- 看板娘空闲时降频并缓存高频计算；原先随进程无限增长的缓存现在有上限；历史分页有界，过期的搜索结果会被忽略。

### 其他新增

- 对话中的 Markdown 由升级后的渲染器显示（表格、任务列表、代码、通过安全的 `chat-asset://` 协议显示本地图片）。
- 编程助手通知可朗读（**语音摘要**：完成、失败、卡住、请求权限、定时汇总）；默认关闭，气泡与提示音不受影响。
- 输入框随文字增高（最高 200 px），对话与界面字号略微加大，窄窗口下发送 / 麦克风 / 耳机按钮仍留在工具栏同一行（左侧选择器先省略号收缩，再折叠为图标）。
- 默认唤醒词改为 **你好，诺米**。

### 修复

- **「分叉为新对话」** 现在会立即在侧栏显示副本（以前要等下一次操作才出现）。
- 看板娘气泡把 Markdown 回复显示为纯文本（不再出现 `**`、反引号、`#`）。
- 「没有找到可用的麦克风」提示几秒后自动消失；对话窗口的免提按钮提示不再被窗口边缘裁切，看板娘工具栏的长提示在窗口内换行。
- 看板娘最大尺寸与屏幕工作区之间保留几像素余量，避免 Windows 分数缩放下窗口比屏幕高 1 px。
- 导入 / 商店下载的 VRM 角色可以重新加载（`cdmodel://` 协议曾被后注册的声明覆盖）。
- 光标移出看板娘并停住后，窗口会恢复点击穿透，而不是一直保持可点击。
- Ctrl/⌘ + `+` / `-` / `0` 在所有键盘布局下都能缩放看板娘（含 Shift+= 与小键盘）；缩放时角色脚底不再漂移。
- Windows 上通过 npm 安装的编程 CLI（Codex、dsh）可正常启动（不再把无扩展名 shim 当可执行文件）；切换供应商时不再对空闲 Claude 会话弹出重启提示；未填写模型时不能把 dsh/Grok 设为当前。
- 停止键、进程树清理与历史扫描的多端问题；Grok 生成图片的 session 根目录按真实路径比较（macOS `/var` → `/private/var`）；Windows 上 Grok 订阅额度探测恢复正常。
- 正确读取 Grok 用量日志中的模型 ID；清理了设置里遗留的「可用模型」模块。

### 需要留意的行为变化

- **Rive 现在是默认的看板娘渲染器。** 之前的分层 2D 角色仅在 Rive 启动失败时作为回退；实验性的 Rive 开关与半身画板已移除。
- **TTS 不再回退到系统语音。** 本地语音模型失败时保持静音，而不是改用系统声音；角色的语速设置会传给本地模型。
- **默认唤醒词由「你好小桌」改为「你好，诺米」**（仅默认值变化）。
- **设置菜单（自 1.0.2 起，在此重申：没有向后兼容）：** 16 个分区合并为 13 个（知识与记忆、日程与日历、隐私与权限、语音与屏幕……），旧的分区 id 和深链接别名已移除；侧栏不再带单独的设置入口。
