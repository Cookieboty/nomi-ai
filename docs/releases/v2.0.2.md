# 诺米 2.0.2

## 新功能 / Features

- 右栏「改动」可以直接提交、暂存、撤销 / Commit, stage and unstage right from the Changes panel
- 分支栏可以拉取（只快进）和推送（不会强推） / Pull (fast-forward only) and push (never force) from the branch bar
- 右栏「改动」可以切换 worktree / Switch between worktrees in the Changes panel
- AI 一键生成提交信息 / Generate commit messages with AI in one click
- 放弃未暂存的改动后可以撤销 / Discarding unstaged changes can be undone
- 外发内容保护：发往云端前自动隐藏密钥，回复里再还原 / Outbound protection: secrets are masked automatically before anything leaves your machine
- 全局背景图，可选内置图或自己的图片 / Global background image, built-in or your own
- 对话窗口可以拖入任意文件 / Drag any file into the chat

## 改进 / Improvements

- 背景图选图失败会提示，大图自动缩小并保留透明 / Clear message when an image can't be used; large images are downsized and keep transparency
- 底部提交区不再被裁掉 / The commit area at the bottom is no longer cut off

## 修复 / Fixes

- 复制按钮点了没反应的问题已修复 / Copy buttons work again
- git 操作更安全：不会误动仓库外的文件，凭据不会出现在日志里 / Safer git operations: files outside the repo are never touched and credentials never show up in logs
- 第一个未暂存的文件不再被误显示为已暂存 / The first unstaged file is no longer shown as staged
- 没配置 Nomi 模型时，生成提交信息改用当前标签的模型 / Commit message generation uses the current tab's model when no Nomi model is set
- 委派子任务在第一轮开始前点「停止」不再被忽略 / Stopping a delegated task before its first turn starts now works
- Windows 上更换对话背景图更稳定，不再出现背景不生效或设置保存失败 / Changing the chat background on Windows is more reliable: no more backgrounds that fail to apply or settings that fail to save
