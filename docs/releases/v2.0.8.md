# Nomi·诺米 2.0.8

2.0.7 之后的版本，Go 版与 Electron 版同时提供（文件名以 `Nomi-Electron-` 开头的是 Electron 版）。 / The release after 2.0.7; Go and Electron builds ship together (Electron files are named `Nomi-Electron-…`).

## 新功能 / New

- 桌面角色的 Rive 动画改为按需下载：安装包不再自带约 16 MB 的动画素材，默认显示静态立绘；在设置里打开动画时才下载，设置页显示下载进度，失败可以重试，下载过一次后离线也能用 / The desktop character's Rive animation is now downloaded on demand: installers no longer carry the ~16 MB animation file and the still image shows by default; turning the animation on in Settings downloads it with progress shown there, a failed download can be retried, and once downloaded it works offline
- 安装包不再带 2D 分层立绘：Rive 动画无法启动时直接回到静态立绘 / Installers no longer carry the 2D layered sprite: if the Rive animation cannot start, the still image is shown

- Codex 和 Grok 标签页支持上下文压缩：命令行工具自己压缩时标签页会显示「正在压缩上下文」，完成后上下文用量随之归零；在这两种标签页里输入 `/compact` 会让命令行工具真正压缩当前会话 / Codex and Grok tabs support context compaction: when the CLI compacts on its own the tab shows it and the context meter resets afterwards, and `/compact` in these tabs asks the CLI to compact the current session

## 修复 / Fixes

### 更新日志 / What's new

- 更新后弹出的「更新日志」显示当前版本的内容，不再一直是 2.0.5；说明随版本发布，看过一次后离线也能打开 / The What's new panel shows the notes of the version you are running instead of the 2.0.5 notes; they ship with each release and stay available offline once viewed

### Windows

- 设置或状态文件被杀毒软件、索引程序短暂占用时，保存不再让应用卡住最多 2 秒，改为在后台重试（#154） / When antivirus or the indexer briefly locks a settings or state file, saving no longer freezes the app for up to 2 seconds; the save retries in the background (#154)
- 覆盖安装和应用内更新更快：不再先跑一遍旧版本的卸载器，没有运行中的 Nomi 时不再额外等待 / Reinstalling and in-app updates are faster: the previous version's uninstaller no longer runs first, and there is no extra wait when Nomi isn't running
- 已经装有 WebView2 运行时的电脑，安装时不会再去重新下载 / Installing on a PC that already has the WebView2 runtime no longer downloads it again

### 稳定性 / Stability

- 托盘菜单里有两个同名模型（比如两个供应商下的同一个模型）时，在设置里切换模型后，点托盘菜单不会再选错模型（#212） / With two recent models of the same name (for example the same model under two providers), switching models in Settings no longer makes the tray menu pick the wrong one (#212)
- Go 版连接 MCP 服务器时取消，不会再在后台留下一个没人管的连接（#213） / In the Go build, cancelling an MCP server connection while it is connecting no longer leaves an orphaned connection running in the background (#213)

## 说明 / Notes

- 已安装 2.0.4 到 2.0.7 的用户在应用内检查更新即可升级到 Go 版 2.0.8 / Users on 2.0.4 through 2.0.7 update in-app to the Go build 2.0.8
