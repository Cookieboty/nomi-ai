# 诺米 2.0.0

## 新功能 / New features

- 委派编程助手：诺米可把开发、文档、审查、调研交给本机 Claude Code、Codex、Grok、Gemini、dsh 或你添加的外部助手；对话里有进度、审批与停止，完成后整理汇报 / Coding-agent handoff: Nomi can send development, docs, review and research to Claude Code, Codex, Grok, Gemini, dsh or an external agent you add; progress, approval and stop live in chat, with a clear report when done
- Agent Profile：委派时可选用默认 / 省钱 / 本地等档位，少花钱也能把活干完 / Agent Profiles: hand off with default / cheap / local tiers so you can spend less and still finish the work
- 外部 CLI：在设置里用命令与参数模板接入任意说 ACP 的编程助手 / External CLI: connect any ACP-speaking coding agent with a command and args template in Settings
- 模型质量面板：按模型、供应商与 Key 对比成功率、延迟与断流，支持并排与导出 / Model quality panel: compare success rate, latency and drops by model, provider and key — side-by-side and exportable
- Nomi 自己的权限模式（计划 / 逐项确认 / 自动改文件等），敏感与破坏性操作仍会请你确认 / Nomi’s own permission modes (plan / confirm each / auto-edit, and more); sensitive and destructive actions still ask you
- 代码沙箱更硬：在支持的系统上隔离运行，改文件更安心 / Harder code sandbox on supported systems, so file changes feel safer

## 改进 / Improvements

- 「模型」页统一网关体验加深：辅助模型、每 Key 并发、回退与分配更稳，对话与编程助手共用一套配置 / Deeper unified Models page: helper models, per-key concurrency, fallbacks and assignments shared by chat and coding agents
- 官方账号一账号一配置目录，多账号可并行用在不同标签 / Official accounts get one config folder each; use several accounts in parallel tabs
- 斜杠命令 /agent 可指定编程助手名；委派默认异步，仓库内可用隔离工作区并行 / Slash /agent can name a coding agent; handoff is async by default, with isolated workspaces in git repos

## 修复 / Fixes

- 模型路由与上游异常时更稳的降级与提示，减少「卡住不知道怎么了」 / Clearer fallbacks and prompts when model routing or upstream fails, so you are less often stuck with no signal
- 编程助手会话、权限切换与自动更新失败提示更清楚，可重试 / Clearer errors (and retry) for coding-agent sessions, permission switches and auto-update failures
- 依赖升级：undici 7.30.1、electron 44.9.3，修复 TLS / 根证书相关漏洞 / Dependency upgrades: undici 7.30.1 and electron 44.9.3 for TLS / root-certificate fixes
