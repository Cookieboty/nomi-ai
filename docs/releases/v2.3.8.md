# Nomi·诺米 2.3.8

工作区改为「项目」：一个项目可以放多个文件夹，跨端工程的前端、后端、文档放在一起；分叉合成一个弹窗，每条回复末尾都能从这里分叉。 / Workspaces become projects: one project can hold several folders, so a product's frontend, backend and docs live together; forking is one dialog, and every reply can be forked from.

## 新功能 / New

- 项目可以包含多个文件夹：其中一个是主文件夹（工作目录、git 和 AGENTS.md 以它为准），其余文件夹 Nomi 和编程助手同样能读写 / A project can hold several folders: one is the primary folder (the working directory; git and AGENTS.md come from it), and Nomi and coding agents can read and write the others too
- 侧栏「项目」标题上的按钮打开「创建项目」，不再直接开对话；项目上的「…」可以改名、增删文件夹、换主文件夹或移除项目（只移除记录，不删文件） / The button on the sidebar's Projects header opens "Create project" instead of starting a chat; a project's "…" menu renames it, adds or removes folders, changes the primary folder, or removes the project (only the entry, never your files)
- 新会话、新建菜单和分叉都可以选项目；改了项目的文件夹，已有会话下一轮起就按新的文件夹工作 / New chats, the new-chat menu and forks let you pick a project; when a project's folders change, existing chats use the new folders from their next turn
- 右栏「改动」按 git 仓库分段，每段有自己的分支、暂存和提交；「文件」每个文件夹一个节点；输入框里 `@` 引用路径覆盖所有文件夹 / In the side panel, Changes shows one section per git repository with its own branch, staging and commit; Files shows one node per folder; `@` paths in the input cover every folder
- 分叉合成一个弹窗：分叉到新会话或其他端、带入几轮上下文、放进哪个项目都在一处选 / Forking is one dialog: a new session or another endpoint, how many turns to carry and which project, all in one place
- 每条回复末尾新增「从这里分叉」：只带到这条回复为止，之后的消息不带，原会话不受影响 / Each reply has "Fork from here": it carries messages up to that reply only and leaves later ones out; the original chat is unchanged

## 变化 / Changes

- 升级后第一次启动时，以前用过的每个工作目录各建成一个项目，会话照旧归在里面 / On the first launch after updating, each working directory you used before becomes a project, with its chats still in it
- 分叉可选的轮数去掉了「最近 1 轮」 / The fork turn choices no longer include "last 1 turn"
- 会话列表出现滚动条时内容不再左右跳动 / The chat list no longer shifts sideways when its scrollbar appears
