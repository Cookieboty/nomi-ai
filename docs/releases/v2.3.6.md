# Nomi·诺米 2.3.6

灵动岛修复：「打开」能跳到对应的地方，`Esc` 随时收起。 / Dynamic Island fixes: Open takes you to the right place, and `Esc` hides it at any time.

## 修复 / Fixes

- 灵动岛上点「打开」或点某一条，会把对话窗口提到最前并跳到它：任务到任务详情，编程助手的请求到它的标签，Nomi 的确认到主对话；之前对话窗口开着时看起来没反应 / Clicking Open or an item on the Dynamic Island brings the chat window to the front and jumps to it: tasks open their details, coding agent requests open their tab, and Nomi's confirmations open the main chat; before, it seemed to do nothing when the chat window was already open
- 灵动岛可以随时关掉：按 `Esc` 或点关闭按钮收起；等你处理的事没有被处理，有新的一条进来时再一起显示 / The Dynamic Island can be closed at any time with `Esc` or the close button; pending items stay pending and show again when a new one arrives
- 灵动岛上的按钮点了没有结果时会恢复可点，不再一直灰着 / Buttons on the Dynamic Island become clickable again when nothing happens, instead of staying greyed out
