# 诺米 1.2.0

## 新功能 / New features

- 三栏工作台：会话 | 对话 | 改动·文件，右栏默认收起，宽屏 Diff 左右对比 / Three-pane workspace: sessions | chat | changes·files, with the right pane collapsed by default and side-by-side diffs on wide screens
- 全屏审查：在铺满窗口的视图中审阅改动，Esc 只关闭全屏层 / Fullscreen review: review changes in a full-window view; Esc closes only the fullscreen layer
- 输入框旁新增上下文用量环，实时显示当前窗口占用，分项明细可展开 / Context-usage ring next to the composer shows live window usage, with a per-item breakdown
- 思考深度新增 max / ultra 档位（Codex） / Reasoning effort adds max and ultra levels (Codex)
- 编程助手（Claude Code / Codex / Grok 等）支持发送图片，并按当前模型能力提示是否可附图 / Coding agents (Claude Code / Codex / Grok …) accept image attachments, with a hint when the current model cannot take images
- 「改动」按已暂存 / 未暂存分组显示 Git 改动，可一键让助手按规范提交（确认后才发送） / Git changes are grouped as staged / unstaged, and one click asks the assistant to commit (sent only after you confirm)
- Markdown 文件可编辑或预览，撤销与丢弃只还原你改过的片段 / Markdown files can be edited or previewed; undo and discard only revert the hunks you edited
- 界面模式「精简 / 全量」，可在设置和新手引导中选择 / UI mode Lite / Full, selectable in Settings and onboarding
- 主界面记住关闭前的位置与大小 / The main window remembers its position and size

## 改进 / Improvements

- 应用图标恢复 Nomi 品牌 N 双色（橙色次笔画） / App icon restored to the two-tone Nomi N with the orange second stroke
- 侧栏与顶栏改版：端点一行筛选、应用入口移到侧栏底部；工作目录移到顶栏 / Sidebar and top bar redesigned: one-row endpoint filter, app entries moved to the sidebar bottom, working directory in the top bar
- 聊天背景铺满整个工作台，左 / 中 / 右三栏可分别设置模糊 / Chat background fills the whole workspace, with separate blur for the left, middle and right panes
- 可拖动调整并记住对话栏宽度；右栏文件树列出全部文件（仅隐藏依赖与缓存目录） / Draggable chat column width is remembered; the file tree lists all files (only dependency and cache folders are hidden)
- 流式输出和 Diff 滚动更流畅，减少动效时自动停掉动画 / Smoother streaming and diff scrolling; animations pause when reduced motion is on
- macOS 窗口外观跟随所选主题，失焦时红绿灯不再消失 / macOS window chrome follows the chosen theme, and the traffic lights no longer vanish when unfocused

## 修复 / Fixes

- Windows 下拖动桌面 Nomi 卡顿 / Windows desktop Nomi drag stutter
- Windows 下 `.cmd` / `.CMD` 命令（如 dsh.cmd）的查找现在返回磁盘上的真实文件名，与 `where` 一致 / Windows command lookup for `.cmd` / `.CMD` tools (e.g. dsh.cmd) now returns the real on-disk file name, matching `where`
- 上下文用量环在压缩或重启后不再停在旧值，窗口大小不会低于已用量 / The context ring no longer sticks to an old value after compaction or restart, and the window size is never below usage
- 自动更新下载卡住后可以重试，失败会区分检查 / 下载 / 安装阶段 / Auto-update can be retried after a stalled download, and failures say whether checking, downloading or installing failed
- 窗口窄于约 1240px 时不再横向溢出 / The layout no longer overflows horizontally on windows narrower than about 1240px
- 上游响应卡住不再无限等待（含非流式与思考模型） / A stalled upstream response no longer hangs forever, including non-streaming and reasoning models
- 工作区文件读写 / 删除拒绝通过符号链接越出目录；文件名含空格的 Git 路径显示正确 / Workspace file read / write / delete rejects symlink escapes; Git paths containing spaces display correctly
