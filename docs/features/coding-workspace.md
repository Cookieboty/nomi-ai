# 编程助手工作台（v1.2.0）

![三栏工作区](../screenshots/v1.2.0-workspace.webp)

> 截图由 mock CLI 驱动真实界面生成，对话内容与路径仅作演示。

在对话窗口切到「工作台」，用 Claude Code / Codex / Grok / Gemini / dsh 写代码时的界面是左中右三栏：

- **左**：会话列表（侧栏底部是设置、知识 · 记忆 · 日程、扩展）。
- **中**：对话；点「查看变更」后，Diff 和文件预览也在中栏打开。
- **右**：「改动 · 文件」，默认收起，顶栏开关上显示改动数。

对话与右栏之间、Diff 与文件树之间的分割线都可以拖动，位置会被记住，双击复位。打开右栏时对话列默认更宽。

## 改动 · 文件

- 工作目录是 git 仓库时，「改动」以 git 状态为准，分「已暂存 / 未暂存」两组；助手本会话改过的文件带标记，可只看「本会话」。分支名显示在右栏顶部。
- 「文件」列出整个工作目录（不截断）：依赖目录（`node_modules` 等）和缓存目录（`.next`、`.turbo`、`.cache` 等）会跳过，被 `.gitignore` 忽略的文件照常列出并置灰，变更文件带标注。
- 「让助手提交 / 提交并推送」只把提交指令填进输入框，**由你确认后再发送**；Nomi 的 Git 面板本身是只读的。
- 读写、删除工作目录里的文件时，会拒绝通过符号链接指向目录外的路径。

## Diff、预览与全屏审查

- Diff 宽度 ≥ 900px 时左右并排，头部可切回单列，选择会被记住。
- 文件预览可以直接编辑并保存；Markdown 文件多一个「预览」模式（渲染未保存的草稿），在 Diff / 编辑 / 预览之间切换不会丢失草稿。
- 「全屏审查」把全部改动文件依次排开，旁边是文件树。

## 本轮改动摘要卡

![本轮改动摘要卡](../screenshots/v1.2.0-turn-edit.webp)

助手每轮改了文件，消息下出现「已编辑 N 个文件」（路径 +/−）：不超过 3 个文件时，可在卡内展开行级 Diff；更多文件用列表卡。卡片上有「查看变更」「全屏审查」和「撤销」——撤销会先让你确认，再撤销这一轮的写入。

## 上下文环

输入栏旁的环形指示默认只显示环；悬停显示「当前上下文 xK / 最大」。用量取这一轮**最后一次**模型请求的输入 + 输出（Claude Code、Codex、Grok、Gemini、dsh 与 Nomi 各按实测口径），不再把整轮累计当成当前上下文；窗口大小优先用 CLI 上报的值（例如 Claude 的 1M）。`/context` 使用同一口径。

## 附图

粘贴或拖入图片发给 Claude Code、Codex、Grok、Gemini；能否附图按当前模型的能力判断，不支持时会提示。dsh 明确拒绝附图。设计见 [多模态附图、上下文占用与 Git 面板](../design/v1.2.0-multimodal-context-changes-git.md)。

## 思考深度

可选档位：minimal / low / medium / high / xhigh / max；Codex 另有 **ultra**，与 max 是两个独立档位（ultra 原样传给 Codex CLI，由 Codex 自己处理）。

## 其他

- **切换会话**：都在侧栏里切换（v2.0.4 起没有顶部对话标签条），见 [个性化](personalization.md#侧栏与顶栏)。
- **并发**：多个会话可以同时运行，没有全局并发上限；在跑的会话在侧栏行里显示「进行中」。
- **工作目录与默认来源**：工作目录在对话头部；「新标签默认」的官方账号 / 第三方来源在侧栏信息卡里设置。
- **聊天背景**：铺满整个工作台，左侧栏、对话区、右侧面板的模糊程度分别可调。
