# 个性化

## 主题

设置 → 通用 → 主题：**日落橙**（默认）、**暖墨**、**石墨**、**奶油**、**冷雾**、**图片主题**，或「跟随系统」（深色用石墨、浅色用奶油）。对话窗口、设置、引导和标题栏一起切换。

## 侧栏与顶栏

会话只在左侧侧栏里切换（v2.0.4 起移除了工作台顶部的对话标签条和「精简 / 全量」界面模式）。当前会话在侧栏里高亮，对话区顶部不再重复显示标题；侧栏里正在跑或排队的会话，时间位置换成「进行中」/「排队中」。

收起 / 展开侧栏的按钮固定在窗口标题栏红绿灯旁（`Ctrl/⌘+B` 或点侧栏左上角的 Nomi 标志也可以）。侧栏收起后是一列端点图标方块，每个对话一个：右上角是状态点，当前对话高亮；鼠标悬停或键盘聚焦时立刻弹出卡片，显示完整标题、端点、时间与状态，点一下切过去；超过 30 个时用「+N」展开侧栏看全部。

## 图片主题

选择「图片主题」后，主题色卡下才显示图片选择、「毛玻璃」「透明度」；不再提供独立的「聊天背景」或纯色背景切换。图片位于窗口最底层，覆盖对话、侧栏、右侧面板、设置和功能弹窗；图片上方的第二底层蒙版提供全局毛玻璃，调整时不会缩放或改变图片取景，文字与控件保持清晰，欢迎区域不再额外模糊。图片主题使用石墨配色，原生标题栏也使用深色外观。

图片主题会缓存已选图片，重启后恢复图片与自定义参数，即使原文件已移动或删除也不需要重选。预设与用户图片独立保存，用户选图优先、即时覆盖预设；换图不会重置自定义毛玻璃和透明度。默认毛玻璃为 8px、透明度为 40%；「恢复默认」恢复预设与这两个默认值，不会退出图片主题。已有自定义参数（包括 0px）保持不变。新手引导里选择图片主题也能调整图片和参数。

「Nomi 图片预设」为项目内的月夜村庄图片 `packages/electron/assets/backgrounds/nomi-preset.jpg`，随安装包的 assets 资源分发；开发态从项目资源读取，打包后从应用 resources 读取，不依赖用户电脑目录或旧版 `chat/presets`。用户缓存丢失时恢复内置预设并保留自定义参数；应用预设资源缺失时安全回退为空背景，不加载外部地址。素材按用户确认的免费素材登记，具体来源与许可证尚未提供，许可状态见 `CREDITS.md`。

图片主题下，用户消息、工具展开详情、选中标签页、底部输入框和文件列表与左侧栏使用同色深的半透明底色；其他主题保留原有底色。侧栏的收起 / 展开见上文「侧栏与顶栏」。

Markdown 的代码块、行内代码、表头及图片占位也使用侧栏同色深的半透明底色，代码块标题和正文不重复叠加背景。语法高亮、复制代码、表格滚动和图片预览保持不变；复制按钮悬停使用透明蒙版及平滑颜色过渡。

本地模型卡片，以及 MCP 卡片与预设也使用半透明面板底色；设置导航、主题卡片和文件栏筛选控件悬停使用透明蒙版与平滑颜色过渡，避免不透明灰底。其他主题保留原配色，系统「减少动态效果」会禁用这些过渡。

模型与供应商配置、帮助说明、分区标签、知识与记忆、语音资源、用量与质量分析，以及共享输入框、下拉框和次按钮也适配半透明背景。下拉菜单和提示使用更深的透明浮层，保持文字可读；状态色、主题缩略图和语法高亮保持原样。

图片主题的顶部底色与左侧栏同色深；顶栏底边、文件栏边框与拖动分隔线使用同一半透明边框。分隔线只绘制一条细线，不重复叠加边框，拖动区域与双击重置功能保持不变。

图片主题的上下文用量提示框使用侧栏同色系的 92% 深色半透明底色，箭头与提示框同色。中央弹窗、全屏变更审查和引导卡片使用 94% 深色半透明底色，配合原有遮罩降低底层会话文字干扰，不增加局部模糊；设置内嵌面板与侧抽屉仍保留原有背景规则。

工具调用条不显示底色和边框，悬停只让文字颜色以 200ms 平滑变化，不改变背景，保留执行状态色和键盘焦点。图片主题的标签页及品牌按钮悬停时使用深色透明蒙版，背景与文字颜色平滑过渡。开启系统「减少动态效果」时取消这类过渡。

旧版分栏模糊设置升级后优先沿用对话区的值；缺少该值时依次沿用左侧栏、右侧面板的值。已有全局模糊值保持不变。

## 应用图标

设置 → 应用图标：**墨色**（默认）、**奶油**、**日落橙**。窗口、任务栏和托盘图标即时更新；安装包、可执行文件和开始菜单 / Finder 里的静态图标保持默认。图标素材见 [品牌规范](../BRAND.md)。

## 快捷键

设置 → 通用 →「快捷键」标签列出全部快捷键：点「修改」后按下新的组合键（需包含 `Ctrl/⌘` 或 `Alt`，或使用 F1–F12），冲突时会提示；`Esc` 取消。

| 默认             | 作用             |
| ---------------- | ---------------- |
| `Ctrl/⌘+K`       | 命令面板         |
| `Ctrl/⌘+N`       | 新对话           |
| `Ctrl/⌘+L`       | 聚焦输入框       |
| `Ctrl/⌘+F`       | 搜索对话（侧栏） |
| `Ctrl/⌘+,`       | 打开设置         |
| `Ctrl/⌘+B`       | 收起 / 展开侧栏  |
| `Ctrl/⌘+Shift+K` | 知识库问答开关   |
| `Ctrl/⌘+Shift+H` | 免按键对话开关   |
| `Ctrl/⌘+Shift+M` | 知识与记忆       |
| `Ctrl/⌘+Shift+E` | 扩展 / MCP       |
| `Ctrl/⌘+Shift+J` | 本机模型         |

`Ctrl/⌘+Shift+M`（以及侧栏底部同名图标）打开设置 →「知识与记忆」，标签切换 知识库 / 长期记忆 / 日程；`Ctrl/⌘+Shift+J` 打开设置 →「模型与供应商」→「本机模型」。

固定快捷键：输入框里 `/` 打开命令，`Enter` 发送、`Shift+Enter` 换行，按住 `F2` 说话。

## 无障碍

- 所有功能都可以用键盘完成；图标按钮都有可读的名称。
- 弹窗会锁定焦点，`Esc` 只关闭最上层，关闭后焦点回到打开它的位置。
- 开启系统的「减少动态效果」后，Nomi 的摆动幅度、灵动岛与界面动画都会收敛。
