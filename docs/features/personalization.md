# 个性化

主题与应用图标在「设置 → 通用 → 通用 → 外观」。

## 主题

可选：**浅色**（新用户默认）、**深色**、**日落橙**、**暖墨**、**石墨**、**奶油**、**冷雾**、**跟随系统**（系统深色用深色，浅色用浅色），以及**图片主题**。对话窗口、设置、引导和标题栏一起切换，已经选过主题的用户保持原来的选择。

### 图片主题

选「图片主题」后，主题色卡下出现图片选择、「毛玻璃」和「蒙版不透明度」：

- 清晰底图按窗口尺寸铺满，对话、侧栏、右侧面板、设置和弹窗共用同一背景；「毛玻璃」调节上方全局蒙版的背景采样模糊，不放大或直接模糊原图，文字与控件保持清晰。
- 「蒙版不透明度」只调节蒙版，不改变图片本身：数值越大蒙版越实、图片越不明显；毛玻璃为 `0px` 时不做模糊。主题色卡同步预览蒙版效果。
- 默认用内置的预设图片（`apps/desktop-go/assets/backgrounds/nomi-preset.jpg`），可以换成自己的图片。所选图片会缓存，原文件移动或删除后重启也能恢复；换图不会重置毛玻璃和透明度。
- 默认毛玻璃为 `0px`、蒙版不透明度为 `50%`；「恢复默认」恢复预设图片与这组参数，不会退出图片主题。
- 图片主题使用石墨配色；委派卡片、任务与素材库面板同样使用透明表面。

## 应用图标

「外观」里的「应用图标」：**日落橙**（默认）、**奶油**、**墨色**。窗口、任务栏 / Dock 和托盘图标即时更新；安装包、可执行文件和 Finder / 开始菜单里的静态图标保持默认的墨色。macOS 菜单栏托盘始终是单色模板图标。图标素材见 [品牌规范](../BRAND.md)。

## 侧栏

- 侧栏左边是固定的导航栏：最上面的 Nomi 标志收起 / 展开会话面板，下面是「对话」「任务」「素材库」；工坊模式下，分隔线下面竖排全部端点（「全部」、Nomi 与各编程助手），点一下只看这个端点的会话；最底部是知识 / 扩展入口，设置在最下面。「侧栏显示的端点」可以选择显示哪些端点、拖动调整顺序。
- 会话面板顶部的「Nomi 灵伴 ⌄」/「Nomi 工坊 ⌄」切换两种模式：灵伴主打聊天、知识问答、记忆与日常事务；工坊是 Nomi 调度 AI 能力完成任务（Claude Code、Codex、多模型、项目管理与代码修改）。右边的放大镜（或 `Ctrl/⌘+F`）打开搜索窗：没输入时是「新对话」和最近对话，输入后搜索对话与本机历史；底部标签可以切到「对话」「任务」「素材库」，点任务 / 素材直接打开对应页面。
- 「工作区」标题右侧是「…」（整理侧栏：按工作区分组 / 合并显示）和「+」（新建对话）；「本机历史」标题右侧是刷新。
- 窗口整体是 Codex 式三层：导航栏和标题栏在窗口底色上；会话面板（浅灰）和对话区（白色，含中栏、右栏、任务与素材库）拼成一张圆角卡片，中间一条细线分开；收起会话面板后对话区自己是一张完整的圆角卡片。标题栏左侧的侧栏按钮图标随收起 / 展开变化；卡片上方显示当前会话名与工作区（新会话不显示），右侧是会话菜单「…」（重命名、分叉、归档、关闭标签、永久删除）和改动 · 文件栏开关。
- 会话只在侧栏里切换，当前会话用浅色圆角底高亮；行首不画端点图标，标题都左对齐；工坊模式的「全部」里，编程助手的会话在行尾有一个灰色小图标标出端点（Nomi 是默认，不标），切到某个端后不再标；悬停卡片里有完整的端点名，Nomi 委派出去的会话写明「由 Nomi 委派给 X」；行上不显示时间，正在跑或排队的会话显示「进行中」/「排队中」。悬停或键盘聚焦一行时右侧弹出小卡片：标题、端点、多久前、状态与工作区；点卡片里的标题可以直接改名（Enter 保存、Esc 取消）。行尾是「置顶」「归档」和「更多」：置顶的会话放在最上面的「置顶」里。工作区与「最近」默认显示 5 / 20 条，每点一次「展开显示」多显示 5 条，全部显示后变成「收起」。
- `Ctrl/⌘+B` 或标题栏旁的按钮收起 / 展开会话面板。收起后只剩导航栏；鼠标移到「对话」或端点图标上，会话面板以浮层弹出，可以直接选，移开或按 `Esc` 收起。
- 行尾的归档按钮把 Nomi 对话归档：不再在侧栏显示，可以在「设置 → Nomi → 已归档的对话」里取消归档或永久删除。「更多」菜单里还有「永久删除」，删除前会再确认一次、不能恢复。编程助手标签的行内按钮是「关闭标签」。
- 会话按工作区分组：Nomi 对话按会话的工作区、编程助手标签按标签目录归到同一个文件夹，按最近活动排序。每个工作区默认显示最近 5 条，其余点「展开显示」；点文件夹名折叠 / 展开（会记住），悬停时文件夹右侧的「新建」在该工作区里开新会话（工坊「全部」视图沿用该工作区最近一个会话的端点，「按端」跟随筛选的端点）。没有工作区的会话列在「最近」里；「工作区」「最近」「本机历史」的分区标题（灰色小字加「>」）点一下可以收起整个分区，「工作区」「最近」会记住；列表标题旁的文件夹树按钮可以关闭分组，回到平铺列表。

## 快捷键

「设置 → 通用 → 快捷键」列出全部快捷键：点「修改」后按下新的组合键（需要包含 `Ctrl/⌘` 或 `Alt`，或使用 F1–F12），冲突时会提示；`Esc` 取消。

| 默认             | 作用                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| `Ctrl/⌘+K`       | 命令面板                                                                                         |
| `Ctrl/⌘+N`       | 新对话                                                                                           |
| `Ctrl/⌘+F`       | 搜索对话                                                                                         |
| `Ctrl/⌘+L`       | 聚焦输入框                                                                                       |
| `Ctrl/⌘+,`       | 打开设置                                                                                         |
| `Ctrl/⌘+B`       | 收起 / 展开侧栏                                                                                  |
| `Ctrl/⌘+Shift+K` | 知识库问答开关                                                                                   |
| `Ctrl/⌘+Shift+H` | 免按键对话开关                                                                                   |
| `Ctrl/⌘+Shift+M` | 知识 · 记忆 · 日程抽屉                                                                           |
| `Ctrl/⌘+Shift+E` | 扩展 / MCP                                                                                       |
| `Ctrl/⌘+Shift+J` | 本机模型（设置 → 模型与供应商 → 本机模型）                                                       |
| `Ctrl/⌘+T`       | 新建编程助手标签                                                                                 |
| `Ctrl/⌘+Shift+W` | 关闭标签                                                                                         |
| `Ctrl+Tab`       | 下一个标签                                                                                       |
| `Ctrl+Shift+Tab` | 上一个标签                                                                                       |
| `Ctrl/⌘+Shift+R` | 重命名标签                                                                                       |
| `Ctrl/⌘+Shift+C` | 在终端打开当前会话的项目目录（编程助手标签的目录或 Nomi 对话选的工作区；目录按工作区规则再校验） |

固定快捷键（不能改）：输入框里 `/` 打开命令；`Enter` 发送、`Shift+Enter` 换行；输入框为空时 `↑` 找回上一条提问；按住 `F2` 说话；`Ctrl/⌘+Shift+F` 把当前对话分叉为新对话；`Ctrl/⌘+1…9` 切换到第 n 个标签（9 = 最后一个）；`Esc` 关闭弹窗或菜单。

## 无障碍

- 所有功能都可以用键盘完成；图标按钮都有可读的名称。
- 弹窗会锁定焦点，`Esc` 只关闭最上层，关闭后焦点回到打开它的位置。
- 开启系统的「减少动态效果」后，诺米的动作、灵动岛与界面动画都会收敛。
