# 长期记忆

入口：对话窗口顶栏「知识 · 记忆 · 日程」抽屉（`Ctrl/⌘+Shift+M`）的「长期记忆」标签，或设置 → 知识与记忆 → 长期记忆。

## Nomi 记得什么

- **对话记忆**：关闭对话窗口、新建对话或聊了一段时间后，Nomi 会把这次对话整理成「标题 + 摘要 + 关键词」，并记下你明确表达过的长期信息（身份、偏好、目标、不喜欢的事、习惯）。密码、密钥、证件号等敏感内容会被过滤。
- **关于我**：这些长期信息的列表，可增删改。
- **用户档案**：一份你自己写的 Markdown（称呼、偏好、背景……），每次对话都会参考。
- 你说「记住……」时，Nomi 会直接记下来。

## 自然地想起

每次提问前，Nomi 会找出相关的记忆一起作为背景，回答气泡上会显示「🧠 参考了 N 条记忆」。

## 管理

记忆面板里可以搜索、编辑、置顶、删除每一条记忆，调整开关与回忆条数，导出为 JSON / Markdown，或一键清除全部。手动改过的条目不会被自动覆盖。

## 技术说明

- 数据保存在 `userData/memory/`（`memory.json`、`settings.json`、`persona.md`），不上传。
- 召回为 BM25 + 可选向量（复用知识库的向量服务配置，受同样的云端同意与仅本地限制）。
- 工具：`memory_search`、`memory_remember`。所有写入都记入本地审计日志。
