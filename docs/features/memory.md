# 长期记忆

入口：「设置 → 知识与记忆 → 长期记忆」；侧栏底部「知识 · 记忆 · 日程」图标或 `Ctrl/⌘+Shift+M` 从右侧抽屉打开同样的标签页。

## Nomi 记得什么

- **对话记忆**：关闭窗口、新建对话或每 10 条消息时，Nomi 会把对话整理成一条「标题 + 摘要 + 关键词」；也可以点「整理当前对话」。整理用当前对话模型。
- **关于我**：整理时自动提取你明确说过的长期信息（称呼、偏好、目标……），可以增删改；也可以直接对 Nomi 说「记住……」。密码、密钥、证件号等敏感内容会被过滤。
- **用户档案**：一份你自己写的 Markdown（称呼、工作、习惯、希望助手怎样回答），每次对话都会参考；保存在 `persona.md`，可以用任何编辑器修改。
- **回复偏好画像**：按规则提取的回复偏好（语言 / 风格 / 语气），可以重置。

## 自然地想起

每次提问前，Nomi 会找出相关的记忆一起作为背景，回答里会标出参考了几条记忆。「每次最多回忆」的条数可以调。开启知识库的向量检索后，回忆会更准确。

只重合一两个泛词（「当前」「什么」）的不算相关：至少要覆盖问题里约四分之一的词才会想起，过往对话的摘要每条最多带 160 字。同一个对话里已经带过的记忆会一直留在上下文里，不会重复带；对话被压缩时，带过的记忆跟着摘要保留，不会丢。修改用户档案后，下一句会带上新版本。

## 管理

- 搜索（按 `/` 聚焦）、编辑、置顶（召回时优先）、忘记每一条记忆；手动改过的条目不会被自动摘要覆盖。
- 忘记是真的忘记：删掉一段对话摘要时，从它整理出的「关于我」条目一起删掉；之后再整理这段对话只看删除之后的新消息，删掉过的条目也不会被重新整理回来。你自己再写一条同样的内容则以你为准。清空全部记忆同理。
- 「设置与导出」里可以关掉长期记忆或自动整理，导出为 JSON / Markdown，或清除全部记忆（包括对话记忆和「关于我」，无法撤销）。
- 长期记忆关闭后不再整理新对话，回答时也不参考记忆；已有记忆保留。

## 实现

- 数据保存在 `userData/memory/`（`memory.json`、`settings.json`、`persona.md`），不上传。
- 召回为 BM25 + 可选向量（复用知识库「向量与重排」的服务配置，受同样的云端同意与「仅本地」限制）。
- AI 工具：`memory_search`、`memory_remember`；写入记入本地审计日志。
- 内核：`apps/desktop-go/internal/core/memory`；视图：`packages/ai-chat/src/components/MemoryPanel`。
