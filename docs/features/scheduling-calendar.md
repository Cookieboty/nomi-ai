# 日程

入口：设置 → 知识与记忆 →「日程」标签（侧栏底部「知识 · 记忆 · 日程」图标或 `Ctrl/⌘+Shift+M` 打开知识与记忆）。提醒、定时任务、主动聊天、免打扰都在同一个面板里。

v2.0.4 起移除了日历同步（系统日历、本地日历、`.ics` 导入导出、日历订阅、CalDAV 和 AI 工具 `calendar_list`），原来的「日程与日历」设置分区并入了「知识与记忆」。

## 提醒

- 一次性或重复：每天、工作日、每周几、每月、每隔 N 分钟。
- 也可以直接在对话里说：「每个工作日早上 9 点提醒我站会」。
- 到点时 Nomi 挥手，气泡里出现提醒卡片（好的 / 稍后）。Nomi 关着时改用灵动岛或系统通知，见下方「提醒怎么送到你面前」。
- 应用关闭期间错过的提醒，下次启动时补上。

## 定时任务

给出名称、指令、时间和重复规则，到点由当前对话模型生成内容，按下方规则提示你，同时总会写进对话窗口。内置模板「每日简报」会结合今天的提醒和你的长期记忆。12 小时内错过的任务会在启动后补跑一次；也可以「立即运行」。

## 主动聊天（默认关闭）

开启后，Nomi 会按你选择的频率（每天最多 1 / 3 / 6 次）在活跃时段偶尔搭话。你刚聊过天、电脑空闲（不在电脑前）或处于免打扰时段时不会开口。「现在试一下」可手动触发。

## 免打扰

在「免打扰」标签里设置免打扰时段（可跨午夜）。期间什么都不弹出：到点的提醒会先攒着，结束时一起提醒（Nomi 关着时合成一条通知）；定时任务照常运行，结果只写进对话窗口。

## 提醒怎么送到你面前

提醒、定时任务结果、主动聊天、编程助手进度和用量预算提醒都按同一个规则，每条只出现在一个地方：

- **Nomi 在桌面上**：只用她的气泡（提醒是提醒卡片），不再弹灵动岛或系统通知。
- **Nomi 关着或隐藏**：用 [灵动岛](dynamic-island.md)；灵动岛关闭、不支持或没开这一类时，改发系统通知（点击打开对话窗口）。
- **免打扰时段**：什么都不弹。

原来的「同时发系统通知」开关已移除。

## 技术说明

- 数据保存在本机 `userData/desktop/reminders.json`、`userData/schedule/`。
