# 日程与日历

入口：对话窗口顶栏「知识 · 记忆 · 日程」抽屉（`Ctrl/⌘+Shift+M`）的「日程」标签，或设置 → 日程与日历 → 日程提醒；标签页：提醒、定时任务、主动聊天、免打扰。日历在设置 → 日程与日历 → 日历接入。

## 提醒

- 一次性或重复：每天、工作日、每周几、每月、每隔 N 分钟。
- 也可以直接在对话里说：「每个工作日早上 9 点提醒我站会」。
- 到点时 Nomi 挥手，气泡里出现提醒卡片（好的 / 稍后），可选同时发系统通知。
- 应用关闭期间错过的提醒，下次启动时补上。

## 定时任务

给出名称、指令、时间和重复规则，到点由当前对话模型生成内容，送到 Nomi 的气泡、系统通知和对话窗口。内置模板「每日简报」会结合今天的日程、提醒和你的长期记忆。12 小时内错过的任务会在启动后补跑一次；也可以「立即运行」。

## 主动聊天（默认关闭）

开启后，Nomi 会按你选择的频率（每天最多 1 / 3 / 6 次）在活跃时段偶尔搭话。你刚聊过天、电脑空闲（不在电脑前）或处于免打扰时段时不会开口。「现在试一下」可手动触发。

## 免打扰

设置免打扰时段（可跨午夜）。期间到点的提醒会先攒着，结束时一起提醒；定时任务照常运行，结果只写进对话窗口。

## 日历

- **系统日历**（设置 → 日程与日历 → 日历接入 →「连接系统日历」）：
  - macOS：读写「日历」App 中的所有账户（首次会请求「自动化」授权）。
  - Windows：经典版 Outlook 的默认日历（读写）。
  - Linux：Evolution / GNOME 本地日历（只读）。
- **其他来源**：本地日历、导入 `.ics` 文件、订阅日历链接（每 30 分钟同步）、CalDAV。
- 日程会进入每日简报，AI 也能通过只读工具 `calendar_list` 查看；写入系统日历前会弹出确认。可「导出 .ics」。

## 技术说明

- 数据保存在本机 `userData/desktop/reminders.json`、`userData/schedule/`、`userData/local/`；CalDAV 密码用系统安全存储加密，导出时不包含。
- 重复日程（RRULE 的 DAILY / WEEKLY / MONTHLY / YEARLY 及 EXDATE）会被展开；macOS 脚本查询不展开系统日历里的重复日程。
