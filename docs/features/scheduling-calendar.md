# 日程与任务

## 日程

入口：「设置 → 知识与记忆 → 日程」；侧栏底部「知识 · 记忆 · 日程」图标或 `Ctrl/⌘+Shift+M` 从右侧抽屉打开同样的标签页。提醒、定时任务、主动聊天、免打扰都在这里。

### 提醒

- 一次性或重复：不重复、每天、工作日、每周几、每月、每隔 N 分钟；也有「5 分钟后」「明天这时」等快捷时间。
- 也可以直接在对话里说：「每个工作日早上 9 点提醒我站会」。
- 到点时诺米挥手，气泡里出现提醒卡片（好的 / 推迟 10 分钟）。诺米不在桌面时改用灵动岛或系统通知，见下文「提醒怎么送到你面前」。
- 应用关闭期间错过的提醒，下次启动时补上。

### 定时任务

给出名称、指令、时间和重复规则，到点用当前对话模型生成内容，结果写进对话窗口，并按下文的规则提醒你。内置模板「每日简报」会结合今天的提醒和你的长期记忆。12 小时内错过的任务会在启动后补跑一次；也可以「立即运行」。

### 主动聊天（默认关闭）

开启后，Nomi 会在你空闲时偶尔主动搭话（结合长期记忆里的话题），频率可选偶尔（每天最多 1 次）/ 适中（3 次）/ 常常（6 次），也可以限定只在某个时段。你刚聊过天、不在电脑前或处于免打扰时段时不会开口。「现在试一下」可以手动触发。

### 免打扰

设置免打扰时段（可以跨午夜，如 22:30–08:00）。期间什么都不弹出：到点的提醒先攒着，结束后一起告诉你；定时任务照常运行，结果只写进对话窗口。

### 提醒怎么送到你面前

提醒、定时任务结果、主动聊天、编程助手进度和用量预算提醒，每条只出现在一个地方：

- **诺米在桌面上**：只用她的气泡（提醒是提醒卡片）。
- **诺米关着或隐藏**：用 [灵动岛](dynamic-island.md)；灵动岛关闭、平台不支持或没开这一类来源时，改发系统通知（点击打开对话窗口）。
- **免打扰时段**：什么都不弹。

## 任务

侧栏会话列表上方的「任务」入口：交代一次，Nomi 一直记着，按时间或事件推进，需要你的时候来找你。角标显示有几件事需要你处理。

- **新建**：在对话里说「每天 9 点帮我……」，或点「新建任务」填表：任务目标、何时运行（一次、每天、工作日、每隔几分钟、手动运行，或「有新动静时」）、谁来做（Nomi、某个编程助手，或只发通知）、能用哪些能力。创建前会弹出授权卡片，写明目标、能力、授权文件夹、期限和预算，确认后才创建。
- **事件触发**：可以看网页 / RSS、GitHub 仓库（issue 与 PR 动态、CI 跑完）、本机 MCP 服务器的只读工具，或应用内事件（编程助手一轮结束、知识库有更新）。新建的事件任务先只记录发现的事，要不要自动处理在任务详情里再打开。
- **能力等级**：只能发通知 → 只读（文件、网页、本机记录）→ 本机写入（知识库、记忆、授权文件夹里的文件）→ 可以跑命令（仍经命令审核）→ 可以做对外的动作（如在 GitHub 上评论、从 `nomi/` 分支开 PR，逐项授权，从不合并）。读写文件只限授权的文件夹。交给编程助手的任务还可以勾选「编程助手沙箱里预先允许」的类别（如云账号凭据），跑的时候不用再问；有 GitHub 对外动作时自动带上 SSH 与 Git 凭据（推代码要用），见 [编程助手](coding-agents.md#本机保护)。
- **编程助手执行**：默认直接在代码目录里改；同一个仓库里并行的任务改到同一个文件时，重要程度高的先改。只有指定基于另一个分支做时才在独立的 git worktree 里做，验收时落地：改动少拷回工作区，改动多提交到新分支 `nomi/…` 由你决定是否合并。同一种任务会接着用上一次的会话。
- **预算与期限**：默认每次最多 20 万 token、30 分钟，每天最多 1 美元，用完会停下来问你；授权有期限，到期前可以续期。
- **处理**：列表按「需要你 / 运行中 / 等触发 / 已结束」分组，也可以切到看板（按进度或重要程度分列）。点一行在右侧看详情：批准、补充信息、验收通过或退回、暂停、取消、撤销授权，以及执行历史和事件日志。应用关闭时正在做的对外动作，重启后会先自动核对，核对不了再请你确认。
- 原来的提醒与定时任务也作为两个分组出现在列表里（只读，点开进日程）。

### 应用与账号

「设置 → 应用与账号」管理任务能用的外部账号，目前是 GitHub：可以直接用本机 `gh` 的登录，或粘贴令牌（只看指定仓库时，只读的细粒度令牌就够）。凭据留在原处（`gh` 或系统安全存储），任务只能按自己的授权使用；删除连接后，用到它的任务会停下来等你重新授权。

## 实现

- 提醒：`apps/desktop-go/internal/core/desktop/reminders`（`userData/desktop/reminders.json`）；定时任务、主动聊天、免打扰：`internal/core/schedule`（`userData/schedule/`）。
- 任务：`apps/desktop-go/internal/core/tasks`（`userData/tasks/`），事件源 `tasks/event_*.go`；连接：`internal/core/connections`。
- 视图：`packages/ai-chat/src/components/SchedulePanel`、`Tasks`、`ConnectionsPanel`。
