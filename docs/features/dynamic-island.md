# 灵动岛通知

诺米不在桌面时，Nomi 的通知会以「灵动岛」样式出现在屏幕顶部中央：在带刘海的 Mac 上从刘海处展开，在其他屏幕上显示为顶部居中的胶囊。点一下打开对话窗口。

设置：「设置 → 通用 → 通知 / 灵动岛」。

- **启用灵动岛通知**：macOS 上默认开；Windows / Linux 上是可选的顶部胶囊，默认关。关闭后，诺米不在桌面时改用系统通知。
- **通知类型**，可分别开关：AI 主动消息（主动搭话、每日简报等）、编程助手进度（完成、需要确认或出错时）、日程提醒（到点的提醒与定时任务结果）。
- **始终用顶部胶囊**：不贴刘海，在屏幕顶部居中显示。
- 「预览一条通知」可以先看看效果。

## 通知走哪里

提醒、定时任务结果、主动聊天、编程助手进度和用量预算提醒，每条只出现在一个地方：

- **诺米在桌面上**：只用她的气泡（提醒是提醒卡片），不弹灵动岛，也不发系统通知。
- **诺米关着或隐藏**：用灵动岛；灵动岛关闭、平台不支持或没开这一类来源时，改发系统通知（点击打开对话窗口）。
- **免打扰时段**（「设置 → 知识与记忆 → 日程 → 免打扰」）：什么都不弹，提醒攒到结束时再送。macOS 的专注模式没有公开接口，无法自动感知。
- 编程助手「还有 N 个任务进行中」的定时汇总不会退回成系统通知；定时任务的结果总会写进对话窗口。

## 样式

- **带刘海的 Mac**：岛的上沿贴着屏幕最上沿，与刘海无缝衔接，只有下方是圆角；图标和状态点放在刘海左右两侧，标题和正文紧贴刘海下沿。刘海版始终是黑色。
- **没有刘海的屏幕 / 强制胶囊**：悬浮胶囊，四角圆角、轻微投影，颜色跟随系统深浅色。
- 窗口高度由内容决定，没有正文时更矮。
- 状态点：运行中蓝、完成绿、失败红、需要处理琥珀。
- 展开 / 收起约 0.34 秒，没有回弹；系统开启「减少动态效果」时没有过渡。
- 不抢焦点，在所有桌面空间可见；内容只以纯文本渲染。

## 实现

- `apps/desktop-go/internal/core/island`：通知路由 `notify.go`、版式参数 `geometry.go`（纯函数，有单测）、页面模板 `islandpage_tpl.go`；窗口在 `internal/shell/wailsshell`。
- 是否有刘海按「内建屏 + 菜单栏高度」推断，判断不准时退回胶囊样式。调试：`CD_ISLAND_SIMULATE_NOTCH=1` 可以在任意平台模拟刘海。
