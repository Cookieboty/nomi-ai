# 灵动岛通知（macOS）

在 macOS 上，Nomi 关着时，她的通知会以「灵动岛」样式出现在屏幕顶部中央：在带刘海的屏幕上从刘海处展开，在其他屏幕上显示为顶部浮动胶囊。

设置：设置 → 通用 →「通知 / 灵动岛」标签。

- **来源**：AI 主动消息、编程助手进度、日程提醒，可分别开关。
- 点击灵动岛打开对话窗口。
- 可强制使用胶囊样式。
- **Windows / Linux**：可选开启顶部胶囊（默认关闭）。

## 通知走哪里（v2.0.4）

提醒、定时任务结果、主动聊天、编程助手进度和用量预算提醒，每条只出现在一个地方：

- **Nomi 在桌面上**：只用她的气泡（提醒是提醒卡片），不弹灵动岛，也不发系统通知。
- **Nomi 关着或隐藏**：用灵动岛；灵动岛关闭、平台不支持或没开这一类来源时，改发系统通知（点击打开对话窗口）。两者不会同时出现。
- **免打扰时段**（设置 → 知识与记忆 → 日程 → 免打扰）：什么都不弹；提醒攒到结束时再送。
- 编程助手「还有 N 个任务进行中」的定时汇总不会退回成系统通知。
- 定时任务的结果仍然总会写进对话窗口。

## 版式（紧凑、窗口高度 = 内容高度）

- **带刘海的 Mac**：岛上沿贴屏幕最上沿，与刘海无缝衔接，只有下方是大圆角。图标和状态点放进「刘海带」里刘海的左右两侧（避开中间被刘海挡住的部分），标题和正文紧贴刘海带下沿（间距 4px，下边距 12px）。顶部预留的高度就是真实菜单栏（刘海）高度，不是固定大值。
- **没有刘海的 Mac / 外接屏 / 强制胶囊**：悬浮胶囊，四角圆角、轻微投影，距菜单栏 / 工作区顶部 5px；内容在胶囊里垂直居中，上下内边距各 11px；顶部不预留任何空白。
- **窗口高度由内容决定**：页面先量出内容行高度，主进程再把窗口设成「岛高度（胶囊再加 18px 投影留白）」，窗口里没有空黑。没有正文时更矮。
- **状态点缀**：运行中蓝、完成绿、失败红、需要处理琥珀；消息 / 编程助手 / 提醒各有默认强调色。图标块与右侧星标用强调色，运行中的星标轻微呼吸。
- **深浅色**：胶囊跟随系统外观（深色桌面深色胶囊，浅色桌面浅色胶囊）；刘海版始终是黑色以与刘海一致。
- **动画**：约 0.34s 的平滑展开 / 收起，没有回弹；系统开启「减少动态效果」时无过渡。
- 点击穿透 / 不抢焦点 / 多显示器 / 全屏行为不变（`focusable: false`、面板窗口、`visibleOnFullScreen`，且保留 `skipTransformProcessType`，不会再弄丢菜单栏图标）。

## 技术说明

- 实现：`packages/electron/src/island/`。窗口透明、无边框、不抢焦点，层级高于菜单栏，在所有桌面空间可见；内容只以纯文本渲染。
- 是否有刘海按「内建屏 + 菜单栏高度」推断，判断不准时退回胶囊样式。macOS 的专注模式没有公开接口，无法自动感知。
- 调试：`CD_ISLAND_SIMULATE_NOTCH=1` 可在任意平台模拟刘海。
- 岛窗口使用独立的内存会话（`partition: 'nomi-island'`）：默认会话上的统一 CSP 响应头（`script-src 'self'`）会拦掉这个 `data:` 页面的内联脚本，岛就只剩一个不会展开的黑块；页面自带更严的 meta CSP（`default-src 'none'`）。
- 版式参数（内边距、间距、投影留白、最小 / 最大内容高度）都在 `island/geometry.ts`，纯函数有单测（`tests/unit/island/island.test.ts`）；真实窗口高度与内边距由 e2e `E21` 校验。
