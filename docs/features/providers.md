# 第三方供应商与模型

入口：「设置 → 模型与供应商 → 第三方供应商」。Nomi 对话和用第三方模型的编程助手都经本机的统一网关访问第三方供应商，协议由网关自动转换。

## 切换模型

对话区的**模型选择器**（按供应商分组，显示推理 / 视觉 / 上下文长度）、托盘的「对话模型」菜单和 `/model` 改的是同一个分配，下一次请求立即生效。

## 添加第三方供应商

不用选协议：

1. **选来源**：搜索预设（模型厂商、中转平台、本机服务，如 DeepSeek、Kimi、智谱 GLM、通义千问、MiniMax、OpenRouter、Ollama、LM Studio），或「自定义地址」。
2. **填凭据**：可以一次粘贴多个 Key（每行一个，第一个是主 Key，其余按顺序作为备用）。自定义地址贴根地址、`/v1` 或完整的 `/v1/chat/completions` 都可以。服务不提供模型列表时，填一个测试用的模型。
3. **检测并保存**：Nomi 同时检测 Anthropic Messages、OpenAI Responses、Chat Completions、Gemini 四种协议，逐条显示结果和失败原因，至少一种可用才能保存。拉到的模型默认启用预设推荐的那些，不能对话的模型（向量、语音等）列出来但不启用。

本机或局域网地址（Ollama、自建服务）要先确认才会访问：本机服务预设自动确认，自定义地址会询问。

## 从网页添加

支持 Nomi 链接的第三方供应商可以直接从它的网页添加：

- **一键导入**：在它的网页上点「添加到 Nomi」（`nomi://provider/import` 链接），Nomi 弹出确认框，显示名称、各协议地址、打码后的 Key 和模型数，点「添加」才保存。
- **网页授权**：点它网页上的「连接 Nomi」（`nomi://provider/connect`），或在「第三方供应商」页点「网页授权」填它的网址。确认后浏览器打开它的授权页，登录同意后回到 Nomi 再确认一次；Key 由 Nomi 直接向第三方供应商换取，不出现在链接里。

链接只能带 https 公网地址；已有地址相同的第三方供应商时确认后更新它，不会新建；等待确认的链接最多 5 条，10 分钟过期。只添加你信任的第三方供应商：经它发出的请求会带上你的对话内容。接入方式见 [第三方供应商链接接入](../integrations/provider-link.md)。

## 分配

「分配」里设各处用哪个模型：

- **Nomi**：对话、工具调用、摘要（后两项默认「跟随对话」）、图片生成（默认「自动」，按对话模型挑同一家的图片模型）。
- **编程助手**：每个 CLI 选「第三方」时默认用的模型，以及辅助模型（起标题、写摘要等，不设就跟主模型一样）；Claude Code 还可以展开「各档模型」分别设 Opus / Sonnet / Haiku / Fable 档和子代理模型（Haiku 档用于后台任务）。

## 多 Key、重连与回退

每个供应商可以有一个主 Key 和多个备用 Key，界面只显示掩码。

- 上游临时出错（408、429、5xx、超时、连接失败）时先在同一个 Key 上退避重试（0.5 秒起，最长 8 秒；上游给了等待时间就按它），每个 Key 最多 3 次，只有一个 Key 时最多 5 次；还不行就换下一个 Key。Key 无效（401 / 403）直接换 Key。
- 同一家累计失败 10 次，换到也提供**同一个模型**的下一家供应商。不会换成别的模型；哪家都没有这个模型就报错。本机 / 局域网的供应商失败时只会换到其它本机 / 局域网供应商，不会把请求发到云端。
- 已经开始输出回复之后不再重试，避免一个回复由两次请求拼成。
- 供应商列表可以拖动排序（键盘：手柄上按 `Alt+↑/↓`），排在前面的优先；每行的开关可以直接停用 / 启用。

## 编辑供应商

点一行打开详情：

- **Key**：调整顺序（就是回退顺序）、停用、改名、删除、追加；每个 Key 显示最近一次错误，恢复后自动消失。
- **模型**：勾选启用，手动添加模型 id，「刷新」重新拉取（新模型默认不启用）；可以搜索、筛选，「全部启用 / 全部停用」只作用于当前筛出来的模型。
- **高级**：各协议的地址（留空即关闭）、给某个模型或 Key 限定协议、模型映射、自定义请求头和 User-Agent、清除自动学到的状态；每个 Key 可以设并发上限和每分钟请求数（超出时排队）。请求体上限默认 32 MiB，可调 1–256 MiB。
- **按哪个已知模型处理**：给模型选一个已知模型（like）后，能力与用量计价都按它算。配了模型映射（公开名 → 发给上游的名字）时，
  用量里记的是实际发给上游的名字，计价仍按公开名设的 like；几个公开名映射到同一个上游名而 like 不一致时，不猜，按未定价统计。

## 模型参数自动适配

网关按内置的模型目录（来自 models.dev）和模型族规则，把请求调整成上游模型能接受的样子：思考深度超出档位时降到最近一档，不支持的采样参数、`max_tokens` 写法、推理内容回传按模型处理，不支持图片的模型把图片换成一行说明；上游明确拒绝某个参数时换一种写法重试一次并记住结论。每次修正都在「用量与分析 → 请求明细」里记一条备注。

**严格模式**（「第三方供应商」页「显示协议」旁的开关，默认关）：打开后模型不支持的参数直接报错，适合排查参数为什么没生效。

## 编程助手用第三方模型

- 每个编程助手标签在对话区右上角选「官方账号」或「第三方」，只影响这一个标签，见 [编程助手](coding-agents.md#官方账号与第三方供应商)。
- 第三方只作用于 Nomi 启动的那个 CLI 进程，不写任何 CLI 的全局配置，也不碰官方凭据；会话历史照常写进各 CLI 自己的目录。
- 启动第三方会话时 Nomi 会告诉 CLI 模型的真实上下文窗口和输出上限，避免过早压缩或超长报错。
- 第三方标签换回官方账号时，第三方的推理内容不能发给官方接口，会用带上下文的新会话继续，原会话保留。
- 每个第三方标签的 CLI 进程用自己的一次性令牌访问网关（只在这个进程的环境变量里，网关只存哈希），进程退出或标签关闭后立即作废；官方标签从不带令牌。
  MiniMax Code 的自定义供应商只认写在配置里的密钥，所以它的令牌写在这个标签私有的配置文件里（只有你能读，权限 600），同样随标签作废。

## 终端启动命令

「第三方供应商」页底部的开关（默认关）。打开后在 `~/.nomi/bin/` 生成 `nomi-claude`、`nomi-codex`、`nomi-gemini`、`nomi-grok`、`nomi-dsh`：在终端里运行它们就用「分配」里给这个 CLI 的第三方模型，`--nomi-model 供应商/模型` 可以临时换模型；直接运行 `claude`、`codex` 仍是官方登录。需要 Nomi 在运行。Kimi Code、MiniMax Code 暂时没有终端启动命令。加入 PATH 前会先确认，只在 shell 配置文件里加一段带标记的内容（Windows 改用户 PATH），关闭开关时删除。

## 用量与模型质量

「设置 → 用量与分析」：

- **用量与费用**：本机编程工具（Claude Code、Codex、dsh、Grok、Gemini CLI、Qwen Code、OpenCode、GitHub Copilot CLI、Kimi、Aider）记下的 token 用量和费用，以及官方账号的订阅额度；预算与隐私、价格与模型数据同步也在这里。读取规则见 [隐私与安全](privacy-security.md#编程工具用量日志)。
- **对比 / 趋势 / 请求明细**：持续记录每次请求的成功率、首字延迟、耗时、输出速度、缓存命中等，按模型、供应商、Key、客户端对比。分两种口径：**网关层**（经 Nomi 网关的 HTTP 请求）和 **CLI 层**（在 Nomi 里运行的编程助手的每一轮，含 CLI 自身和工具的开销）。只存元数据，不含对话内容，默认保留 30 天（可选 7 / 30 / 90）。

## 安全

- API Key 用系统安全存储加密（macOS 钥匙串 / Windows DPAPI / Linux Secret Service），保存在本机，界面只能拿到掩码；Key 只随请求发往你为该供应商配置的地址。
- 网关只监听本机，每个客户端用自己的令牌访问；出站请求固定解析后的 IP，防止 DNS 重绑定。
- 工具结果发给谁按真正的上游判断：经网关访问云端供应商时按云端处理，「仅本地」与云端同意照常生效。
- 发往第三方供应商前，对话、文件内容和命令输出里的密钥默认换成占位符，见 [隐私与安全](privacy-security.md#外发保护)。

## 环境变量

- `DEEPSEEK_API_KEY`、`OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY`、`OLLAMA_BASE_URL` 提供的供应商以只读方式接入，没有为 Nomi 对话分配模型时默认用它们。
- `NOMI_PROVIDER=<id>` 强制指定 Nomi 对话的供应商（此时模型选择器与托盘菜单锁定）。

- 网关：[统一网关](../development/gateway.md)，代码在 `apps/desktop-go/internal/gateway`（重试与回退 `server/retry.go`）。

- 视图：`packages/ai-chat/src/components/ModelsPage`、`ProviderLink`、`UsagePanel`、`QualityPanel`。
