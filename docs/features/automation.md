# 自动化与桌面能力

Nomi 可以在你授权的范围内替你动手：读文件、设提醒、上网查资料、跑一小段代码。每一步都会检查权限、写入审计日志，改动类操作可以撤销。

## 文件

- **授权文件夹**：设置 → 隐私与权限 → 桌面权限、对话窗口 📁 或托盘「桌面能力（文件授权 / 操作记录）…」，通过系统选择框授权（只读或读写）。默认什么都访问不了。
- 然后直接说：「帮我总结 ~/Documents/report.pdf」「找一下提到 invoice 的文件」。Nomi 可以列出、搜索、读取、总结 txt、md、pdf、docx 等文件。
- **确认**：需要你同意时，Nomi 弹出气泡（允许 / 查看详情 / 拒绝）；详情对话框显示工具、参数和预演结果。破坏性操作只能在对话框里确认，120 秒未答复视为拒绝。
- **撤销**：删除只会移到应用回收站（保留 30 天）；「操作记录 → 撤销上一步」可恢复最近一次改动。
- **始终拒绝**：`.ssh`、`.gnupg`、云凭据目录、钥匙串、浏览器配置、`.env`、私钥文件以及应用自身的数据目录，即使在授权文件夹内也不行。

## 提醒与剪贴板

- **提醒**：见 [日程](scheduling-calendar.md)。
- **剪贴板**：AI 可以读取或写入当前剪贴板（`clipboard_read` / `clipboard_write`），每次运行前都会先征得同意。

v2.0.4 起移除了笔记（`note_*` 工具与「笔记」标签）和剪贴板历史；启动时会删除旧版留下的剪贴板历史数据。

## 受控浏览器

AI 可以在一个可见的独立窗口里打开公开网页、读取文字、点击和输入，你随时能看到它在做什么。这个窗口不保存 cookie、不共享你的登录，拒绝下载、弹窗和权限请求，也不能访问本机或局域网地址。默认每一步都会询问你。

## 代码沙箱

AI 可以运行一小段 JavaScript 或 Python，每次都要在对话框里看过代码再确认。代码只能读写本次的临时目录，超时自动终止，运行后删除临时目录，环境变量中不包含任何 API Key。

## 权限设置

设置 → 隐私与权限 → 桌面权限 → 工具权限里可以把每个读写类工具设为：总是允许 / 每次运行首次询问 / 每次都询问。破坏性工具和代码运行固定为每次确认。

## 技术说明

- 文件解析在受限的子进程中进行（内存上限、超时）；PDF 用 unpdf，docx 用 fflate 解包读取。
- 一轮对话读过文件内容后，同一轮里的任何写操作都会再次确认，防止文档内容诱导模型改文件。
- 数据保存在 `userData/desktop/`（设置、审计日志、操作记录、回收站）；审计日志只记录参数的哈希与长度。
- JavaScript 沙箱基于 Electron 自带 Node 的权限模型；Python 优先走 OS 沙箱（macOS `sandbox-exec` / Linux `bwrap`），不可用或 Windows 时回落 `python3 -I` 并在结果里标 `sandbox`，界面会说明。详见 [code-sandbox-os](../development/code-sandbox-os.md)。
