# 知识库

入口：对话窗口顶栏「知识 · 记忆 · 日程」抽屉（`Ctrl/⌘+Shift+M`）的「知识库」标签，或设置 → 知识与记忆 → 知识库。输入框旁的 📚 开关（`Ctrl/⌘+Shift+K`）切换「知识库问答」。

## 添加来源

- **文件夹**：只能通过系统选择框添加，添加即授予该文件夹的只读权限；可随时移除。
- **笔记**：Nomi 的本地笔记会一起被索引。
- 支持 txt、Markdown、csv、json、代码文件、PDF（引用带页码）、docx、odt、rtf、xlsx；开启 OCR 后还能识别 png / jpg / webp / bmp / tiff / gif 里的文字。
- 隐藏目录、`node_modules`、`dist` 和超过 30 MB 的文件会跳过；敏感目录（如 `.ssh`、浏览器配置）始终不读。

## 带引用的回答

开启知识库问答后，Nomi 先检索相关片段，再让当前模型基于它们回答。正文里的 `[1]`、`[2]` 是可点击的引用：可以预览片段、打开文件或在文件夹中显示。

## 检索效果

- 默认使用完全本地的关键词检索，对中文也有不错的效果，无需额外配置。
- 可选接入向量模型（推荐本机 Ollama 的 `nomic-embed-text` 或 `bge-m3`）与重排服务，进一步提高相关性。
- 使用云端向量 / 重排服务前需要单独同意发送文件片段；开启「仅本地模型」时一律不发送。

## 更新索引

增量更新：启动后不久以及之后每 30 分钟自动检查一次，也可以随时点「更新索引」或「全部重建」。

## 技术说明

- 解析在受限的子进程中进行（超时与内存上限）。OCR 使用 tesseract.js，本地运行；语言数据（英文、简体中文）按需下载，下载前显示许可并校验 SHA-256。
- 检索为 BM25 + 可选向量的 RRF 融合；数据保存在 `userData/knowledge`。
- 扫描版 PDF 暂不做 OCR（图片文件可以）。
- AI 工具 `kb_search` 可在对话中只读检索知识库。
