# 隐私与安全

Nomi·诺米 是本地优先的：你的数据留在你的电脑上。

入口：「设置 → 隐私与权限」，分「隐私与数据」「外发保护」「数据导出」三个标签；文件授权、工具权限与操作记录在「设置 → Nomi → 桌面权限」。

## 数据保存在哪里

对话、记忆、知识库索引、提醒、日程、任务、技能和设置都保存在本机的应用数据目录（下文写作 `userData`），不上传、不同步：

| 系统    | 位置                                           |
| ------- | ---------------------------------------------- |
| macOS   | `~/Library/Application Support/Nomi`           |
| Windows | `%APPDATA%\Nomi`                               |
| Linux   | `~/.config/Nomi`（或 `$XDG_CONFIG_HOME/Nomi`） |

对话记录在 `userData/conversations/`（见 [AI 对话](chat.md#会话保存在哪里)），文件权限 0600。

API Key、云端识别的 Key、MCP 的密钥 / 令牌用系统安全存储加密；系统安全存储不可用时**拒绝保存**，不会降级成明文落盘。

## 仅本地模式

「设置 → Nomi → 桌面权限 → 云端与仅本地」里的「仅本地模型可读文件」：开启后，文件内容、图片、知识库片段、录音只会交给本机模型（如 Ollama、内置的 llama.cpp）；发给云端模型的这类请求会被拒绝。未开启时，某个云端模型第一次收到这类内容前会征得你的同意，已同意的模型列在同一页。「本机模型」页的「离线模式」也会打开它。

## 外发保护

「设置 → 隐私与权限 → 外发保护」（默认开）：发往第三方供应商之前，对话、文件内容和命令输出里的密钥换成占位符，回复里再换回来，密钥原文只留在本机。对 Nomi 对话和所有编程助手都生效。

- 识别各家 API Key、令牌（GitHub、Slack、JWT 等）、私钥（PEM）、密码（连接串、赋值）；「严格识别」还会按键名认密钥（可能误判）。
- 找到之后可以选择**脱敏**（默认）、**只提醒**（原样发出，只记一笔）或**拦截**（这一轮不发）。
- 「发同格式的假 key」：用前缀、长度、字符类别都相同的假 key 代替占位符，让工具对 key 格式的校验能通过。
- 「你登记的密钥」：公司内网令牌、数据库密码这类没有固定格式的值，登记后（至少 8 个字符，加密存在本机）任何请求里出现都会被隐藏；「从不脱敏」里放误判成密钥的值。
- 「本机模型也隐藏」默认关：Ollama、LM Studio 等本机或局域网模型的数据本来就不出本机。
- 「试一试」粘贴一段文字，在本机算出供应商会收到什么；「最近隐藏的密钥」只记类型、长度和开头几个字符。

## 权限与确认

- 文件只能在你授权的文件夹内访问（系统选择框，或对话里「请求访问文件夹」卡片上点「授权」）；敏感位置始终拒绝。详见 [自动化与桌面能力](automation.md)。
- **Nomi 对话的工作区**：新对话的输入框上方可以给每个 Nomi 对话选一个工作区（新对话默认「文稿/nomi」，也可以不用工作区）。Nomi 的文件工具在工作区里可以直接用；工作区外只有你单独授权过的文件夹 / 文件（包括拖到诺米身上的文件）能访问，并照常走授权与确认。主目录本身、它的上级、文稿 / 桌面 / 下载本身、系统目录和敏感目录不能当工作区。
- **工作区文件操作免确认**（「设置 → Nomi → 权限」，没单独设过时跟随「全部自动」）：开着时，工作区里的文件读写不再逐项确认；工作区外未授权的路径和敏感文件仍然拒绝。
- **命令自动审核**（「设置 → Nomi → 权限」，默认开）：Nomi 跑命令（`workspace_run`）前先让辅助模型判断风险：低风险直接执行；高风险、或这一轮读过外部内容（文件、网页、命令输出、知识库、记忆、MCP 返回等）时交给你确认。审核出错或超时、辅助模型在云端而你还没同意向它发送内容时，也交给你确认。关掉后每条命令都要确认。注意：命令以你的身份运行，**不限于工作区**，能读写你能访问的任何文件。
- **命令白名单**：命令确认卡片上勾「以后不再询问以此开头的命令」，就把它的前缀（如 `pnpm test`、`go test`、`git status`、`pnpm run build`）记进白名单，之后以它开头的命令直接执行，不再审核也不再确认。只认已知的测试 / 构建 / 检查 / 只读查询类「程序 + 子命令」（如 `pnpm test`、`go vet`、`cargo check`、`make test`、`git diff`、`tsc`），只有程序名的（如 `make`）不行；只有简单命令能记：带管道、重定向、`;` / `&&` 串联（开头一个 `cd 子目录 &&` 除外）、命令替换的不行；带 `-exec`、`-toolexec`、`-vettool`、`--output`、`-O`、`--config` 这类能换外部程序或写到任意位置的参数时不记也不放行（按 shell 去掉引号后的实际参数判断，`"-exec=…"`、`--out"put"=…` 一样拦；这些长选项的缩写如 `--outp=…` 也拦）。以下情况仍照常审核 / 确认：这一轮读过外部内容；读过外部内容的一轮里改过文件（之后的轮次也暂停，直到你亲手确认一次命令，最长 24 小时）；「逐项确认」模式；你给这个工具单独设了「每次都询问」。在「桌面权限 → 工具权限 → 命令白名单」里查看和移除；以前记下、现在不再认的规则会自动丢掉。
- Nomi 对话输入栏的**权限模式**（`Shift+Tab` 切换）决定 Nomi 自己的工具多久问一次：
  - **计划**：只读，修改操作直接拒绝；
  - **逐项确认**：每次修改都问，不能「本次运行不再询问」；
  - **自动改文件**（默认）：按「桌面权限 → 工具权限」里每个工具的设置；
  - **自动**：修改操作不再问，单独设过「每次都询问」的工具除外。
  - 删除等破坏性操作、以及同一轮读过文件内容之后的写入，在任何档位都要确认。
- 所有工具调用都写入本地审计日志（只记录参数的哈希与长度）。
- 编程助手的权限另见 [编程助手](coding-agents.md#权限模式)：「全部自动」开着时，新标签以「完全放开」运行，它跑的命令能访问你能访问的一切。

## 导出与清除

- 「数据导出」：把所选类别（对话 `conversations/`、长期记忆、日程与提醒、技能、设置）打包成一个 `.zip`；不包含 API Key 和加密的 MCP 配置值。
- 「隐私与数据」里可以清空当前对话（只删当前对话的消息）、管理记忆、跳到用量隐私设置；记忆、桌面权限等也都可以单独清除。
- 「用模型生成对话标题」：开着时新对话的第一条消息会再发给当前模型一次来起标题；关掉后用第一句话作标题。

## 订阅额度与登录凭据

「设置 → 用量与分析 → 用量与费用」里按工具显示官方账号的订阅额度（Claude Code、Codex、Grok），每张卡可以单独刷新。只有账号 / 订阅登录才显示额度条；用 API Key 或第三方供应商的只标「API 计费，无订阅额度」，并照常显示用量与费用。

- **Nomi 不碰登录凭据**：不读取、不保存、不上传 `auth.json`、`.credentials.json` 或系统钥匙串里的登录信息，不调用未公开的接口；额度从不估算。
- **额度只来自两类来源**：本机已有的数据（如 Codex 写进会话日志的额度快照、Claude Code 状态栏输入里的额度，后者需要你在卡片里主动开启），以及你刷新时由官方 CLI 用它自己的登录态取到的结果（临时运行 `claude -p /usage`、`codex app-server` 或 Grok 的 ACP，只读、不审批，用完即退出）。Nomi 只保留百分比、窗口、重置时间和套餐，邮箱与账号 id 一律丢弃。
- 有多个官方账号时，这些命令在默认账号自己的配置目录里运行。
- 「主动刷新额度」关掉后，刷新只重读本机已有的数据，不启动任何 CLI。

## 编程工具用量日志

「用量与费用」会读取本机编程工具已经写下的**记账字段**（时间、模型、各类 token 数、会话 / 项目名），按请求去重后在本机算费用。支持 Claude Code、Codex、dsh、Grok、Gemini CLI、Qwen Code、OpenCode、GitHub Copilot CLI、Kimi、Aider。

- 只读、只取记账字段：不读对话正文，不读凭据；OpenCode 与 Copilot CLI 的 SQLite 数据库以只读方式打开，只执行固定的查询。
- 不联网、不上传；尊重各工具的主目录环境变量（如 `CLAUDE_CONFIG_DIR`、`CODEX_HOME`、`GROK_HOME`）。
- **用量账本**：去重后的记录存在 `userData/usage/`，按「用量保留」设置（默认 1 年）删除。最近约 2 个月的记录在 `ledger.jsonl`、逐条常驻内存；更早的按本地日期挪进 `ledger-days/YYYY-MM-DD.jsonl`，内存里只留每天的合计与去重用的 key 哈希（`ledger-days/index.gob` 是这些合计的缓存，删了会重建）。统计与热力图直接用每天的合计，请求明细 / 导出 CSV 查到更早的日期时才读那几天的文件；重新扫到早于 2 个月的编程工具日志时，也只读那一两天的文件找对应的网关路由记录，同一个请求不会再记一次。改价格或自定义价格后，更早日期的费用在后台按新价格重算，重算完之前显示的是旧价格的费用（token 与调用数不受影响）。回退到 2.3.0 之前的版本只能看到最近约 2 个月，日文件原样保留，再升级回来就都在。
- **价格与模型数据**：从 `https://models.dev/api.json` 下载公开的价格表与模型参数（启动时距上次核对超过 12 小时才联网，可关闭；或手动「立即同步」），请求里不带任何用量或账号信息。价格优先级：自定义 > 同步 > 内置。

## 诊断日志

「设置 → 隐私与权限 → 隐私与数据 → 诊断日志」，排查第三方供应商、编程助手和网关的问题时用。

- 默认打开（开发版始终记录），对话的「执行轨迹」里能看到网关请求正文。会记下对话内容和代码，只存在本机；不想记录就关掉「保存诊断日志」，之后按你的选择。默认开着时日志保持普通级别；在设置里主动打开（或开发版）才记调试级日志。
- 记录编程助手的收发原文（`userData/logs/`，保留 7 天）和网关的请求 / 响应正文（`userData/gateway/trace/`，保留 24 小时，总量超过 256 MB 时从最旧的删）。每个网关请求有一个追踪 id，写在响应头 `x-nomi-trace-id` 和「请求明细」里。
- Key、令牌和 Authorization 头会被替换掉；环境变量一律不记。
- 「导出诊断包」把最近 24 小时的日志打成一个 .zip，导出前再脱敏一遍。诊断包包含对话内容和代码，只发给你信任的人。
- 开发时可以用环境变量 `NOMI_DIAG_BODY=0` 单独关掉网关正文追踪。

## 应用安全

- 界面与内核之间只经本机 `127.0.0.1` 上的连接通信，每个窗口一份一次性令牌，并校验来源；界面能调用的操作都在应用契约里逐项声明。
- 诺米的气泡、灵动岛只以纯文本渲染。
- 访问外部地址前会检查并拒绝本机、局域网与其他内部地址（包括各种变形写法和 DNS 解析后的地址）；本机 / 局域网的模型服务要你先确认。
