# 屏幕问答

## 截图提问

- 对话窗口 ✂️ 或 `Ctrl/⌘+Shift+S`；任意界面 `Ctrl/⌘+Alt+A`（可在面板中关闭全局快捷键）。
- 对话窗口自动隐藏，在全屏遮罩里拖拽框选：`Enter` 确认、`F` 整屏、`Esc` / 右键取消。
- 截图作为图片附件发给当前模型。图片也可以直接粘贴或拖入输入框。

## 屏幕记忆（默认关闭）

入口：对话窗口 🖥（`Ctrl/⌘+Shift+O`），或设置 → 语音与屏幕 → 屏幕。

- 开启后按间隔（默认 60 秒）截屏，**在本机识别文字**，只保存文字和小缩略图，按保留期（默认 7 天）自动清理。
- 之后可以搜索，或直接问 Nomi：「我刚才看的那个页面说了什么？」
- **自动跳过**：任一可见窗口标题包含排除词（默认含密码管理器、无痕 / 隐私浏览、银行）、画面没有变化、电脑空闲超过 5 分钟、画面里没有文字。
- **明显提示**：托盘显示「● 屏幕记忆中」并可「暂停 1 小时」，对话窗口顶部有红点。

## 隐私

- 发送图片或屏幕记忆片段前都会检查权限：开启「仅本地模型」时拒绝发往云端；云端模型第一次收到图片前会征得你的同意。
- 会话历史只保存缩略图，原图不落盘。

## 技术说明

- OCR 复用知识库的 tesseract 语言包；数据保存在 `userData/screen-memory`。
- 屏幕记忆开启时 AI 可使用工具 `screen_memory_search`。
