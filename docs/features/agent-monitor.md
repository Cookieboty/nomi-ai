# 编程助手监视

> 后续规划（会话接管 / 版本更新 / CLI 供应商）：见 [编程助手接入设计稿](coding-agent-harness.md)。

Nomi 可以帮你盯着本机正在跑的编程助手：任务完成、失败、等你回复或疑似卡住时，用气泡提醒你。

入口：设置 → 编程助手 →「监视与会话」标签（版本检查与更新在各端点页的「版本」卡片）。监视开关、系统通知开关、已检测工具、立即扫描与会话列表都在这里；通知 / 灵动岛的来源与样式在「通知 / 灵动岛」。

## 支持的工具

Claude Code、Codex CLI、Gemini CLI、Cursor、Aider、Cline、Continue。可以按工具单独开关。

## 状态

- **进行中**：最近有活动。
- **等你回复**：这一轮已结束，进程还在。
- **可能卡住**：进程还在，上一步是工具调用，且长时间（默认 5 分钟）没有更新。
- **已完成 / 失败 / 已结束**。

首次发现的历史会话不会打扰你，只在状态变化或卡住时提醒。默认不发系统通知（可开启），macOS 上可以显示在 [灵动岛](dynamic-island.md)。

## 什么时候提示

- **任务开始 / 进行中不提示**：看板娘不弹气泡、不出声，灵动岛也不弹，只在列表里被动显示。完成、失败、等你回复、卡住、需要确认工具权限时才提示。
- **每 10 分钟汇总**：监视开启后，每 10 分钟扫描一次；若还有进行中的任务，提示「还有 N 个编程任务进行中（按工具分组）」，没有则不提示。
- **总结播报**（设置里的开关，默认关）：开启后，汇总会附带当前任务的最近进度并朗读，任务结束时朗读完成总结；关闭时只有气泡 / 灵动岛的简短提示，不出声。

细节见 [编程助手接入设计稿 §14.10](coding-agent-harness.md)。

## 原则

只读取这些工具已经写在本机的会话与日志文件，并检查对应进程是否在运行；从不登录、不访问任何远端账号。

## 技术说明

- 实现：`packages/electron/src/agents/AgentProgressService.ts`（进程检测、会话去重）与 `parsers.ts`（各工具的会话格式）。
- Claude Code、Codex、Gemini CLI 会解析会话内容；Cursor 的会话是私有格式，只根据文件更新时间与进程判断。
