# 编程助手监视

Nomi 可以帮你盯着本机正在跑的编程助手（包括终端里直接运行的）：任务完成、失败、等你回复或疑似卡住时提醒你。

入口：「设置 → 编程助手 → 监视与会话」。这里有「监视编程助手进度」总开关、监视哪些助手、已检测到的工具、「立即扫描」和活跃会话列表（Nomi 自己的编程助手标签可以直接打开）。通知样式与类型在「设置 → 通用 → 通知 / 灵动岛」，免打扰时段在「日程」里。

## 支持的工具

Claude Code、Codex、dsh、Grok、Gemini CLI，可以按工具单独开关。

## 状态

- **进行中**：会话文件刚有写入，进程还在。
- **等你回复**：这一轮已结束，进程还在。
- **可能卡住**：进程还在，但长时间（默认 5 分钟）没有更新。
- **已完成 / 失败 / 已结束**。

会话按会话去重；首次发现的历史会话不会打扰你，只在状态变化时提醒。

## 什么时候提示

- **开始和进行中不提示**：只在列表里显示。完成、失败、等你回复、卡住、需要确认时才提示。
- **定时汇总**：每 10 分钟检查一次，还有进行中的任务时提示「还有 N 个编程任务进行中」，没有就不提示。这条汇总不会退回成系统通知。
- **语音播报**（默认关）：开启后，任务状态和定时汇总在提示音之外再朗读一遍；遵守语音开关与静音。
- 诺米在桌面上时用她的气泡；诺米不在时用 [灵动岛](dynamic-island.md)，灵动岛不可用时改发系统通知。

## 原则

只读取这些工具已经写在本机的会话与日志文件，并检查对应进程是否在运行；从不登录、不访问任何远端账号。

## 实现

- `apps/desktop-go/internal/core/agents`：进程检测 `processes.go`、会话扫描 `fsscan.go`、各工具的会话格式 `parsers.go`、默认值 `settings.go`。Grok 只根据文件更新时间与进程判断。
