# 编程助手监视

Nomi 可以帮你盯着本机正在跑的编程助手（包括终端里直接运行的）：任务完成、失败或这一轮做完在等你回复时提醒一次，中途不播报进度。

几个编程助手前后脚（1.5 秒内）完成或出错时，合成一条提醒，不连着打扰好几次；等你处理的提醒不合并，照常马上弹；Nomi 自己标签的会话只在标签那边提醒一次。已经空闲的会话文件被 CLI 自己碰一下（退出、回收）不算又完成了一次；Gemini 建会话时自带的环境说明（还没有你说的话）不算一个会话。

入口：「设置 → 编程助手 → 监视与会话」。这里有「监视编程助手进度」总开关、监视哪些助手、已检测到的工具、「立即扫描」和活跃会话列表（Nomi 自己的编程助手标签可以直接打开）。通知样式与类型在「设置 → 通用 → 通知 / 灵动岛」，免打扰时段在「日程」里。

## 支持的工具

Claude Code、Codex、dsh、Grok、Gemini CLI、Kimi Code、MiniMax Code，可以按工具单独开关。

## 状态

- **进行中**：会话文件刚有写入，进程还在。
- **等你回复**：这一轮已结束，进程还在。
- **可能卡住**：进程还在，但长时间（默认 5 分钟）没有更新（只在列表里标出，不提醒）。
- **已完成 / 失败 / 已结束**。

会话按会话去重；首次发现的历史会话不会打扰你，只在状态变化时提醒。

## 什么时候提示

- **只在结束时提示一次**：开始、进行中、可能卡住都只在列表里显示，不提示、不播报；完成、失败、这一轮做完在等你回复时提示一次，需要确认时马上提示。
- 以前每 10 分钟一次的「还有 N 个编程任务进行中」定时汇总已经去掉（连同它的定时器），不再有中途的进度播报。
- **语音播报**（默认关）：开启后，任务结束时在提示音之外再朗读一遍结果；遵守语音开关与静音。
- Nomi 工作台在屏幕上时，完成类的提示不弹灵动岛，只弹需要确认和失败；你正看着的那个标签什么都不弹（规则见 [灵动岛](dynamic-island.md#工作台在屏幕上时)）。
- 诺米在桌面上时用她的气泡；诺米不在时用 [灵动岛](dynamic-island.md)，灵动岛不可用时改发系统通知。

## 原则

只读取这些工具已经写在本机的会话与日志文件，并检查对应进程是否在运行；从不登录、不访问任何远端账号。

## 实现

- `apps/desktop-go/internal/core/agents`：进程检测 `processes.go`、会话扫描 `fsscan.go`、各工具的会话格式 `parsers.go`、默认值 `settings.go`。Grok 只根据文件更新时间与进程判断。
