# 语音

设置入口：「设置 → 通用 → 语音」。

## 语音输入

- **按住说话**：按住输入栏的麦克风按钮，或在对话窗口按住 `F2`；`Esc` 取消。
- **免按键对话**：`Ctrl/⌘+Shift+H`，或在诺米工具栏的语音菜单里开关。自动检测你什么时候开始和停止说话，灵敏度可调（灵敏 / 适中 / 稳妥）。下载 Silero VAD 后判断更准，没下载时用基础的能量检测。
- **开口即打断朗读**：诺米朗读时你一开口，朗读就停下。
- **识别后自动发送**：默认开；关掉时识别结果填进输入框，便于修改。
- **识别引擎**：
  - **本地 whisper.cpp**（离线，推荐）：引擎和模型按需下载，下载前显示许可、下载后校验 SHA-256；模型越大越准，也越占空间和时间。
  - **OpenAI 兼容服务**：用已保存的第三方供应商，或填自定义地址（如本机的 whisper.cpp server），请求 `/audio/transcriptions`。
  - **豆包流式语音识别 2.0**（火山引擎，自带 API Key）：录音实时上传识别，由服务商计费；需要先在火山引擎控制台开通。可以设置云端失败时回退到本地 whisper.cpp。
- 使用云端识别前会先征得同意；开启「仅本地模型」时不能把录音发到云端。

## 唤醒词（实验，默认关闭）

开启后说出唤醒词，诺米开始听你说话；唤醒词后面紧跟的话直接作为指令。默认是当前角色包的唤醒词（官方角色为「你好，诺米」），可以改成 2～8 个字的中文或英文。唤醒词检测始终在本机用 whisper.cpp 完成，不上传，需要先下载本地引擎与模型；开启后麦克风在后台持续监听。

## 诺米的声音

声音分两部分：**预录提示语音** + **实时朗读引擎**。台词有预录片段就播片段，没有就交给实时朗读引擎；引擎为「无」或合成失败时只显示文字。

### 角色提示语音（默认开）

- 诺米的常用中文提示语（问候、提醒、开关语音等）随安装包内置为 96 段预录语音，在 `characters/nomi/voice/zh/`。
- 只在界面语言为中文、诺米没有静音、「角色提示语音」开着时播放。
- 带变量的台词（如「你不在的时候错过了 N 条提醒」）气泡显示完整文字，语音念一句固定说法；同一句 1.5 秒内只播一次。

### 实时朗读引擎（默认 Edge 在线朗读）

| 选项                     | 说明                                                 |
| ------------------------ | ---------------------------------------------------- |
| Edge 在线朗读（默认）    | 默认晓伊（`zh-CN-XiaoyiNeural`）、语速 -5%，需要联网 |
| 无（只显示文字）         | 不合成语音，预录提示语音不受影响                     |
| Azure 语音 / OpenAI 语音 | 暂未接入，选中后不出声，只显示文字                   |

- Edge 朗读用的是微软 Edge 浏览器「大声朗读」背后的在线服务，**不是微软公开的官方接口**，以后可能失效；不想把台词文字发给微软，可以把引擎改为「无」。
- **音色与语速**：音色列表在线获取，只保留中文音色；取不到时用内置的几个。「朗读语速」-50%～+50%，台词和 AI 回复共用。「试听」用未保存的设置合成一句，「检测连接」实际合成一个短句并显示延迟。
- 朗读前会去掉代码、链接地址、HTML、Markdown 符号等；长文本按句切段，边播边取下一句。
- 没联网、超时（15 秒）或服务变化时静默，只显示文字；连续失败时设置里会提示「实时朗读暂时连不上」。

### 朗读 AI 回复（默认开）

- 「朗读 AI 回复」开着、且实时朗读引擎可用时，诺米边生成边朗读 Nomi 对话的回复；编程助手对话和委派的那一轮不念。
- 代码块、行内代码、思考过程、表格、链接地址不念；每条回复只念开头约 300 字（按整句）。
- 发新消息、停止生成、切换或新建会话、按住说话时立即打断。

## 隐私

- 应用不保存录音，也不留历史音频。本地 whisper.cpp 识别（包括唤醒词）会把这一段录音临时写进系统临时目录（`cd-asr-*/in.wav`，仅当前用户可读）供引擎读取，识别结束或出错、取消时删除；其余情况录音只在内存里处理。
- 本地引擎完全离线，不上传音频；在线识别会把录音发给所选服务商，每次调用都记入审计日志，服务商如何保留数据以其条款为准。
- 云端识别的 API Key 用系统安全存储加密保存；系统安全存储不可用时不保存。

## 实现

- 视图：`packages/voice`（录音、VAD、唤醒词、设置面板），诺米的播放与口型 `packages/renderer/src/mascot/tts/audioPlayback.ts`，预录片段 `packages/renderer/src/mascot/voice/promptClips.ts`，朗读切句 `packages/ai-chat/src/services/replySpeech.ts`。
- 内核：识别 `apps/desktop-go/internal/core/voice`（`whisper.go`、`cloudasr.go`、`volc.go`），朗读 `internal/core/tts`（Edge 客户端在 `tts/edge/`，项目自写，不需要安装 Edge）。
- 预录片段生成脚本：`scripts/voice/gen.py`（需要 `pip install edge-tts` 和 ffmpeg）。
