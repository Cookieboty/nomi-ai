# 自动更新

- 安装版在启动约 15 秒后静默检查一次更新，之后每 6 小时检查一次。
- 发现新版本自动开始下载，设置 → 通用 →「更新」显示进度。
- 下载完成后提示「更新已下载，重启后安装」；工作台左下角「设置」旁与设置页左下角会出现「重启更新」，**必须由你点击**（设置页「关于与更新」里仍可先确认再装）才会重启安装，绝不会在退出时偷偷安装。
- 更新安装并重启后，若未关闭「更新后显示更新日志」，会弹出本版本的更新说明（日期、新增 / 优化 / 修复、历史链接）；取消勾选会持久化，之后升级不再自动弹出，可在设置 → 通用 →「关于与更新」重新打开该开关，或点「查看」随时打开。
- 可以在设置 → 通用 →「更新」里关闭自动检查，或随时手动「检查更新」。
- 检查、下载、安装任一步失败，都会说明失败在哪一步，按钮变成「重试」（重试会先取消旧的下载）；下载 90 秒没有任何进度会自动取消并标为失败。
- 从源码运行时更新不可用，设置页会说明。

## 技术说明

使用 electron-updater，更新源为本项目的 GitHub Releases。发布流程见 [发布](../RELEASE.md)。
