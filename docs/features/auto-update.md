# 自动更新

设置入口：「设置 → 通用 → 通用 → 关于与更新」。

- 安装版启动约 15 秒后检查一次更新，之后每 6 小时检查一次。可以关掉「启动时与定期自动检查更新」，或随时手动「检查更新」。
- 发现新版本后自动在后台下载本平台的安装包，设置页显示进度。新版本刚发布、本平台的安装包还没上传完时，会提示稍后再检查。
- 下载完成后提示「更新已下载，重启后安装」，侧栏底部和设置页左下角出现「重启更新」。**必须由你确认**才会安装，不会在退出时偷偷安装。点了之后：
  - **macOS**：Nomi 退出，新版本换进原来的位置（「应用程序」里的 Nomi.app）后自动重新打开，不用再拖拽。只有 Nomi 不在可写的位置时
    （直接从 dmg 里运行、从「下载」里打开的隔离副本、所在文件夹没有写权限），才会打开新的 dmg 让你拖进「应用程序」。
  - **Windows**：后台静默运行安装程序覆盖升级，装完自动重新打开，不弹安装向导。
  - **Linux**：AppImage 原地替换后重新打开；deb 交给系统的软件安装器。
- 检查或下载 90 秒没有任何响应会自动取消并标为失败；任一步失败都会说明失败在哪一步，按钮变成「重试」。
- 更新后重启时，若开着「更新后显示更新日志」（默认开），会弹出这个版本的更新说明；「查看」可以随时打开。
- 从源码运行时没有自动更新，设置页会说明。

## 实现

- 更新源是本项目 GitHub Releases 里的 `latest-go.json`（各平台安装包的地址、大小、SHA-256 和更新说明；macOS 条目另有 `update`，
  指向原地替换用的 `-mac.zip`）；下载后校验 SHA-256。
- macOS 原地替换（`swap_unix.go`）：zip 解压到 Nomi.app 旁边的隐藏暂存目录，校验签名有效、Bundle ID 一致、与当前应用同一个 Team ID，
  然后由一个独立的小脚本等 Nomi 退出、把新 Nomi.app 换进原位置（换失败就恢复旧的）并重新打开。
- Windows 以 `/S --updated --force-run` 运行 NSIS 安装器（`packaging/windows/installer.nsi`）。
- 代码：`apps/desktop-go/internal/core/updates`（`service.go` 检查时机与状态，`github.go` 下载与安装，`releasenotes.go` 更新说明）；清单由 `apps/desktop-go/packaging/update-manifest.py` 生成。发布流程见 [发布](../RELEASE.md)。
