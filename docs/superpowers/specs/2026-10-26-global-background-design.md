# 全局图片背景

## 已确认的行为

- 图片位于窗口最底层，对话、侧栏、Diff / 文件预览、设置、引导和功能弹窗共用。
- 移除欢迎区域的独立毛玻璃效果，不再出现中间单独模糊的矩形。
- 自定义背景仅保留「毛玻璃」「透明度」，毛玻璃仅处理背景，文字与控件保持清晰。
- 主题选择新增「图片主题」；仅选中图片主题时显示图片选择、毛玻璃、透明度。删除独立的聊天背景与纯色背景选择。
- 图片主题固定使用石墨基础配色；缓存已选图片及自定义参数，重启后恢复。预设与用户图片独立，用户选图优先，重新选图立即覆盖且不重置参数；恢复默认回到预设、8px 毛玻璃及 40% 透明度，不退出图片主题。当前原图仅用作本机预设，开放分发许可确认前不随安装包内置；无预设时安全回退为空背景。
- 对话侧栏展开时显示 Nomi 图标与文字，整块品牌按钮可收起；收起时只显示图标并可展开，移除标题栏独立开关。保留快捷键与键盘可访问性。
- 图片主题的用户消息、工具展开详情、选中 Tab、底部输入框和文件列表使用侧栏同色深的半透明背景；其他主题保留原有底色。文件列表内层透明，避免半透明底色多次叠加。
- Markdown 代码块、行内代码、表头和图片占位与侧栏使用同色深的半透明背景，代码块标题与正文保持透明，避免重复叠加。保留语法高亮、复制、表格滚动及图片预览；复制按钮使用透明 hover 蒙版与颜色过渡，减少动态效果时禁用。
- 本地模型、日历和剪贴板卡片，以及 MCP 卡片与预设接入半透明面板令牌；设置导航、主题卡片及文件栏控件 hover 使用透明蒙版与 200ms 颜色过渡，减少动态效果时禁用。文件栏分段控件的底层保持透明，避免面板底色重复叠加，其他主题配色保持不变。
- 顶栏内标签撑满顶栏高度，去掉顶部留白、标签之间的缝隙及圆角缺口，图标、新建与右侧操作垂直居中；窄栏换行后标签仍撑满第二行。图片主题的顶部底色与侧栏同色深，选中标签只叠加轻透明蒙版；顶栏底边与侧栏、文件栏分隔使用同一半透明边框令牌。拖动条显示为单条细线，不与相邻边框叠加，保留拖动热区、双击重置与减少动态效果。
- 工具调用条不显示背景与边框；hover 只过渡文字颜色，不改背景，保留状态色和键盘焦点。图片主题的 Tab 和品牌按钮 hover 继续透出图片：独立表面使用 70% 的侧栏底色，已有面板上的 hover 用 18% 同色蒙版。颜色进入和退出用 200ms 过渡，减少动态效果时禁用。

## 实现

- 上下文用量提示移除硬编码棕底与白字，使用主题浮层令牌，图片主题为侧栏同色系 92% 深色半透明背景，同色箭头；保留进度环状态色。中央 Modal（不包括内嵌与侧抽屉）、全屏审查和引导卡片在图片主题下使用 94% 深色半透明背景，保持原有遮罩，不增加局部模糊；命令 / 插件列表项使用半透明面板背景与边框。

- 背景挂到 body，固定铺满视口；body 建立层叠上下文，负层级不逃逸到页面底色下。
- 最底层图片固定铺满窗口，第二底层蒙版使用 backdrop-filter 提供毛玻璃模糊；两层均不缩放、不扩边，调整模糊不改变图片取景。
- 面板使用独立的语义背景令牌；图片主题的设置卡片、帮助栏、分区标签、模型 / 供应商配置、知识 / 记忆、语音资源、屏幕记忆、用量和质量面板使用半透明背景。共享输入框、下拉框与次按钮同色系半透明，菜单与提示使用深透明浮层；仅覆盖控件专属令牌，不改变基础色板、状态色与其他主题。
- 设置覆盖层改为透明，共用背景层；禁用自定义背景时还原主题外观。
- 配置持久化统一为 blur；旧 blurCenter 优先迁移，缺省时用 blurLeft / blurRight。已有 blur 优先。
- 主题持久化 image 偏好，实际色板解析为 graphite，原生窗口同步为深色；图片地址与参数原子写入，启动验证文件存在、格式与路径安全，旧临时图片自动迁移，预设及自定义缓存互不覆盖。保持用户显式设置的 0px 等值。
- 每次选图生成新的资源地址并删除上张图片，协议响应禁用缓存；拖动毛玻璃滑块时旧 IPC 回包不能覆盖最新数值。
- 不更改桌面壁纸或看板娘角色素材，也不改 IPC 白名单与图片文件安全边界。

## 验证计划

1. 主进程单测验证旧配置迁移、数值约束、图片主题与参数持久化、原生窗口外观、保存和重置。
2. 渲染进程单测验证只有图片主题显示图片配置、只保留两个滑块、全局状态同步、背景层和主题模式切换。
3. CSS 契约验证窗口底层、第二底层毛玻璃蒙版、图片取景不变、欢迎区域无额外模糊、输入区与弹层层级不回归。
4. 类型检查、lint、i18n / 前端标准检查，并用浏览器验证设置与弹窗背景和全局模糊。
