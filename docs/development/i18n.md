# 多语言开发规范

Nomi 的语言资源集中在包 **`@nomi-ai/i18n`**（[`packages/i18n`](../../packages/i18n)）；视图、Go 内核与插件共享同一个词典。`packages/ui` 只保留语言状态和视图适配；Go 内核内嵌一份副本（`apps/desktop-go/internal/core/i18n/locales`，`dict_test.go` 比对两份），用 `i18n.T(key, args…)` 取文案。运行时只解析稳定 key（`project.module.message`），**中文原文不能作为 key**，也不会通过兼容映射自动转换。

## Key 和目录

稳定 key 使用三段小写 kebab-case：`project.module.message`。

| 目录                               | 用途                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------- |
| `src/locales/zh`                   | 基准中文词典，定义完整 key 集合                                           |
| `src/locales/en`                   | 英文词典                                                                  |
| `src/locales/<language>`           | 后续语言，目录名使用短语言标识，例如 `ja`                                 |
| `src/locales/<language>/<project>` | 项目边界，例如 `ui`、`electron`（主进程文案，名字沿用旧版）、`ai-runtime` |
| `*.json`                           | 模块词典，例如 `chat-settings.json`、`common.json`                        |

同一个 key 必须出现在 `zh` 和所有已接入语言中。占位符也必须一致，例如 `{0}`、`{name}`。同一项目内不能让两条 key 共用同一段基准文案，避免后续维护和翻译检查产生歧义。

业务代码统一调用稳定 key：

```ts
t('ui.chat-settings.new-chat');
t('electron.common.read-failed', fileName);
```

## 修改流程

1. 在 `zh` 和所有语言的同一模块中增加或修改 key。
2. 执行 `node scripts/i18n/refresh-catalog.mjs`，更新生成的 `catalog.ts`。
3. 改了 `electron` / `ai-runtime` 或 Go 用到的 key：把 `packages/i18n/src/locales` 复制到 `apps/desktop-go/internal/core/i18n/locales`。
4. 执行 `pnpm check:i18n`。
5. 执行相关包的 typecheck 和测试（Go：`go test ./internal/core/i18n/`）。

检查会报告：中文 key、非法 key 格式、缺失或多余翻译、占位符不一致、项目内重复基准文案、源码中的未知 key 和死 key。Go 源码与内嵌 JSON
（`apps/desktop-go`，不含测试）里的字符串字面量也计入使用（`goKeySources`）；`fmt.Sprintf("electron.common.task-level-%d", n)` 这样的格式串
按模式匹配一组 key；`electron.*` / `ai-runtime.*` 下 Go 用到却不在词典里的 key 报未知。

## keepZh（保留中文）

`scripts/i18n/config.cjs` 的 `keepZh` 列出**刻意保留中文、不进词典**的源文件。这些文案面向模型或内部解析，不是用户界面：

- 唤醒词（`voice/src/wake.ts`）

Go 内核里面向模型的提示词、工具 schema 不经词典，检查只看 Go 里形如稳定 key 的字符串，不管其中的中文。

用户可见的 UI 字符串不要靠 keepZh 躲过检查；应写入 `packages/i18n` 并用 `t()` / `tr()`。修改 `keepZh` 时同步更新本说明。
