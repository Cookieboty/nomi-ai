编程助手经第三方供应商时的报错更合理：供应商的 Key 无效（上游 401 / 403）不再原样转给 CLI，改成 502 并说明「请在「模型」页检查 Key」，Claude Code 不会再误以为要重新登录官方账号；首字节前超时返回 504。网关新增按标签区分的路由令牌与绑定（标签选的主模型、档位、辅助模型、思考深度跟着这个标签走；CLI 发来不认识的模型名时按标签主模型处理并在请求记录里注明），以及按 Key 的并发 / 每分钟请求数上限（超出时排队，等不到换下一个 Key）。各编程助手的差异（内置模型名、会话标识、严格程度、心跳形式）改为客户端规格统一描述。
