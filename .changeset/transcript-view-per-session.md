对话与编程助手会话新增按会话生效的会话详细程度（#310）：

- 设置 → 通用 → 外观新增全局默认（精简 / 显示思考 / 详细），初始「显示思考」；
- 会话标题栏新增菜单，可按会话覆盖全局默认，会话级优先；菜单底部「跟随全局设置」清除覆盖；
- 精简：两段回复之间的工具调用按类型（探索 / 命令 / 编辑 / 其它）各合成一行，同类不必相邻、每段每类最多一行，进行中显示正在做的那一步；思考不单独显示；
- 显示思考：工具调用同样按类型各一行，思考合并成一块单独显示；
- 详细：每次工具调用单独一行，参数与输出、思考都默认展开；
- 选择只影响当前会话，切换会话或重启后保留。
- 思考折叠时显示第一句，进行中显示正在想的那一句；进行中的步骤文字带流动的灰度渐变。
