feat(side-workspace): 侧边工作区新增内置交互式终端。内核侧按标签 id 起一个跨平台 PTY（macOS / Linux 用 unix pty，Windows 用 ConPTY），视图侧用 xterm.js 收发；同一 id 复用同一个 PTY 并回放最近输出，切会话不重建。终端支持向右 / 向下分屏（二叉树布局，双击分隔条恢复均分）、清屏、切换目录、重启、在系统终端中打开；关闭仍有进程在跑的分屏或标签会先确认，关标签会连同其下所有分屏一起结束。「新建标签页」也重做成按「工作区 / 协作与工具」分组的入口卡片，终端从主工程目录打开（worktree 里的 CLI 标签默认落到项目主文件夹）。新契约过程 `sideTerminal.open / write / resize / sync / close / closeAll`，目录守卫只拦受保护目录与非法路径，不再因主目录过于宽泛而拒绝，未绑定项目的会话也能开终端。/ The side workspace gains a built-in interactive terminal: the kernel runs a cross-platform PTY per tab id (unix pty on macOS and Linux, ConPTY on Windows) driven by xterm.js in the view, reusing the same PTY and replaying recent output when a tab is revisited. Terminals can split right or down in a binary layout (double-click the divider to even it out), clear, change directory, restart, or open in the system terminal; closing a pane or tab that still has a running process asks first, and closing a tab ends every pane under it. The new-tab page is rebuilt as grouped entry cards (workspace / collaboration and tools), and terminals open at the project's primary folder rather than a worktree. New contract procedures `sideTerminal.open / write / resize / sync / close / closeAll`; the directory guard blocks only protected and invalid paths, so sessions without a project can open one too.
