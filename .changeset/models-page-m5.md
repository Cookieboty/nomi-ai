「模型」页可以编辑第三方供应商：调整 Key 的回退顺序、增删和停用 Key（每个 Key 显示最近一次错误），手动添加或刷新模型，设置回退链；「高级」里可以改各协议地址、给模型或 Key 指定协议、模型映射、自定义请求头和 User-Agent。环境变量提供的供应商（如 DEEPSEEK_API_KEY）在「模型」页只读显示，Nomi 对话没有分配模型时直接使用它。编程助手一栏里没安装的 CLI 可以一键安装。新增可选的「终端启动命令」：打开后可以在终端里用 nomi-claude、nomi-codex 等命令使用第三方模型（直接运行 claude、codex 仍是官方登录），加入 PATH 前会先确认。托盘菜单改为列出最近用过的 5 个模型。移除了旧版编程助手第三方供应商与本地路由的残留代码和接口。
