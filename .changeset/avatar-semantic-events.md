refactor(mascot): the AI and the character now exchange semantic events only. `avatar_gesture` takes `{ name }` with a semantic gesture (`thumbsUp`, `shakeHead`, `greet`, `random` …) instead of `{ group, index }` with a clip name, and `avatar_emotion` takes `{ name, weight? }` with a semantic emotion (`happy`, `relaxed` …); clip / motion names are rejected. A character pack's `mapping.json` translates these names to its own expressions and motions, and names it does not map are ignored (a pack without `mapping.json` uses the default mapping, which matches the built-in character, so its behaviour is unchanged). The `waifu` preset is renamed `companion` with no alias (`WaifuToolsPlugin` → `CompanionToolsPlugin`, `WaifuAgentPresetPlugin` → `CompanionAgentPresetPlugin`); nothing on disk stores the preset id, so no migration is needed. The unused `TtsLipSyncPlugin` and `TouchInjectPlugin` are removed: lip sync stays in the mascot window, and taps and pats reach the AI as `touched` / `clicked` events.
