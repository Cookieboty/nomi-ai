feat(agents): coding tools (Claude Code / Codex / dsh …) no longer pop a bubble, voice, sound or island notice when a task starts; only finish / failure / waiting / stalled / permission requests notify. While monitoring is on, a digest ("N coding tasks still running", grouped by tool) is shown every 10 minutes. New "Spoken summaries" switch (off by default) adds progress to the digest and reads a completion summary aloud through the existing TTS path; when off, only short bubble / island notices are shown.
