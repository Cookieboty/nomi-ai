perf(chat): Nomi 对话更省上下文、缓存更稳。按需提供的工具在同一个对话里开过就一直提供，「派出去」的规则也不随话题时有时无，前缀缓存不再被打断；前几轮的思考内容不随历史重发（Anthropic 以外的协议会把它算进输入）。上一轮用量过了约 60% 时，较早几轮工具记录里的大段输出只留开头和结尾，对话原文能保留得更久；一轮里缩短之后仍然快满时，把较早的步骤压成摘要接着做。命令和代码输出超过上限时保留开头和结尾（报错不再被截掉），命令输出上限降到 3 万字。`/compact` 的摘要分节写，并补上最近的文件、计划和技能，后面可以写重点。执行轨迹和 `/context` 里显示上一轮的缓存命中率。/ Nomi chats use less context and hit the prompt cache more reliably. Tools that were offered once in a chat stay offered, and the hand-off rules no longer come and go with the topic, so the cached prefix isn't broken; reasoning from earlier turns is no longer resent (protocols other than Anthropic bill it as input). Once the last reply used about 60% of the context, long tool outputs from older turns keep only their beginning and end, so the original conversation lasts longer; if a turn is still nearly full after that, its earlier steps are summarized and work continues. Command and code output over the limit keeps its beginning and end, so errors are no longer cut off, and command output is capped at 30k characters. `/compact` writes a sectioned summary followed by recent files, the plan and loaded skills, and accepts what to focus on. The execution trace and `/context` show the last reply's cache hit rate.
