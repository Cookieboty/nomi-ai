分叉合成一个弹窗：分叉到同一个端的新会话或其他端、带入几轮上下文（全部 / 最近 20、10、5、3 轮）、放进哪个项目都在一处选；会话菜单只留一项「分叉对话」。每条回复末尾新增「从这里分叉」：只带到这条回复为止，之后的消息不带，原会话不受影响。

Forking is one dialog: fork to a new session on the same endpoint or to another endpoint, choose how many turns to carry (all / last 20, 10, 5, 3) and which project, all in one place; the conversation menu has a single "Fork chat" item. Each reply now has "Fork from here", which carries messages only up to that reply and leaves later ones out; the original chat is unchanged.
