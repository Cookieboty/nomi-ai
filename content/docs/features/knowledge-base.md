# 知识库

入口：「设置 → 知识与记忆 → 知识库」；侧栏底部「知识 · 记忆 · 日程」图标或 `Ctrl/⌘+Shift+M` 从右侧抽屉打开同样的标签页。输入框的「更多功能」菜单或 `Ctrl/⌘+Shift+K` 切换「知识库问答」。

## 添加来源

- 点「加入文件夹」，通过系统选择框添加；加入即授予该文件夹的只读权限，可以随时移除。
- 支持 txt、Markdown、csv、json、yaml、html 和常见代码文件，以及 PDF（引用带页码）、docx、odt、rtf、xlsx。
- 隐藏目录、`node_modules`、`dist`、`build` 等目录和超过 30 MB 的文件会跳过；敏感目录（如 `.ssh`、浏览器配置）始终不读。
- 图片里的文字暂时不能检索：面板里有「识别图片中的文字（OCR）」开关和语言数据下载，但当前版本还没有 OCR 识别，开启后图片文件会索引失败（不影响其它文件）。

## 带引用的回答

开启「知识库问答」后，Nomi 先检索相关片段，再让当前模型基于它们回答，用你提问的语言回答。正文里的 `[1]`、`[2]` 是可点击的引用：可以预览片段、打开文件或在文件夹中显示。「每次引用片段数」决定附给模型多少段，越多越全面，也越占上下文。

「检索测试」标签里可以输入问题，看看能检索到哪些片段。

## 检索效果

- 默认用完全本地的关键词检索（BM25），对中文也有不错的效果，不需要额外配置。
- 「向量与重排」里可以接入向量模型（推荐本机 Ollama 的 `nomic-embed-text` 或 `bge-m3`）和支持 `/rerank` 接口的重排服务，进一步提高相关性。服务从「设置 → 模型与供应商」里已添加的供应商中选。
- 使用云端向量 / 重排服务前要单独同意发送文件片段；开启「仅本地模型可读文件」时一律不发送。

## 更新索引

增量更新：启动后约 20 秒以及之后每 30 分钟自动检查一次，也可以随时点「更新索引」或「全部重建」。

## 实现

- 内核：`apps/desktop-go/internal/core/knowledge`（检索为 BM25 + 可选向量的融合排序），文件解析 `internal/core/desktop/parse`；数据保存在 `userData/knowledge`。
- AI 工具 `kb_search` 可以在对话中只读检索知识库。
- 视图：`packages/ai-chat/src/components/KnowledgePanel`。
