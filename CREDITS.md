- **Onboarding illustrations** (`characters/nomi/onboarding/*.webp`: welcome, profile, provider, privacy) — AI-generated scene art requested by the project owner (Cookieboty) for the first-run guide and licensed by the project owner under the MIT licence. Updated in v2.0.4: welcome / profile / provider were regenerated using the official reference art (`docs/brand/reference/nomi-closeup.png`, `nomi-clean-halfbody.jpg`) as the character reference so Nomi's face, hair and accessories stay consistent across all steps. The hands are shown purely through per-step CSS sizing and bottom alignment, with no redraw. Because the original art clips the top of Nomi's hair at the frame edge, the app webps (960×800, lossless) add 260px of plain background above each image and extend only the missing hair crown (≈11–26px) by deterministically projecting the original top-row hair pixels onto a contour-matched dome; every pixel of the original image is kept byte-identical below the extension. A dedicated privacy illustration (Nomi holding a glowing lock shield) was generated for step 4 using the welcome / profile / provider art as reference. They are decorative only and are **not** brand-lock master art; the rig and brand parts are unchanged — see [docs/BRAND.md](docs/BRAND.md#9-品牌锁).
- **Vector logo / app icons / tray icons** (`docs/brand/*.svg`, `apps/desktop-electron/assets/`) — recreated as vectors from the brand board by Nomi-ai contributors; same terms.

## Code references

- **[magpie](https://github.com/yetone/magpie)** by yetone — MIT licence (© 2026 yetone).
  - Unified gateway (`packages/gateway/`): design reference for reasoning-effort fitting (`fitLevel`), passing sealed reasoning back unchanged (`SealedBy`), tool-call ids and pairing, and text tool calls; the fixed effort↔budget table in `packages/gateway/src/intent.ts` (4096 / 10000 / 24000 / 32000 and the 4096 / 12000 / 24000 thresholds) uses magpie's values (`internal/gateway/ir.go` `budgetOf` / `effortOfBudget`).
  - Privacy mode (`packages/gateway/src/privacy/`): design reference for secret masking from `internal/redact`, `internal/masking`, `internal/gwmw` and `LESSONS.md` — `{{KIND_xxxxxxxx}}` placeholders keyed by HMAC-SHA256, restoring them in streamed responses, masking already-seen values, skip rules, and refusing to send when masking fails, plus shape-preserving fake keys. The code is an independent TypeScript implementation, **except** several built-in secret-detection regexes in `packages/gateway/src/privacy/rules.ts` (private key block, `sk-…`, relay `xx_sk_…`, GitHub / GitLab tokens, `AIza…`, `AKIA/ASIA…`, Slack `xox…`, JWT, `scheme://user:pass@`), which are ported from magpie `internal/redact/redact.go`. magpie's copyright notice and MIT licence text are reproduced in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md#magpie).
